## 一、 矩阵乘法转置公式的证明

**结论**：设 $A$ 是 $m \times n$ 矩阵，$B$ 是 $n \times s$ 矩阵，则 $(AB)^T = B^T A^T$ 。

**证明**：

我们可以通过比较等号两边矩阵在第 $i$ 行、第 $j$ 列的元素是否相等来证明。

1. **左边 $(AB)^T$ 的元素**：
    
    - 设 $C = AB$。根据矩阵乘法定义，$C$ 的第 $j$ 行第 $i$ 列元素为 $c_{ji} = \sum_{k=1}^n a_{jk} b_{ki}$ 。
        
    - 那么 $C^T$（即 $(AB)^T$）的第 $i$ 行第 $j$ 列元素就是原矩阵的 $c_{ji}$。
        
2. **右边 $B^T A^T$ 的元素**：
    
    - 设 $B^T$ 的第 $i$ 行是原矩阵 $B$ 的第 $i$ 列，其元素可记为 $b'_{ik} = b_{ki}$ 。
        
    - 设 $A^T$ 的第 $j$ 列是原矩阵 $A$ 的第 $j$ 行，其元素可记为 $a'_{kj} = a_{jk}$ 。
        
    - $B^T A^T$ 的第 $i$ 行第 $j$ 列元素为：$\sum_{k=1}^n b'_{ik} a'_{kj} = \sum_{k=1}^n b_{ki} a_{jk}$ 。
        
3. **结论**：
    
    - 观察发现 $\sum_{k=1}^n b_{ki} a_{jk} = \sum_{k=1}^n a_{jk} b_{ki}$。
        
    - 两边对应元素完全一致，故 $(AB)^T = B^T A^T$ 成立 。

## 二、 关于秩结论 $r(A) = r(A^T A)$ 的证明

**结论**：对于任意实矩阵 $A$，其秩与其转置乘积的秩相等 。

**证明**：

这个证明通常通过证明齐次线性方程组 $Ax = 0$ 与 $A^T Ax = 0$ 具有相同的**解空间**（同解）来完成。

1. **证明同解**：
    
    - 若 $x$ 满足 $Ax = 0$，则显然有 $A^T(Ax) = A^T 0 = 0$，所以 $x$ 也是 $A^T Ax = 0$ 的解 。
        
    - 反之，若 $x$ 满足 $A^T Ax = 0$，我们在等式左边同时乘 $x^T$：
        
        $$x^T A^T Ax = x^T 0 = 0$$
        
        $$(Ax)^T (Ax) = 0$$
        
    - 由于 $(Ax)^T (Ax)$ 相当于向量 $Ax$ 的内积（模的平方），根据向量性质，内积为 0 意味着向量本身必须为 0 。
        
    - 故 $Ax = 0$。这说明两个方程组同解。
        
2. **秩的推导**：
    
    - 既然两个方程组同解，它们的基础解系所含向量个数 $n - r$ 就相等 。
        
    - 因此，$n - r(A) = n - r(A^T A)$。
        
    - 得出 $r(A) = r(A^T A)$ 。
        
3. **延伸结论**：
    
    - 同理可证 $r(A^T) = r(AA^T)$。
        
    - 结合 $r(A) = r(A^T)$ ，最终得到：
        
        $$r(A) = r(A^T) = r(A^T A) = r(AA^T)$$

**助手笔记**： 这个性质在处理**最小二乘法**或**实对称矩阵**（如讲义第五章、第六章内容）时非常有用。特别是 $A^T A$ 永远是一个实对称矩阵 ，这为你后续学习二次型打下了坚实基础。
