


### 一、 证明：两个可逆矩阵的乘积仍可逆

**结论**：若 $n$ 阶矩阵 $A$ 与 $B$ 均可逆，则 $AB$ 也可逆，且 $(AB)^{-1} = B^{-1}A^{-1}$ 。

**证明过程**：

1. **利用逆矩阵定义**：根据讲义定义，若能找到一个矩阵 $C$，使得 $(AB)C = C(AB) = E$，则 $AB$ 可逆且 $C$ 为其逆矩阵 。
    
2. **构造并验证**：令 $C = B^{-1}A^{-1}$。
    
    - **左乘验证**：$(AB)(B^{-1}A^{-1}) = A(BB^{-1})A^{-1} = AEA^{-1} = AA^{-1} = E$ 。
        
    - **右乘验证**：$(B^{-1}A^{-1})(AB) = B^{-1}(A^{-1}A)B = B^{-1}EB = B^{-1}B = E$ 。
        
3. **结论**：根据逆矩阵的唯一性，矩阵 $AB$ 是可逆的，其逆矩阵为 $B^{-1}A^{-1}$ 。

### 二、 证明：矩阵乘以可逆矩阵，其秩不变

**结论**：设 $A$ 是 $m \times n$ 矩阵，若 $P, Q$ 分别为 $m, n$ 阶可逆矩阵，则 $r(A) = r(PA) = r(AQ)$ 。

**证明过程（以左乘 $P$ 为例）**：

1. **初等矩阵分解**：讲义第 49 页推论指出，任何可逆矩阵 $P$ 都可以表示为有限个初等矩阵的乘积，即 $P = P_s \cdots P_2 P_1$ 。
    
2. **初等变换对应关系**：根据初等矩阵定理，左乘一个初等矩阵 $P_i$ 相当于对矩阵 $A$ 施行了一次相应的初等行变换 。
    
3. **秩的不变性**：讲义第 50 页明确给出定理：**初等变换不改变矩阵的秩** 。
    
4. **递推得出结论**：
    
    - $r(A) = r(P_1 A)$（一次行变换）
        
    - $r(P_1 A) = r(P_2 P_1 A)$（再次行变换）
        
    - 依此类推，最终得到 $r(A) = r(P_s \cdots P_1 A) = r(PA)$ 。
        
5. **同理**：右乘可逆矩阵 $Q$ 相当于施行初等列变换，同理可证 $r(A) = r(AQ)$ 。
