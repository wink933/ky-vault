## 1. 线性表示 (Linear Representation)

**定义**：如果 $n$ 维向量 $\beta$ 可以表示为向量组 $\alpha_1, \alpha_2, \dots, \alpha_s$ 的线性组合，即存在一组数 $k_1, k_2, \dots, k_s$，使得：

$$\beta = k_1\alpha_1 + k_2\alpha_2 + \dots + k_s\alpha_s$$

我们就称 $\beta$ 可由该向量组**线性表示** 。

- **方程组视角**：$\beta$ 能否被线性表示，等价于非齐次线性方程组 $Ax = \beta$ 是否有解 。
    
- **秩的判定**：$\beta$ 可由向量组线性表示 $\iff r(\alpha_1, \dots, \alpha_s) = r(\alpha_1, \dots, \alpha_s, \beta)$ 。
    
- **温馨提示**：零向量能被任何向量组线性表示（系数全取 0 即可） 。

## 2. 线性相关与线性无关 (Linear Dependence/Independence)

这是考研最核心的考点，它们描述的是向量组内部是否有“冗余” 。

### 线性相关 (Linear Dependent)

**定义**：如果有**不全为零**的数 $k_1, k_2, \dots, k_s$，使得 $k_1\alpha_1 + k_2\alpha_2 + \dots + k_s\alpha_s = 0$，则称向量组**线性相关** 。

- **直观理解**：向量组里至少有一个向量是多余的，可以被其他的向量组合出来 。
    
- **判定结论**：包含零向量的向量组一定线性相关 。
    

### 线性无关 (Linear Independent)

**定义**：只有当系数 $k_1 = k_2 = \dots = k_s = 0$ 时，等式才成立，则称向量组**线性无关** 。

- **直观理解**：每个向量都是独立的，谁也代表不了谁，没有任何“废话” 。
    
- **判定结论**：单个非零向量一定线性无关 。

## 3. 三位一体：从方程组和秩的角度理解

讲义第 67 页将这些抽象定义与我们之前的工具联系了起来 ：

|**概念**|**对应方程组 Ax=0**|**矩阵秩 r(A) 与向量个数 s 的关系**|
|---|---|---|
|**线性相关**|有非零解|$r(A) < s$|
|**线性无关**|只有零解|$r(A) = s$|

**重要推论**：

1. **维数限制**：当向量个数 $s >$ 向量维数 $n$ 时，这组向量必线性相关（比如 3 个二维向量一定相关） 。
    
2. **行列式判定**：对于 $n$ 个 $n$ 维向量，线性无关 $\iff |A| [cite_start]\neq 0$ 。

## 4. 常用“骚操作”结论 (总结自讲义第 73-76 页)

- **部分相关 $\implies$ 整体相关**：如果一个小分队里有人搞小团体（相关），那整个大部队就相关 。
    
- **整体无关 $\implies$ 部分无关**：如果大部队纪律严明（无关），那拆出来的任何小分队肯定也无关 。
    
- **以少表多，多必相关**：如果用 3 个向量能表示出 5 个向量，那这 5 个向量内部一定存在冗余（线性相关） 。
