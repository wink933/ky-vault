### 📌 考点定义：配方法的本质与代数表达

- **定义本质**：配方法是化二次型为标准形（或规范形）的一种纯代数运算手段。通过中学阶段熟知的“完全平方公式”，将含有交叉项的二次型 $f(x) = \mathbf{x}^T A \mathbf{x}$ 强行凑配成只含平方项的独立多项式之和。
- **矩阵表达**：配方的过程，在代数上严格等价于对原变量 $\mathbf{x}$ 进行了一次**可逆线性变换 $\mathbf{x} = C\mathbf{y}$**。代入原二次型得到 $f(\mathbf{x}) = (C\mathbf{y})^T A (C\mathbf{y}) = \mathbf{y}^T(C^T A C)\mathbf{y} = \mathbf{y}^T B \mathbf{y}$，由于交叉项消失，此时的 $B$ 就是一个对角矩阵 $\Lambda$。

---

### 📐 几何意义与性质

- **几何直观（空间的非正交拉伸）**：与正交变换（相当于纯粹的旋转）不同，配方法代表的坐标系变换往往是非正交的（包含了切变和拉伸）。它同样能把歪斜的二次曲面“掰正”对齐坐标轴，但在这个过程中，原本坐标轴之间的夹角和刻度比例被改变了。
- **核心性质（合同非相似）**：配方法所对应的变换 $C^T A C = \Lambda$ **仅仅是合同变换，绝对不是相似变换！** 这意味着配方法只能保证“惯性定理”的成立（正负惯性指数 $p, q$ 不变），但**绝对不能保留特征值**。

---

### 📝 常用结论与计算流程（张宇解题套路）

面对具体二次型，张宇老师将配方法分为以下两种经典操作情境：

**套路一：有平方项的情况（优先处理）**

1. **集中变量**：若二次型中存在平方项（例如 $x_1^2$），则将所有含有 $x_1$ 的项（包括平方项和混合项）全部集中在一起。
2. **凑完全平方**：利用公式 $a^2 + 2ab + b^2 = (a+b)^2$，将其配成一个含有 $x_1$ 的完全平方项。
3. **循环往复**：对于剩余的变量（不含 $x_1$），继续寻找 $x_2$ 的平方项并集中配方，依此类推，直到所有交叉项被彻底消灭。

**套路二：无平方项、仅有交叉项的情况（先造平方项）**

1. **可逆替换（无中生有）**：若二次型中只有 $x_1x_2$ 这种交叉项，找不到任何一个平方项来作为配方的“抓手”。此时必须先做一个特殊的纯粹可逆替换：**令 $x_1 = y_1 + y_2, x_2 = y_1 - y_2$**。
2. **转化平方**：代入后，交叉项就变成了平方项：$x_1x_2 = (y_1+y_2)(y_1-y_2) = y_1^2 - y_2^2$。
3. **回归套路一**：有了平方项后，再按照上述“套路一”继续进行普通的配方操作。

**终极步骤：写出变换矩阵**

- 令所有配好的括号内部整体等于新变量 $y_i$（如 $y_1 = x_1 + 2x_2$），从而得到反向关系式 $\mathbf{y} = P\mathbf{x}$。
- **求逆矩阵**：对 $\mathbf{y} = P\mathbf{x}$ 求逆，得到正向变换公式 $\mathbf{x} = C\mathbf{y}$（其中 $C = P^{-1}$）。

### 🔄 跨章节关联分析

- **关联“矩阵的秩”**：二次型配方后化为标准形 $d_1 y_1^2 + \dots + d_n y_n^2$。根据合同等价性，**非零项的系数个数严格等于原矩阵 $A$ 的秩 $r(A)$**。
- **关联“矩阵合同的判定”**：在做选择题判断两个矩阵是否合同时，相比于求解复杂的特征值，直接用配方法快速得出两个二次型的正惯性指数 $p$ 和负惯性指数 $q$，只要 $p, q$ 一致必定合同。
- **关联“正定二次型”**：要判定一个二次型是否正定，若不用顺序主子式，直接用配方法将其化为标准形，只要**所有的平方项系数严格大于 0**，该二次型必定正定。

---

### ⚠️ 纠错警示（考场极其致命的陷阱）

1. **配出来的系数 $\neq$ 特征值（极度致命）**：**用配方法算出来的标准形系数 $d_i$，仅仅是凑出来的系数，它们只能用来判定正负惯性指数，绝对不是矩阵 $A$ 的特征值 $\lambda_i$！** 很多考生拿着配方法的结果去填“矩阵的特征值”，这是对“合同”与“相似”概念的严重混淆。
2. **变换矩阵不可逆陷阱**：在令新变量 $y_i$ 时，必须保证新旧变量的替换矩阵 $C$ 是**满秩可逆的（即 $|C| \neq 0$）**。如果你在配方中因为某个变量缺失，强行令诸如 $y_3 = 0$，导致矩阵降维，那么这个变换就变成了非法的非等价变换，整道题直接 0 分。
3. **正向替换与反向替换的混淆**：配方得到的括号内部通常是 $\mathbf{y}$ 用 $\mathbf{x}$ 表达（即 $\mathbf{y} = P\mathbf{x}$），但题目要求的标准合同变换矩阵 $C$ 是 $\mathbf{x} = C\mathbf{y}$ 中的 $C$。**千万记得最后要求一次逆矩阵 $C = P^{-1}$，不要把 $P$ 当成 $C$ 直接写上去！**
