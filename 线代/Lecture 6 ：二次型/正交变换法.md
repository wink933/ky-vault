### 📌 考点定义：什么是正交变换法？

- **数学定义**：对于 $n$ 元二次型 $f(x) = \mathbf{x}^T A \mathbf{x}$（$A$ 为实对称矩阵），寻找一个**正交矩阵 $Q$**（满足 $Q^T Q = E$，即 $Q^{-1} = Q^T$），作可逆线性替换 **$\mathbf{x} = Q\mathbf{y}$**。
- **代数结果**：代入后得到 $f = (Q\mathbf{y})^T A (Q\mathbf{y}) = \mathbf{y}^T (Q^T A Q) \mathbf{y} = \mathbf{y}^T \Lambda \mathbf{y}$。此时二次型被化为标准形：$f = \lambda_1 y_1^2 + \lambda_2 y_2^2 + \dots + \lambda_n y_n^2$。
    - 其中，对角阵 $\Lambda$ 上的元素 $\lambda_i$ 恰好是原实对称矩阵 $A$ 的特征值。

### 📐 几何意义与性质

- **几何直观（空间的纯粹旋转）**：与配方法导致坐标轴非等比例拉伸不同，正交变换 $\mathbf{x} = Q\mathbf{y}$ 代表对坐标系进行了一次**纯粹的旋转或镜像变换**（因为正交阵保长度、保夹角）。它将原本歪斜的二次曲面完美“掰正”，使曲面的对称轴与新的坐标轴完全重合，且不改变曲面原本的形状和大小。
- **双重身份（终极性质）**：由于正交矩阵满足 $Q^T = Q^{-1}$，故有 $Q^T A Q = Q^{-1} A Q = \Lambda$。这意味着正交变换**既是合同变换（保证了正负惯性指数绝对不变），又是相似变换（完美保留了所有特征值的具体数值）**。

### 📝 常用结论与典型计算流程（张宇标准化 5 步走）

在解答大题时，严格按照以下机械化步骤推进：

1. **求特征值 $\lambda$**：计算特征方程 $|\lambda E - A| = 0$，解出 $n$ 个特征值 $\lambda_1, \dots, \lambda_n$。
2. **求特征向量 $\xi$**：将每个特征值代入齐次线性方程组 $(\lambda_i E - A)\mathbf{x} = \mathbf{0}$，求出基础解系 $\xi_i$。
3. **正交化构造（施密特正交化）**：
    - 对于单根特征值对应的特征向量，保持不动。
    - 对于**多重特征值**算出的多个线性无关的特征向量，必须使用正交化公式将其化为两两正交的向量 $\eta_1, \eta_2 \dots$。
4. **单位化**：将所有正交化后的特征向量除以它们自身的模长（$|\eta|$），得到规范正交向量组 $\eta_1^*, \eta_2^*, \dots, \eta_n^*$。
5. **拼装写结论**：按列拼装成正交矩阵 $Q = [\eta_1^*, \eta_2^*, \dots, \eta_n^*]$。作正交变换 $\mathbf{x} = Q\mathbf{y}$，直接写出标准形 $f = \lambda_1 y_1^2 + \lambda_2 y_2^2 + \dots + \lambda_n y_n^2$。

### 🔄 跨章节关联分析

- **关联“矩阵的秩”**：正交变换化出的标准形中，非零平方项的个数（即非零特征值的个数）严格等于原矩阵 $A$ 的秩 $r(A)$。
- **关联“线性方程组”**：第二步求特征向量的过程，本质上就是求解齐次方程组的基础解系，多重根的重数必定等于自由变量的个数 $n - r(\lambda_i E - A)$。
- **关联“向量内积”**：第三步和第四步的底层支撑，正是第三讲向量组的内积运算与正交规范基的构造。

### 🎯 考题套路

- **套路一：化二次型为标准形（解答题压轴）**：直接给定含有交叉项的二次型，要求利用正交变换法求出 $Q$ 和标准形。必须严格展示正交化与单位化过程。
- **套路二：反求矩阵 $A$ 的元素**：题目告知二次型通过正交变换化为了特定的标准形（即暗中给出了特征值 $\lambda_i$），并给出部分特征向量。利用“实对称矩阵属于不同特征值的特征向量必然正交”这一性质，通过内积为 $0$ 反求未知参数。

### ⚠️ 纠错警示（考场极其致命的陷阱）

1. **单位化的遗漏陷阱（最易死穴）**：在算出正交的特征向量后，**极其容易忘记除以模长进行“单位化”！** 如果不单位化，拼出来的 $Q$ 根本就不是正交矩阵（$Q^T \neq Q^{-1}$），最后 $Q^T A Q = \Lambda$ 绝对不成立，整道大题的后半段直接 0 分。
2. **强行乱用正交化**：张宇老师再三强调，**只有“属于同一个多重特征值”的特征向量之间，才需要施密特正交化！** 实对称矩阵中，属于**不同**特征值的特征向量天然就是相互正交的。千万不要画蛇添足把所有特征向量混在一起做正交化，既浪费时间又容易算错。
3. **拼装 $Q$ 时列的对应顺序**：在构造正交矩阵 $Q$ 时，各列特征向量的排列顺序，**必须与你在标准形中书写的特征值 $\lambda_1, \lambda_2 \dots$ 顺序严格一一对应**，位置一旦错乱，变换等式即告失效。
