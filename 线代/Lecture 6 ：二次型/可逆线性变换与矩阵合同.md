### 📌 考点定义：可逆线性变换与合同

- **可逆线性变换**：对于 $n$ 元变量 $\mathbf{x} = (x_1, \dots, x_n)^T$ 和 $\mathbf{y} = (y_1, \dots, y_n)^T$，若存在关系式 **$\mathbf{x} = C\mathbf{y}$**，且矩阵 $C$ 满足 **$|C| \neq 0$（即 $C$ 是可逆矩阵）**，则称该变换为可逆线性变换。
- **矩阵合同的导出**：将二次型 $f(\mathbf{x}) = \mathbf{x}^T A \mathbf{x}$ 进行可逆线性变换 $\mathbf{x} = C\mathbf{y}$，代入可得： $$f(\mathbf{x}) = (C\mathbf{y})^T A (C\mathbf{y}) = \mathbf{y}^T (C^T A C) \mathbf{y} = \mathbf{y}^T B \mathbf{y} = g(\mathbf{y})$$ 记 $B = C^T A C$。
- **严格数学定义**：设 $A, B$ 为 $n$ 阶方阵，若存在**可逆矩阵 $C$**，使得 **$C^T A C = B$**，则称矩阵 $A$ 与 $B$ 合同，记作 **$A \simeq B$**。

---

### 📐 几何意义与核心性质

- **几何直观（换坐标系不改图态）**：可逆线性变换 $\mathbf{x} = C\mathbf{y}$ 本质上是空间坐标系的切换。因为变换矩阵 $C$ 可逆，说明空间没有发生“降维塌缩”。因此，原本闭合的曲面（如椭圆面）变换后依然是闭合的，原本发散的曲面（如双曲面）变换后依然发散。
- **合同等价关系**：合同是一种等价关系，完美满足反身性（$A \simeq A$）、对称性（$A \simeq B \implies B \simeq A$）和传递性（$A \simeq B, B \simeq D \implies A \simeq D$）。
- **合同的三大“不变量”**：
    1. **秩不变**：因为 $C$ 可逆，乘以可逆矩阵不改变矩阵的秩。故 **$A \simeq B \implies r(A) = r(B)$**。这意味着，**可逆线性变换绝对不会改变二次型的秩**。
    2. **对称性遗传**：在二次型中矩阵 $A$ 是对称矩阵（$A^T=A$）。由于 $B^T = (C^T A C)^T = C^T A^T C = C^T A C = B$，所以**与对称矩阵合同的矩阵也必定是对称矩阵**。
    3. **惯性定理（终极不变量）**：无论你选用哪种可逆线性变换（配方法还是正交变换），化出的标准形可能不同，但二次型的**正惯性指数 $p$ 和负惯性指数 $q$ 是绝对不变的**。

---

### 🔄 跨章节关联分析（三大矩阵关系终极串联）

张宇老师极度重视矩阵“等价、相似、合同”的横向对比：

- **关联“等价”**：合同必然等价（因为 $A \simeq B \implies r(A)=r(B)$，而秩相同是同型矩阵等价的充要条件）。
- **关联“相似”**：普通的合同与相似没有直接必然联系。合同满足 $C^TAC=B$，而相似满足 $P^{-1}AP=B$。
- **关联“正交矩阵”的特权**：如果我们选用的可逆线性变换矩阵 $C$ 是一个**正交矩阵 $Q$**（满足 $Q^T = Q^{-1}$），此时 $Q^T A Q = Q^{-1} A Q = \Lambda$。这说明：**实对称矩阵的正交变换，既是合同变换，又是相似变换！** 此时不仅正负惯性指数不变，连特征值也完美保留。

---

### 📝 考题套路与判定流程

- **套路一：判定两个实对称矩阵是否合同**
    - _核心判据_：两个同阶实对称矩阵（或二次型）合同的**充要条件**是：它们具有相同的**秩**和相同的**正（负）惯性指数**。
    - _做法_：不用去求 $C$！分别求出 $A$ 和 $B$ 的特征值，统计正特征值的个数（正惯性指数）和负特征值的个数（负惯性指数）。只要个数一致，它们必然合同。
- **套路二：求可逆线性变换矩阵 $C$**
    - _利用正交变换法_：求出特征向量并规范正交化，拼成的 $Q$ 就是可逆矩阵 $C$。
    - _利用配方法_：将 $x_1, x_2, \dots$ 凑成完全平方项 $y_1, y_2, \dots$，写出 $\mathbf{x} = C\mathbf{y}$ 的矩阵形式，这个 $C$ 即为所求。

---

### ⚠️ 纠错警示（考场极其致命的陷阱）

1. **$C$ 的可逆性陷阱（一票否决）**：无论是写配方法还是其他变换，**必须保证你写出的替换矩阵 $C$ 满秩（即 $|C| \neq 0$）！** 如果你用降维的替换（如强行令 $x_1 = 0$），导致二次型的秩减少，这就绝不再是合同变换，此题直接 0 分。
2. **相似与合同的混淆陷阱**：合同矩阵 **$C^T A C = B$** 仅仅保证了空间的“惯性状态”一致，**绝对不保证特征值相同！** 千万不要认为合同矩阵的特征值一样，只有发生相似变换（如乘以正交阵）时特征值才不变。
3. **转置运算穿针引线的遗漏**：在证明合同矩阵对称性时，展开 $(C^TAC)^T$，必须利用穿针引线法倒序写出 $C^TA^T(C^T)^T$。这是大题理论推导的基本功，绝不可跳步。
