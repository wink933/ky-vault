这确实是一个非常严谨的好问题。很多同学在考研复习时只会背这个“两两相乘”的结论，但一旦遇到证明题（特别是像你图片中这种 $\vert{}A\vert{}=0$ 的情况），就会因为无法使用 $A^{-1}$ 而束手无策。

为了做到在考场上无懈可击，我们必须将证明分为**两种情况**来进行“外科手术式”的拆解。以 $3$ 阶方阵 $A$ 为例，设其特征值为 $\lambda_1, \lambda_2, \lambda_3$。

### 情形一：当矩阵可逆时（$\vert{}A\vert{} \neq 0$）

这是最简单、最常规的情况。此时 $A$ 的三个特征值全都不为 $0$。

**证明过程：**

1. 设 $\lambda$ 是 $A$ 的任一特征值，$x$ 是对应的特征向量（$x \neq 0$）。
    
    根据定义有：$Ax = \lambda x$。
    
2. 因为 $\vert{}A\vert{} \neq 0$，所以 $A$ 可逆，$A^{-1}$ 存在，且 $\lambda \neq 0$。
    
    等式两边同乘 $A^{-1}$：
    
    $$x = \lambda A^{-1} x \implies A^{-1} x = \frac{1}{\lambda} x$$
    
    这说明 $A^{-1}$ 的特征值是 $\frac{1}{\lambda}$。
    
3. 根据伴随矩阵的基本公式 $AA^* = \vert{}A\vert{}E$，在等式两边同乘 $A^{-1}$ 可得：
    
    $$A^* = \vert{}A\vert{} A^{-1}$$
    
4. 用这个公式去乘特征向量 $x$：
    
    $$A^* x = (\vert{}A\vert{} A^{-1}) x = \vert{}A\vert{} (A^{-1} x) = \vert{}A\vert{} \cdot \frac{1}{\lambda} x = \frac{\vert{}A\vert{}}{\lambda} x$$
    
5. 因为矩阵 $A$ 的行列式等于所有特征值之积，即 $\vert{}A\vert{} = \lambda_1 \lambda_2 \lambda_3$。
    
    - 当 $\lambda = \lambda_1$ 时，$A^*$ 的特征值为 $\frac{\lambda_1 \lambda_2 \lambda_3}{\lambda_1} = \lambda_2 \lambda_3$
        
    - 当 $\lambda = \lambda_2$ 时，$A^*$ 的特征值为 $\frac{\lambda_1 \lambda_2 \lambda_3}{\lambda_2} = \lambda_1 \lambda_3$
        
    - 当 $\lambda = \lambda_3$ 时，$A^*$ 的特征值为 $\frac{\lambda_1 \lambda_2 \lambda_3}{\lambda_3} = \lambda_1 \lambda_2$
        

**结论：** 结论完美成立。

### 情形二：当矩阵不可逆时（$\vert{}A\vert{} = 0$）—— 对应你图片中的考法

此时 $A^{-1}$ 根本不存在，情形一的证明方法直接失效！这也是考研命题人最喜欢挖坑的地方。我们需要动用“特征多项式与矩阵的迹”来降维打击。

已知 $\vert{}A\vert{} = 0$，说明 $A$ 至少有一个特征值为 $0$。不妨设 **$\lambda_3 = 0$**。

**证明过程：**

1. **分析 $A^*$ 的秩（寻找 $0$ 特征值）：**
    
    - 因为 $\vert{}A\vert{}=0$，所以 $A$ 的秩 $r(A) \le 2$。
        
    - 根据伴随矩阵秩的定理：当 $r(A) < n$ 时，$r(A^*) \le 1$。
        
    - 对于 $3$ 阶矩阵 $A^*$ 而言，它的秩最多是 $1$。这意味着，**$A^*$ 至少有 $3-1=2$ 个特征值是 $0$。**
        
2. **分析 $A^*$ 的迹（寻找非零特征值）：**
    
    - 我们知道，矩阵特征值之和等于矩阵的迹（主对角线元素之和）：$\sum \lambda = tr(A^*)$。
        
    - $A^*$ 的主对角线元素分别是 $A_{11}, A_{22}, A_{33}$（即原矩阵 $A$ 的三个主子式）。所以 $tr(A^*) = A_{11} + A_{22} + A_{33}$。
        
    - 根据韦达定理（或者特征多项式展开定理），原矩阵 $A$ 的所有二阶主子式之和，等于其特征值两两乘积之和：
        
        $$A_{11} + A_{22} + A_{33} = \lambda_1\lambda_2 + \lambda_1\lambda_3 + \lambda_2\lambda_3$$
        
3. **完美拼合：**
    
    因为我们已知 $\lambda_3 = 0$，代入上面的韦达定理公式：
    
    $$tr(A^*) = \lambda_1\lambda_2 + \lambda_1(0) + \lambda_2(0) = \lambda_1\lambda_2$$
    
    现在我们来清点一下 $A^*$ 的三个特征值：
    
    - 前面由秩的性质得知，$A^*$ 至少有两个特征值是 $0, 0$。
        
    - 三个特征值之和必须等于 $tr(A^*)$，即 $\lambda_1\lambda_2$。
        
    - 显然，第三个特征值只能是 $\lambda_1\lambda_2$。
        

**结论：**

$A^*$ 的三个特征值被严格锁定为 **$0, 0, \lambda_1\lambda_2$**。

你回头对比一下“两两相乘”法则：$\lambda_2\lambda_3=0$，$\lambda_1\lambda_3=0$，$\lambda_1\lambda_2$。两者分毫不差！

这也就是为什么在你图片中，原矩阵特征值为 $\mu, \mu, 0$ 时，伴随矩阵的特征值会直接变成 $0, 0, \mu^2$ 的底层数学逻辑。
