图片中的这三条性质是线性代数（尤其是二次型）的“定海神针”。在考研数学中，实对称矩阵之所以拥有如此高的地位，正是因为这三条极其优美的性质。

为了让你在考场上不仅能背下来，还能彻底看透它们的底层逻辑，我们像做“外科手术”一样，对这三条性质逐一进行严密的推导和证明。

### 性质 (1)：特征值必为实数

**命题核心：** 为什么实对称矩阵不会像普通矩阵那样出现复数特征值？（关于“几何重数等于代数重数”的证明涉及到较深的谱定理（Spectral Theorem），通常在基础阶段作为公理接受，但“特征值必为实数”是可以严格证明的。）

**证明过程：**

设 $\lambda$ 是实对称矩阵 $A$ 的一个特征值，$x$ 是对应的特征向量（注意，在未证明之前，我们需要假设 $\lambda$ 和 $x$ 可能是复数/复向量）。

根据特征值定义：

$$Ax = \lambda x$$

1. 对等式两边同时取**共轭转置**（记为 $\bar{x}^T$ 和 $\bar{A}^T$）。因为 $A$ 是实对称矩阵，所以 $\bar{A} = A$，且 $A^T = A$。因此 $\bar{A}^T = A$。
    
    等式左边变为：$\bar{x}^T A$
    
    等式右边变为：$\bar{\lambda} \bar{x}^T$
    
    所以有：$\bar{x}^T A = \bar{\lambda} \bar{x}^T$
    
2. 在上述新等式两边同时**右乘**原特征向量 $x$：
    
    $$\bar{x}^T A x = \bar{\lambda} \bar{x}^T x$$
    
3. 另一方面，我们在原定义等式 $Ax = \lambda x$ 两边同时**左乘** $\bar{x}^T$：
    
    $$\bar{x}^T A x = \lambda \bar{x}^T x$$
    
4. 观察步骤 2 和步骤 3 的等式左边，完全一样！因此它们的右边也必然相等：
    
    $$\bar{\lambda} \bar{x}^T x = \lambda \bar{x}^T x$$
    
    即：
    
    $$(\bar{\lambda} - \lambda) \bar{x}^T x = 0$$
    
5. 因为 $x$ 是特征向量（非零向量），所以它与自己的共轭转置的内积 $\bar{x}^T x = \vert{}x_1\vert{}^2 + \vert{}x_2\vert{}^2 + \dots + \vert{}x_n\vert{}^2 > 0$。
    
    要使乘积为 $0$，只能是前面的系数为 $0$：
    
    $$\bar{\lambda} - \lambda = 0 \implies \bar{\lambda} = \lambda$$
    
    一个数等于它的共轭，说明 **$\lambda$ 必定是实数**。
    

### 性质 (2)：不同特征值对应的特征向量必正交（考研极高频考点）

**命题核心：** 若 $\lambda_1 \neq \lambda_2$，则对应的特征向量 $x_1, x_2$ 满足 $x_1^T x_2 = 0$。

**证明过程（极其精妙的“转置转移”法）：**

已知 $Ax_1 = \lambda_1 x_1$，$Ax_2 = \lambda_2 x_2$，且 $A^T = A$。

我们构造一个标量乘法 $\lambda_1 x_1^T x_2$，并对其进行变形：

1. 将常数 $\lambda_1$ 放进括号里：
    
    $$\lambda_1 x_1^T x_2 = (\lambda_1 x_1)^T x_2$$
    
2. 替换特征值定义式：
    
    $$= (Ax_1)^T x_2$$
    
3. 利用转置穿脱原则：
    
    $$= x_1^T A^T x_2$$
    
4. **最关键的一步，代入实对称条件 $A^T = A$：**
    
    $$= x_1^T A x_2$$
    
5. 重新结合，利用 $Ax_2 = \lambda_2 x_2$：
    
    $$= x_1^T (Ax_2) = x_1^T (\lambda_2 x_2)$$
    
6. 把常数 $\lambda_2$ 提出来：
    
    $$= \lambda_2 x_1^T x_2$$
    

我们将首尾连起来，得到了一个方程：

$$\lambda_1 x_1^T x_2 = \lambda_2 x_1^T x_2$$

移项得：

$$(\lambda_1 - \lambda_2) x_1^T x_2 = 0$$

题目已知 $\lambda_1 \neq \lambda_2$，所以 $\lambda_1 - \lambda_2 \neq 0$。那么必然得出：

$$x_1^T x_2 = 0$$

即向量 $x_1$ 与 $x_2$ 正交，证明完毕。

### 性质 (3)：正交相似对角化的充要条件

这部分包含了两个方向：“能正交相似对角化的实矩阵一定是实对称阵”（倒推） 和 “实对称阵一定能正交相似对角化”（正推）。

#### 倒推证明（极其简单，必会）：

**命题：** 若存在正交阵 $Q$ 使得 $Q^{-1}AQ = \Lambda$（对角阵），则 $A$ 必为实对称阵（即 $A^T = A$）。

**证明过程：**

1. 已知 $Q^{-1}AQ = \Lambda$，在等式两边左乘 $Q$，右乘 $Q^{-1}$，解出 $A$：
    
    $$A = Q \Lambda Q^{-1}$$
    
2. 因为 $Q$ 是正交阵，所以 $Q^{-1} = Q^T$，代入上式：
    
    $$A = Q \Lambda Q^T$$
    
3. 对 $A$ 整体求转置：
    
    $$A^T = (Q \Lambda Q^T)^T$$
    
4. 利用穿脱原则展开：
    
    $$A^T = (Q^T)^T \Lambda^T Q^T$$
    
5. 因为 $(Q^T)^T = Q$，且对角矩阵的转置等于其本身（$\Lambda^T = \Lambda$）：
    
    $$A^T = Q \Lambda Q^T = A$$
    
    证毕。只要能正交对角化，它就必定是实对称矩阵。
    

#### 正推逻辑梳理：

**命题：** 实对称阵 $A$ 必可正交相似对角化。

这个证明是将前面的性质综合起来的**算法流程**：

1. 因为是实对称阵，由性质(1)可知，它一定有 $n$ 个实特征值，且不管有没有重根，都能找齐 $n$ 个线性无关的特征向量（代数重数=几何重数）。
    
2. 由性质(2)可知，属于**不同特征值**的特征向量已经是天然正交的了。
    
3. 对于属于**同一个特征值**的多个特征向量（即存在重根时），我们只需要对这一组内部的向量使用 **施密特（Gram-Schmidt）正交化** 即可。因为特征子空间内的任何线性组合仍然是特征向量，所以正交化后的向量依然是特征向量。
    
4. 最后，把所有这 $n$ 个相互正交的特征向量**单位化**，按列拼在一起，就构成了一个正交矩阵 $Q$。
    
5. 此时必然满足 $Q^{-1}AQ = Q^TAQ = \Lambda$。
