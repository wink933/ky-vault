这几条充分条件是考研线性代数解答题中用来“定性分析”的顶级工具。你图片中红笔标注的“直接用”非常正确，在考场上遇到它们，直接写结论即可，无需现场证明。

但为了让你用得踏实、底气十足，我们依然采用“外科手术式”的推导，把你划线的这几个充分条件的底层逻辑彻底打通。

### 1. 证明：$A$ 有 $n$ 个不同的特征值 $\Rightarrow A \sim \Lambda$

**核心逻辑：** 属于不同特征值的特征向量必定线性无关。

**证明过程（反证法与归纳法结合）：**

假设矩阵 $A$ 有 $m$ 个互不相同的特征值 $\lambda_1, \lambda_2, \dots, \lambda_m$，对应的特征向量为 $p_1, p_2, \dots, p_m$。

我们要证明这 $m$ 个向量线性无关。

当 $m=1$ 时，特征向量非零，自然线性无关。

假设当 $m=k-1$ 时，这些特征向量线性无关。现在考察 $m=k$ 的情况，设存在一组系数 $c_i$ 使得：

$$c_1p_1 + c_2p_2 + \dots + c_kp_k = 0 \quad \text{(式 1)}$$

等式两边同乘矩阵 $A$（利用 $Ap_i = \lambda_i p_i$）：

$$c_1\lambda_1p_1 + c_2\lambda_2p_2 + \dots + c_k\lambda_kp_k = 0 \quad \text{(式 2)}$$

为了消去最后一个向量，将 (式 1) 两边同乘 $\lambda_k$，并与 (式 2) 相减：

$$c_1(\lambda_1 - \lambda_k)p_1 + c_2(\lambda_2 - \lambda_k)p_2 + \dots + c_{k-1}(\lambda_{k-1} - \lambda_k)p_{k-1} = 0$$

因为假设前 $k-1$ 个向量是线性无关的，所以它们前面的系数必须全部为 0。

又因为特征值互不相同，即对于任意 $i \neq k$，都有 $(\lambda_i - \lambda_k) \neq 0$。

所以必然得出：$c_1 = c_2 = \dots = c_{k-1} = 0$。

把这些 0 代回 (式 1)，得到 $c_k p_k = 0$。因为特征向量 $p_k \neq 0$，所以 $c_k = 0$。

**结论：** 当有 $n$ 个不同的特征值时，必定能找到 $n$ 个线性无关的特征向量。完美满足相似对角化的充要条件，故 $A \sim \Lambda$。

### 2. 证明：$A$ 为实对称矩阵 $\Rightarrow A \sim \Lambda$

**核心逻辑：** 正如你图片中红笔标注的一针见血——**“实对称矩阵的几何重数 = 代数重数”**。

**证明框架：**

实对称矩阵必可对角化（不仅是相似对角化，还能**正交相似对角化**），这是由高等代数中的谱定理（Spectral Theorem）严格保证的。它的核心逻辑链条如下：

1. **特征值必为实数：** 我们之前已经证明过，排除了复数域的干扰。
    
2. **不同特征值的特征向量正交：** 保证了不同特征子空间是互相垂直、绝对独立的。
    
3. **重根不缺失维度（最关键）：** 即使存在 $k$ 重根，实对称矩阵的性质也能保证齐次方程组 $(\lambda E - A)x = 0$ 的秩一定为 $n - k$。这意味着基础解系必定恰好有 $k$ 个线性无关的解向量。
    
    **结论：** 没有任何一个特征值会“吃回扣”。所有特征值的几何重数都等满代数重数，把基底拼起来刚好凑齐 $n$ 个，因此必定可以对角化。
    

### 3. 证明：$r(A)=1$ 且 $tr(A) \neq 0 \Rightarrow A \sim \Lambda$

**核心逻辑：** 利用矩阵的“秩”锁定 0 特征值的数量，利用“迹”锁定非零特征值，从而证明不会出现缺陷。

**证明过程：**

1. **锁定 $\lambda = 0$ 的重数：**
    
    已知 $r(A) = 1$，求解齐次线性方程组 $Ax=0$ 时，基础解系的个数为 $n - r(A) = n - 1$ 个。
    
    这意味着，$\lambda = 0$ 是特征值，且能找出 $n-1$ 个线性无关的特征向量（**几何重数为 $n-1$**）。
    
    由于代数重数必须 $\ge$ 几何重数，所以 $0$ 至少是 $n-1$ 重根。
    
2. **锁定最后一个特征值：**
    
    我们知道，矩阵所有特征值之和等于迹。设最后一个特征值为 $\lambda_n$：
    
    $$0 + 0 + \dots + 0 + \lambda_n = tr(A) \implies \lambda_n = tr(A)$$
    
3. **对角化生死线判定：**
    
    题目明确给出 **$tr(A) \neq 0$**，说明最后一个特征值 $\lambda_n$ 不是 0，它是一个单根。
    
    - 单根 $tr(A)$：代数重数为 1，几何重数必然为 1。
        
    - 重根 $0$：代数重数为 $n-1$，第一步已证其几何重数也是 $n-1$。
        
        **结论：** 所有特征值的几何重数 = 代数重数。共凑齐 $(n-1) + 1 = n$ 个线性无关的特征向量，故 $A \sim \Lambda$。
        

_(注：如果你把那个 $\neq 0$ 的条件去掉，变成 $tr(A)=0$，那 0 就变成了 $n$ 重根，代数重数为 $n$，但几何重数只有 $n-1$，此时就绝对不能对角化了。)_

### 4. 证明：$(A-aE)(A-bE)=0$ 且 $a \neq b \Rightarrow A \sim \Lambda$

这个多项式的证明，我们在上一次对话中利用“空间分解法”做过非常严密的硬核拆解，这里为你总结它的本质。

**本质逻辑：**

不需要去硬算特征向量，而是通过恒等变形 $E = \frac{1}{a-b}(A-bE) - \frac{1}{a-b}(A-aE)$ 证明：**整个 $n$ 维空间中的任意一个向量，都可以被拆分为属于特征值 $a$ 的特征向量与属于特征值 $b$ 的特征向量之和。**

既然特征向量能撑满整个 $n$ 维空间，那肯定存在 $n$ 个线性无关的特征向量。

**特别推论的秒杀：**

图中最下方的“特别地”是考研最爱出的两种题型：

- **幂等矩阵 $A^2 = A$：** 移项得 $A^2 - A = 0$，即 $(A-E)(A-0E) = 0$。对应 $a=1, b=0$（且 $1 \neq 0$），所以必可对角化。
    
- **对合矩阵 $A^2 = E$：** 移项得 $A^2 - E = 0$，即 $(A-E)(A+E) = 0$。对应 $a=1, b=-1$（且 $1 \neq -1$），所以必可对角化。
