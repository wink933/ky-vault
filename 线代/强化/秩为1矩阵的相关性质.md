这张图片总结的是线性代数中一个极其核心、堪称“秒杀利器”的专属模型：**秩为 1 的矩阵（即 $A = \alpha \beta^T$ 型矩阵）**。

在应对高强度的线代综合题时，一旦看到矩阵是由两个非零列向量相乘构造而成（或者算出矩阵的秩为 1），脑海中必须立刻条件反射出图片里的这三条性质。

我们来对这三条性质进行“外科手术式”的底层逻辑拆解：

### 核心大前提：认清内外积的本质差异

设 $\alpha, \beta$ 都是 $n$ 维非零列向量（$n \times 1$）。

- **外积 $\alpha \beta^T$：** 得到的是一个 $n \times n$ 的方阵 $A$。它的每一列都是 $\alpha$ 的倍数，每一行都是 $\beta^T$ 的倍数，因此其**秩必然为 1**。
    
- **内积 $\beta^T \alpha$（或 $\alpha^T \beta$）：** 得到的是一个 $1 \times 1$ 的矩阵，本质上就是一个**标量（常数）**。我们设这个常数为 $l$。
    

### (1) 为什么 $tr(A) = \alpha^T \beta = \beta^T \alpha = l$？

**证明逻辑：**

1. **从代数定义看：** 矩阵的迹 $tr(A)$ 是主对角线元素之和。
    
    已知 $A = \alpha \beta^T$，按照矩阵乘法展开，主对角线上的元素依次是 $a_1b_1, a_2b_2, \dots, a_nb_n$。
    
    所以，$\sum a_{ii} = a_1b_1 + a_2b_2 + \dots + a_nb_n$。
    
2. **从内积定义看：** 列向量的内积 $\alpha^T \beta$ 或 $\beta^T \alpha$ 的计算公式，恰好也是 $a_1b_1 + a_2b_2 + \dots + a_nb_n$。
    
3. **从迹的高阶性质看：** 矩阵的迹满足交换律 $tr(XY) = tr(YX)$。
    
    $$tr(A) = tr(\alpha \beta^T) = tr(\beta^T \alpha)$$
    
    由于 $\beta^T \alpha$ 算出来就是一个 $1 \times 1$ 的标量 $l$，一个标量的迹当然就是它自己。
    

**结论：** 秩为 1 矩阵的迹，就等于构造它的那两个向量的内积。这个数字 $l$ 是后续所有推导的灵魂。

### (2) 为什么 $A^n = l^{n-1}A$？

**证明逻辑：**

图片中已经给出了非常精彩的代数证明。其核心技巧是利用矩阵乘法结合律，**在中间把“标量”捏出来**。

1. 计算 $A^2$：
    
    $$A^2 = (\alpha \beta^T)(\alpha \beta^T)$$
    
2. 利用结合律，重新加括号：
    
    $$A^2 = \alpha (\beta^T \alpha) \beta^T$$
    
3. 重点来了！中间的 **$(\beta^T \alpha)$ 就是我们第一步推导出的常数 $l$**。常数是可以随意挪动位置的，把它提出来：
    
    $$A^2 = \alpha (l) \beta^T = l (\alpha \beta^T) = lA$$
    
    即：$A^2 = tr(A) \cdot A$。
    
4. 依次类推：
    
    $$A^3 = A^2 \cdot A = (lA) \cdot A = lA^2 = l(lA) = l^2 A$$
    
    归纳可得：$A^n = l^{n-1} A$。
    

**实战意义：** 求这类矩阵的高次幂，不需要苦哈哈地硬乘，找准主对角线之和 $l$ 即可瞬间降维。

### (3) 特征值与可否相似对角化判定（最核心考点）

对于秩为 1 的 $n$ 阶方阵 $A = \alpha \beta^T$：

**1. 特征值的确定：**

- **找 0 特征值：** 因为 $r(A) = 1$，齐次方程组 $Ax=0$ 的基础解系含有 $n - r(A) = n - 1$ 个线性无关的解向量。这意味着，方程组有 $n-1$ 个线性无关的非零解满足 $Ax = 0 \cdot x$。
    
    因此，$\lambda = 0$ 是矩阵 $A$ 的特征值，且其**几何重数为 $n-1$**。对应地，它至少是一个 $n-1$ 重根。
    
- **找非零特征值：** 矩阵全部特征值之和等于矩阵的迹。
    
    $$\sum \lambda_i = \lambda_1 + 0 + \dots + 0 = tr(A)$$
    
    所以，最后一个特征值必定是 $tr(A)$。
    
- **结论：** $A$ 的 $n$ 个特征值永远是：$tr(A), 0, 0, \dots, 0$。
    

**2. 为什么非零特征值对应的特征向量是 $\alpha$？**

我们直接验证一下：用矩阵 $A$ 乘以列向量 $\alpha$：

$$A \alpha = (\alpha \beta^T) \alpha = \alpha (\beta^T \alpha) = \alpha (l) = l \alpha = tr(A) \alpha$$

完美契合特征值定义式 $Ax = \lambda x$！所以 $\alpha$ 就是特征值 $tr(A)$ 对应的特征向量。

**3. 对角化判定的“生死线”：**

矩阵能否对角化，取决于每个特征值的几何重数是否等于代数重数。

- **若 $tr(A) \neq 0$：**
    
    此时特征值分为两类：单根 $tr(A)$ 和 $n-1$ 重根 $0$。
    
    $0$ 这个特征值的代数重数是 $n-1$，前面分析过它的几何重数也是 $n - 1$（因为 $r(A)=1$）。两者相等，所以**必然可以对角化**（$A \sim \Lambda$）。
    
- **若 $tr(A) = 0$：**
    
    此时特征值全都是 $0$（即 $0$ 是 $n$ 重根，代数重数为 $n$）。
    
    但是，它的几何重数依然是 $n - 1$（只要 $\alpha, \beta$ 不是零向量，秩依然是 1）。
    
    几何重数 $(n-1) <$ 代数重数 $(n)$。出现了“编制给满，人员招不齐”的缺陷情况，因此**绝对不能对角化**（$A \nsim \Lambda$）。
    

把这个 $A = \alpha \beta^T$ 模型吃透，遇到线代解答题中相关的秩、幂次、对角化问题，完全可以做到降维打击，一眼看穿出题人的底牌。
