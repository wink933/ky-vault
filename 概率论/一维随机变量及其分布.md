《概率论与数理统计》第二章“一维随机变量及其分布”主要围绕随机变量的概念、分布函数、常见的离散型与连续型分布以及随机变量函数的分布展开。以下为您提炼的核心知识点：

### 一、 随机变量与分布函数

- **随机变量的概念**：在样本空间 $\Omega$ 上定义的实值单值函数 $X=X(e)$ 称为随机变量，其本质是将随机事件的数量化表示。
- **分布函数的定义**：设 $X$ 是一个随机变量，对于任意实数 $x$，令 $F(x) = P{X \le x}$，则称 $F(x)$ 为随机变量 $X$ 的分布函数。它可以用来计算随机变量落在任意区间的概率：$P{a < X \le b} = F(b) - F(a)$。
- **分布函数的四大性质**：一个函数能否成为分布函数的充要条件是满足以下四条性质：
    1. **非负性**：$0 \le F(x) \le 1$。
    2. **规范性**：$\lim_{x \to -\infty} F(x) = 0$，$\lim_{x \to +\infty} F(x) = 1$。
    3. **单调不减性**：对于任意 $x_1 < x_2$，有 $F(x_1) \le F(x_2)$。
    4. **右连续性**：$F(x_0) = F(x_0 + 0)$。

### 二、 一维离散型随机变量及其分布

- **定义与分布律**：若随机变量 $X$ 的取值是有限个或可列无穷多个，则称为离散型随机变量。其概率分布（分布律）记为 $P{X = x_k} = p_k$，必须满足非负性（$p_k \ge 0$）和归一性（$\sum p_k = 1$）。
- **四大常见离散型分布**：
    1. **0-1分布**：随机变量仅取 0 或 1 两个值，$P{X=k} = p^k (1-p)^{1-k}$。
    2. **二项分布 $X \sim B(n, p)$**：背景是 $n$ 次独立重复试验（伯努利试验），每次成功的概率为 $p$，求成功次数 $X$ 的概率：$P{X=k} = C_n^k p^k (1-p)^{n-k}$。
    3. **泊松分布 $X \sim P(\lambda)$**：$P{X=k} = \frac{\lambda^k e^{-\lambda}}{k!}$。**泊松定理**指出，当二项分布中 $n$ 较大、$p$ 较小时，可用泊松分布近似替代二项分布进行计算，此时取 $\lambda \approx np$。
    4. **几何分布 $X \sim G(p)$**：背景为做独立重复试验，表示直到成功为止一共需要进行的试验次数 $X$，公式为 $P{X=k} = (1-p)^{k-1}p$。

### 三、 一维连续型随机变量及其分布

- **定义与概率密度**：若存在非负可积函数 $f(x)$，使得 $F(x) = \int_{-\infty}^{x} f(t)dt$，则称 $X$ 为连续型随机变量，$f(x)$ 为其概率密度函数。
- **概率密度的性质**：
    1. 非负性：$f(x) \ge 0$。
    2. 规范性：$\int_{-\infty}^{+\infty} f(x)dx = 1$。
    3. 连续型随机变量在任意个别点取值的概率为 $0$，因而区间的开闭不影响概率大小：$P{a \le X \le b} = P{a < X < b} = \int_{a}^{b} f(x)dx$。
- **三大常见连续型分布**：
    1. **均匀分布 $X \sim U(a, b)$**：在区间 $(a,b)$ 内的密度函数恒为常数 $\frac{1}{b-a}$。计算概率时，可直接用子区间的有效长度除以总长度得到。
    2. **指数分布 $X \sim E(\lambda)$**：密度函数为 $f(x) = \lambda e^{-\lambda x} (x>0)$。该分布具有**无记忆性**，即 $P{X > s+t | X > s} = P{X > t}$。
    3. **正态分布 $X \sim N(\mu, \sigma^2)$**：其密度函数曲线呈钟形，关于 $x=\mu$ 对称。当 $\mu=0, \sigma=1$ 时称为标准正态分布 $N(0,1)$，分布函数记为 $\Phi(x)$，且满足对称性性质 $\Phi(-x) = 1 - \Phi(x)$。一般正态分布可以通过**标准化**变换 $Z = \frac{X-\mu}{\sigma} \sim N(0,1)$ 转化为标准正态分布进行查表或计算。

### 四、 一维随机变量函数的分布

- **离散型函数分布**：若已知离散型随机变量 $X$ 的分布律，求 $Y = g(X)$ 的分布律时，只需要将 $X$ 的取值代入函数求出 $Y$ 的取值；若不同的 $X$ 算出了相同的 $Y$ 值，则将它们对应的概率相加即可。
- **连续型函数分布（分布函数法）**：求连续型随机变量函数 $Y = g(X)$ 的概率密度，通常使用分布函数法。
    1. 先求 $Y$ 的分布函数：$F_Y(y) = P{Y \le y} = P{g(X) \le y}$。
    2. 将不等式转化为 $X$ 的范围，通过对 $X$ 的概率密度 $f_X(x)$ 积分求出 $F_Y(y)$。
    3. 最后对 $F_Y(y)$ 关于 $y$ 求导，得到 $Y$ 的密度函数 $f_Y(y) = F'_Y(y)$。
