在概率论中，求两个连续型随机变量之和 $Z = X + Y$ 的概率密度函数，是我们在考研和期末考试中最常遇到的题型之一。最终推导出来的结果就是著名的**卷积公式**。

我们依旧秉持之前建立的“黄金法则”：**要求密度函数，先求分布函数，然后再求导。**

下面我们一步步进行详细推导。

### 第一步：写出 $Z$ 的分布函数 $F_Z(z)$

根据分布函数的定义，$Z$ 的分布函数表示随机变量 $Z$ 小于等于某个具体数值 $z$ 的概率：

$$F_Z(z) = P(Z \le z) = P(X + Y \le z)$$

### 第二步：将概率转化为二重积分

现在问题变成了：求二维随机向量 $(X,Y)$ 落在区域 $X + Y \le z$ 内的概率。

设 $X$ 和 $Y$ 的联合概率密度函数为 $f(x,y)$。根据二维随机变量求概率的法则，我们需要在积分区域 $D: x + y \le z$ 上对 $f(x,y)$ 进行二重积分。

我们将这个区域写成先对 $y$ 积分、后对 $x$ 积分的形式（即画垂直于 $x$ 轴的竖线）：

- $x$ 的范围是全体实数：$(-\infty, +\infty)$
    
- 固定 $x$ 时，$y$ 的上限受限于 $x + y \le z$，即 $y \le z - x$。所以 $y$ 的范围是 $(-\infty, z-x]$。
    

写成累次积分式：

$$F_Z(z) = \iint_{x+y \le z} f(x,y) dx dy = \int_{-\infty}^{+\infty} \left( \int_{-\infty}^{z-x} f(x,y) dy \right) dx$$

### 第三步：巧妙的换元法（核心步骤）

为了接下来求导方便，我们希望把积分上限中的变量 $z$ 提取出来。我们对内层积分（关于 $y$ 的积分）进行变量代换。

令 $v = x + y$，因为此时是对 $y$ 积分（视 $x$ 为常数），所以有：

- $y = v - x$
    
- 微元代换：$dy = dv$
    
- 积分限代换：当 $y \to -\infty$ 时，$v \to -\infty$；当 $y = z-x$ 时，$v = (z-x) + x = z$。
    

将这些代入原来的积分式中，内层积分变成了关于 $v$ 的积分：

$$F_Z(z) = \int_{-\infty}^{+\infty} \left( \int_{-\infty}^{z} f(x, v-x) dv \right) dx$$

根据微积分中交换积分次序的定理（Fubini定理），我们把对 $v$ 的积分调到外层：

$$F_Z(z) = \int_{-\infty}^{z} \left( \int_{-\infty}^{+\infty} f(x, v-x) dx \right) dv$$

### 第四步：变上限积分求导得出密度函数

现在，大功告成！我们有了 $Z$ 的分布函数，要求其概率密度 $f_Z(z)$，只需对 $F_Z(z)$ 关于 $z$ 求导。

观察上式，最外层正好是一个以 $z$ 为上限的积分。根据“变上限积分求导法则”，对它求导就是直接把上限 $z$ 替换掉积分变量 $v$：

$$f_Z(z) = \frac{d}{dz} F_Z(z) = \int_{-\infty}^{+\infty} f(x, z-x) dx$$

这就是一般情况下的**和的密度函数公式**。

> _(注：同理，如果你在第二步先对 $x$ 积分，最后推导出来的公式就是 $f_Z(z) = \int_{-\infty}^{+\infty} f(z-y, y) dy$，两者完全等价。)_

### 第五步：引入“独立性”得出最终的卷积公式

上面的公式适用于任何情况。但在实际应用中，绝大多数题目都会附带一个条件：**$X$ 和 $Y$ 相互独立**。

如果 $X$ 和 $Y$ 相互独立，那么它们的联合密度函数等于边缘密度函数的乘积：

$$f(x,y) = f_X(x)f_Y(y)$$

把这个关系代入第四步的结果中，$f(x, z-x)$ 就可以拆解为 $f_X(x)f_Y(z-x)$。

于是我们得到了最终的**卷积公式**：

$$f_Z(z) = \int_{-\infty}^{+\infty} f_X(x)f_Y(z-x) dx$$

**物理意义的直观理解：**

为了让 $X+Y$ 刚好等于目标值 $z$，如果 $X$ 占据了 $x$ 的份额，那么 $Y$ 就必须“死死咬住”剩下的 $(z-x)$ 的份额。因为它们独立，所以这种组合发生的概率密度是 $f_X(x) \cdot f_Y(z-x)$。最后，把 $X$ 可能取到的所有 $x$ 的情况（从 $-\infty$ 到 $+\infty$）全部累加（积分）起来，就得到了 $Z=z$ 的总概率密度。
