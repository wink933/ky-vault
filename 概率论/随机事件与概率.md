《概率论与数理统计》第一章“随机事件和概率”主要围绕事件的关系与运算、概率的计算公式以及三大核心概率模型展开。以下是为您提炼的第一章所有核心知识点：

### 一、 基本原理与排列组合

- **两个基本原理**：完成一件事如果分步进行使用**乘法原理**，如果分类进行使用**加法原理**。
- **排列与组合**：从 $n$ 个不同元素中抽取 $r$ 个元素，若**考虑顺序则为排列**（记为 $P_n^r$ 或 $A_n^r$），包含放回与不放回抽样；若**不考虑顺序则为组合**（记为 $C_n^r$）。

### 二、 随机试验与样本空间

- **随机试验 $E$**：需满足三个条件：(1) 在相同条件下可重复进行；(2) 结果不止一个且事前明确所有可能结果；(3) 单次试验无法确定哪个结果会出现。
- **样本空间与事件**：随机试验的每一个可能结果称为**样本点**，所有样本点组成的集合为**样本空间 $\Omega$**。样本空间的子集称为**随机事件**，其中包含所有样本点的 $\Omega$ 称为**必然事件**，不包含任何样本点的空集 $\varnothing$ 称为**不可能事件**。

### 三、 随机事件的关系与运算

- **基本关系**：
    - **包含关系 ($A \subset B$)**：$A$ 发生一定导致 $B$ 发生。
    - **和事件 ($A \cup B$ 或 $A+B$)**：$A$ 和 $B$ 至少有一个发生。
    - **积事件 ($A \cap B$ 或 $AB$)**：$A$ 和 $B$ 同时发生。
    - **差事件 ($A-B$)**：$A$ 发生且 $B$ 不发生。
- **特殊关系**：
    - **互斥（互不相容）**：$AB = \varnothing$，表示两事件不能同时发生。
    - **对立（逆事件）**：$A \cup B = \Omega$ 且 $AB = \varnothing$（记为 $\overline{A}$），两者对立一定互斥，互斥不一定对立。
    - **完备事件组（划分）**：一组互不相容的事件，且它们的和事件为必然事件 $\Omega$。
- **运算律**：满足**交换律**、**结合律**、**分配律**以及**对偶律（德摩根律）**：$\overline{A \cup B} = \overline{A} \cap \overline{B}$，$\overline{AB} = \overline{A} \cup \overline{B}$。

### 四、 概率的三大模型

- **古典概型**：具有两个特点：(1) 样本空间有限；(2) 每个样本点出现的可能性相等。概率计算公式为：$P(A) = \frac{A中基本事件的个数}{\Omega中基本事件总数}$。
- **几何概型**：样本点无限，落在某个子区域内的概率与该区域的度量（长度、面积或体积）成正比，计算公式为：$P(A) = \frac{A的度量}{\Omega的度量}$。
- **$n$重伯努利概型**：只有两个结果（$A$ 和 $\overline{A}$）的试验独立重复进行 $n$ 次。如果单次试验中 $A$ 发生的概率为 $p$，则 $n$ 次试验中 $A$ 恰好发生 $k$ 次的二项概率公式为：$P(A_k) = C_n^k p^k (1-p)^{n-k}$。

### 五、 概率的性质与五大公式

- **公理化定义与性质**：概率满足**非负性**（$P(A) \ge 0$）、**规范性**（$P(\Omega)=1$）以及对互斥事件的**可列可加性**。推导出的性质包括逆事件概率 $P(\overline{A}) = 1 - P(A)$，以及单调性法则等。
- **减法公式**：对于任意事件 $A$、$B$，有 $P(A-B) = P(A) - P(AB)$。
- **加法公式**：对于任意两事件，$P(A \cup B) = P(A) + P(B) - P(AB)$。
- **条件概率与乘法公式**：
    - 在事件 $A$ 发生的条件下事件 $B$ 发生的概率为 **条件概率** $P(B|A) = \frac{P(AB)}{P(A)}$（要求 $P(A)>0$）。
    - 变形得到 **乘法公式**：$P(AB) = P(A)P(B|A) = P(B)P(A|B)$。
- **全概率公式与贝叶斯公式**：
    - **全概率公式**：$P(B) = \sum_{i=1}^n P(A_i)P(B|A_i)$。常用于将复杂事件拆分为多个互斥的简单阶段（由因求果）。
    - **贝叶斯公式**：$P(A_i|B) = \frac{P(A_i)P(B|A_i)}{\sum_{i=1}^n P(A_i)P(B|A_i)}$。属于逆条件概率（执果索因），已知结果发生，倒推是由某个特定原因引起的概率。

### 六、 事件的独立性

- **独立的定义**：如果满足 $P(AB) = P(A)P(B)$，则称事件 $A$ 与 $B$ 相互独立。
- **独立的性质**：
    - 事件独立代表一个事件的发生与否不影响另一个事件发生的概率。
    - 如果 $A$ 与 $B$ 独立，则它们各自的对立事件（$A$ 与 $\overline{B}$，$\overline{A}$ 与 $B$，$\overline{A}$ 与 $\overline{B}$）也相互独立。
    - 概率为 0 或 1 的必然事件/不可能事件与任何事件都独立。
    - 独立与互斥的区别：对于非零概率事件，**独立一定不互斥，互斥一定不独立**。
- **多个事件的独立性**：三个事件两两独立，不能推出它们相互独立（必须还满足 $P(ABC)=P(A)P(B)P(C)$）。
