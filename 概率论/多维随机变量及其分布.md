《概率论与数理统计》第三章“多维随机变量及其分布”主要围绕二维随机变量的分布函数、离散型与连续型二维随机变量的性质、常见二维分布以及多维随机变量函数的分布展开。以下是为您提炼的本章所有核心知识点：

### 一、 二维随机变量及其分布函数

- **概念**：设 $E$ 为随机试验，样本空间为 $\Omega={e}$，设 $X=X(e)$ 和 $Y=Y(e)$ 是定义在 $\Omega$ 上的两个随机变量，则称 $(X,Y)$ 为二维随机变量。
- **联合分布函数**：对于任意实数 $x, y$，二元函数 $F(x,y) = P{X \le x, Y \le y}$ 称为二维随机变量 $(X,Y)$ 的联合分布函数。
- **分布函数的四大性质**：
    1. **非负有界性**：$0 \le F(x,y) \le 1$。
    2. **规范性**：$F(-\infty, y) = F(x, -\infty) = F(-\infty, -\infty) = 0$；$F(+\infty, +\infty) = 1$。
    3. **单调不减性**：对于变量 $x$ 和 $y$ 均是单调不减的。
    4. **右连续性**：对于 $x$ 和 $y$ 均是右连续的，即 $F(x+0, y) = F(x,y)$， $F(x, y+0) = F(x,y)$。
- **边缘分布函数**：将其中一个变量取值趋于正无穷，可得到另一个变量的边缘分布函数。即 $F_X(x) = F(x, +\infty)$，$F_Y(y) = F(+\infty, y)$。
- **独立性**：如果对任意实数 $x, y$ 都有 $F(x,y) = F_X(x)F_Y(y)$，则称随机变量 $X$ 和 $Y$ 相互独立。

### 二、 二维离散型随机变量

- **联合分布律**：$P{X=x_i, Y=y_j} = p_{ij}$，要求满足非负性（$p_{ij} \ge 0$）且所有概率之和为1（$\sum\sum p_{ij} = 1$）。
- **边缘分布律**：
    - $X$ 的边缘分布律：求和消去 $Y$，即 $P{X=x_i} = p_{i\cdot} = \sum_{j=1}^{\infty} p_{ij}$。
    - $Y$ 的边缘分布律：求和消去 $X$，即 $P{Y=y_j} = p_{\cdot j} = \sum_{i=1}^{\infty} p_{ij}$。
- **条件分布律**：在给定 $Y=y_j$ 的条件下，$X$ 的条件分布律为 $P{X=x_i | Y=y_j} = \frac{p_{ij}}{p_{\cdot j}}$（要求 $p_{\cdot j}>0$）。
- **独立性判断**：对于所有 $i, j$，均有 $p_{ij} = p_{i\cdot} p_{\cdot j}$，则 $X$ 与 $Y$ 独立。

### 三、 二维连续型随机变量

- **联合概率密度**：存在非负函数 $f(x,y)$，使得 $F(x,y) = \int_{-\infty}^{x} \int_{-\infty}^{y} f(u,v)dvdu$，称 $f(x,y)$ 为联合概率密度。它满足 $\iint_{-\infty}^{+\infty} f(x,y)dxdy = 1$。
- **边缘概率密度**：
    - $f_X(x) = \int_{-\infty}^{+\infty} f(x,y)dy$（对 $y$ 积分消去 $y$）。
    - $f_Y(y) = \int_{-\infty}^{+\infty} f(x,y)dx$（对 $x$ 积分消去 $x$）。
- **条件概率密度**：在 $Y=y$ 的条件下，$X$ 的条件概率密度为 $f_{X|Y}(x|y) = \frac{f(x,y)}{f_Y(y)}$（要求 $f_Y(y)>0$）。
- **独立性判断**：对于平面上几乎所有的点 $(x,y)$，均有 $f(x,y) = f_X(x)f_Y(y)$，则 $X$ 与 $Y$ 独立。

### 四、 常见的二维连续型分布

- **二维均匀分布**：若 $(X,Y)$ 落在某个平面区域 $G$ 内的概率均匀，则其密度函数在该区域内为常数 $\frac{1}{|G|}$（$|G|$ 为区域面积），在区域外为 0。
- **二维正态分布 $(X,Y) \sim N(\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho)$**：
    1. **边缘分布仍为正态分布**：$X \sim N(\mu_1, \sigma_1^2)$，$Y \sim N(\mu_2, \sigma_2^2)$。
    2. **独立性与不相关的等价性**：$X$ 与 $Y$ 相互独立 $\iff$ 相关系数 $\rho = 0$。
    3. **线性组合性质**：$X$ 与 $Y$ 的非零线性组合（如 $aX+bY$）仍然服从一维正态分布。
    4. **条件分布性质**：在 $Y=y$ 的条件下，$X$ 的条件分布仍然服从正态分布。

### 五、 多维随机变量函数的分布 (核心考点)

- **离散型函数的分布**：若已知 $(X,Y)$ 的联合分布律，求 $Z=g(X,Y)$ 的分布律时，先计算出所有可能的 $g(x_i, y_j)$ 取值，然后将取值相同的概率累加即可。
- **连续型函数的分布**：
    1. **分布函数法（万能方法）**：先求 $Z = g(X,Y)$ 的分布函数 $F_Z(z) = P{g(X,Y) \le z} = \iint_{g(x,y) \le z} f(x,y)dxdy$，再求导得到概率密度 $f_Z(z)$。
    2. **和的分布与卷积公式 ($Z=X+Y$)**：当 $X, Y$ 独立时，$f_Z(z) = \int_{-\infty}^{+\infty} f_X(x)f_Y(z-x)dx$ 或 $f_Z(z) = \int_{-\infty}^{+\infty} f_X(z-y)f_Y(y)dy$。
    3. **最大值与最小值分布**：
        - **最大值 $M = \max(X,Y)$**：当 $X,Y$ 独立时，$F_M(z) = F_X(z) \cdot F_Y(z)$（即所有变量都要小于等于 $z$）。推论到 $n$ 个独立同分布变量：$F_M(z) = [F(z)]^n$。
        - **最小值 $N = \min(X,Y)$**：当 $X,Y$ 独立时，$F_N(z) = 1 - [1-F_X(z)][1-F_Y(z)]$。推论到 $n$ 个独立同分布变量：$F_N(z) = 1 - [1-F(z)]^n$。
- **离散型与连续型结合的函数分布**：常利用全概率公式思想，先按照离散型随机变量的取值进行划分，结合条件概率转化为单纯的连续型问题进行计算。
