《概率论与数理统计》第四章“数字特征”主要研究随机变量的集中趋势、离散程度以及变量之间的线性相关性。本章不仅是计算的核心，也是后续大数定律和数理统计的基础。以下为您提炼本章的所有核心知识点：

### 一、 数学期望（均值）

数学期望描述了随机变量取值的平均水平或集中趋势。

- **1. 定义与计算**：
    - **离散型**：若 $X$ 的分布律为 $P{X=x_i} = p_i$，则期望为 $E(X) = \sum_{i=1}^{\infty} x_i p_i$（要求级数绝对收敛）。
    - **连续型**：若 $X$ 的概率密度为 $f(x)$，则期望为 $E(X) = \int_{-\infty}^{+\infty} x f(x)dx$（要求积分绝对收敛）。
- **2. 随机变量函数的期望**：
    - 对于一维函数 $Y=g(X)$，离散型为 $E(Y) = \sum g(x_i)p_i$，连续型为 $E(Y) = \int_{-\infty}^{+\infty} g(x)f(x)dx$。
    - 对于二维函数 $Z=g(X,Y)$，离散型为 $E(Z) = \sum\sum g(x_i, y_j)p_{ij}$，连续型为 $E(Z) = \iint g(x,y)f(x,y)dxdy$。
- **3. 数学期望的性质**：
    - 常数的期望等于它本身：$E(C) = C$。
    - 齐次性：$E(CX) = CE(X)$。
    - **可加性（无条件成立）**：$E(X+Y) = E(X) + E(Y)$，甚至推论到线性组合 $E(k_1X \pm k_2Y) = k_1E(X) \pm k_2E(Y)$。
    - **乘法性质（需独立）**：若 $X$ 与 $Y$ 相互独立，则 $E(XY) = E(X)E(Y)$。

### 二、 方差与标准差

方差描述了随机变量取值相对于其数学期望的偏离程度（分散程度）。

- **1. 定义与计算公式**：
    - **定义**：$D(X) = E{[X - E(X)]^2}$，方差的算术平方根 $\sqrt{D(X)}$ 称为标准差。
    - **常用计算公式（极其重要）**：$D(X) = E(X^2) - [E(X)]^2$。
- **2. 方差的性质**：
    - 常数的方差为 0：$D(C) = 0$。
    - 缩放平移性质：$D(CX) = C^2D(X)$；$D(X+C) = D(X)$。
    - 加减性质：$D(X \pm Y) = D(X) + D(Y) \pm 2Cov(X,Y)$。
    - **若 $X$ 与 $Y$ 相互独立**（此时 $Cov(X,Y)=0$），则有 $D(X \pm Y) = D(X) + D(Y)$。注意，无论是加还是减，方差总是相加的。
    - 若 $D(X) = 0$，则等价于 $X$ 以概率 1 取常数，即 $P{X=C} = 1$。

### 三、 常见分布的期望与方差

牢记七大常见分布的数字特征是解题的基础：

- **0-1分布**：$E(X) = p$，$D(X) = p(1-p)$。
- **二项分布 $X \sim B(n,p)$**：$E(X) = np$，$D(X) = np(1-p)$。
- **泊松分布 $X \sim P(\lambda)$**：$E(X) = \lambda$，$D(X) = \lambda$（期望与方差相等）。
- **几何分布 $X \sim G(p)$**：$E(X) = \frac{1}{p}$，$D(X) = \frac{1-p}{p^2}$。
- **均匀分布 $X \sim U(a,b)$**：$E(X) = \frac{a+b}{2}$，$D(X) = \frac{(b-a)^2}{12}$。
- **指数分布 $X \sim E(\lambda)$**：$E(X) = \frac{1}{\lambda}$，$D(X) = \frac{1}{\lambda^2}$。
- **正态分布 $X \sim N(\mu,\sigma^2)$**：$E(X) = \mu$，$D(X) = \sigma^2$。

### 四、 协方差

协方差用于衡量两个随机变量之间的总体误差及线性相关性。

- **1. 定义与公式**：
    - 定义：$Cov(X,Y) = E{[X-E(X)][Y-E(Y)]}$。
    - **常用计算公式**：$Cov(X,Y) = E(XY) - E(X)E(Y)$。
- **2. 协方差的性质**：
    - 对称性：$Cov(X,Y) = Cov(Y,X)$。
    - 与自身的协方差：$Cov(X,X) = D(X)$。
    - 与常数的协方差：$Cov(X, C) = 0$。
    - 线性运算展开：$Cov(aX, bY) = abCov(X,Y)$；$Cov(X_1 \pm X_2, Y) = Cov(X_1, Y) \pm Cov(X_2, Y)$。

### 五、 相关系数与不相关

相关系数是一个无量纲的量，专门用于衡量两个随机变量之间**线性相关**的紧密程度。

- **1. 相关系数的定义**：
    - $\rho_{XY} = \frac{Cov(X,Y)}{\sqrt{D(X)}\sqrt{D(Y)}}$ （前提是 $D(X)>0, D(Y)>0$）。
- **2. 相关系数的性质**：
    - 有界性：$|\rho_{XY}| \le 1$。
    - 完全线性相关：$|\rho_{XY}| = 1$ 的充分必要条件是存在常数 $a, b$ 使得 $P{Y=aX+b} = 1$。其中 $\rho = 1$ 对应 $a > 0$（正相关），$\rho = -1$ 对应 $a < 0$（负相关）。
- **3. 不相关的等价说法及与独立的关系**：
    - **不相关的五大等价条件**：若 $\rho_{XY} = 0$，则称 $X, Y$ 不相关。它等价于： ① $Cov(X,Y) = 0$ ② $E(XY) = E(X)E(Y)$ ③ $D(X+Y) = D(X) + D(Y)$ ④ $D(X-Y) = D(X) + D(Y)$
    - **独立与不相关的关系**：
        - **独立一定不相关**（只要期望和方差存在）。因为独立代表没有任何关系，自然也没有线性关系。
        - **不相关不一定独立**。不相关仅代表没有“线性关系”，但它们之间可能存在非线性的其他函数关系（如平方关系等）。
        - **特例**：对于二维正态分布 $(X,Y) \sim N(\mu_1,\mu_2,\sigma_1^2,\sigma_2^2,\rho)$ 而言，“不相关”与“独立”是完全等价的。
