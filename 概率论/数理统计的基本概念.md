《概率论与数理统计》第六章“数理统计的基本概念”是整个数理统计部分的基石。本章主要介绍了总体与样本的概念、常用的统计量、三大抽样分布以及正态总体下的核心抽样分布定理。以下为您提炼本章的所有核心知识点：

### 一、 总体、样本与统计量

- **总体与样本**：在数理统计中，研究对象的某项数量指标的全体称为**总体**，其中的每个元素称为**个体**。从总体中抽取的 $n$ 个相互独立且与总体具有相同分布的随机变量 $X_1, X_2, \cdots, X_n$ 称为**简单随机样本**（即独立同分布，简记为 i.i.d.）。
- **统计量**：设 $X_1, X_2, \cdots, X_n$ 是来自总体的样本，一个**不含任何未知参数**的连续函数 $g(X_1, X_2, \cdots, X_n)$ 称为统计量。
- **五大常用统计量及其数字特征**：
    1. **样本均值**：$\overline{X} = \frac{1}{n}\sum_{i=1}^n X_i$。其数字特征为：$E(\overline{X}) = \mu$，$D(\overline{X}) = \frac{\sigma^2}{n}$。
    2. **样本方差**：$S^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \overline{X})^2$。其期望为：$E(S^2) = \sigma^2$（即样本方差是总体方差的无偏估计）。
    3. **样本 $k$ 阶原点矩**：$A_k = \frac{1}{n}\sum_{i=1}^n X_i^k$。
    4. **样本 $k$ 阶中心矩**：$B_k = \frac{1}{n}\sum_{i=1}^n (X_i - \overline{X})^k$。
    5. **顺序统计量**：将样本按从小到大排序，最小值记为 $X_{(1)}$，最大值记为 $X_{(n)}$。

### 二、 数理统计的三大分布

- **1. $\chi^2$ 分布 (卡方分布)**
    - **构造**：设 $n$ 个随机变量 $X_1, \cdots, X_n$ 相互独立，且都服从标准正态分布 $N(0,1)$，则它们的平方和 $\chi^2 = X_1^2 + \cdots + X_n^2$ 服从自由度为 $n$ 的 $\chi^2$ 分布，记作 $\chi^2 \sim \chi^2(n)$。
    - **性质**：$E(\chi^2) = n$，$D(\chi^2) = 2n$。
    - **可加性**：若两个 $\chi^2$ 分布相互独立，则它们的和仍然服从 $\chi^2$ 分布，自由度相加。
- **2. $t$ 分布 (学生分布)**
    - **构造**：设 $X \sim N(0,1)$，$Y \sim \chi^2(n)$，且 $X$ 与 $Y$ 相互独立，则 $t = \frac{X}{\sqrt{Y/n}}$ 服从自由度为 $n$ 的 $t$ 分布，记作 $t \sim t(n)$。
    - **性质**：概率密度曲线关于 $y$ 轴对称。对于上 $\alpha$ 分位点，满足对称性关系：$t_{1-\alpha}(n) = -t_\alpha(n)$。
- **3. $F$ 分布**
    - **构造**：设 $X \sim \chi^2(m)$，$Y \sim \chi^2(n)$，且 $X$ 与 $Y$ 相互独立，则 $F = \frac{X/m}{Y/n}$ 服从第一自由度为 $m$、第二自由度为 $n$ 的 $F$ 分布，记作 $F \sim F(m,n)$。
    - **性质**：倒数性质——若 $F \sim F(m,n)$，则 $\frac{1}{F} \sim F(n,m)$。对于上 $\alpha$ 分位点有：$F_{1-\alpha}(m,n) = \frac{1}{F_\alpha(n,m)}$。
    - **与 $t$ 分布的关系**：若 $T \sim t(n)$，则 $T^2 \sim F(1,n)$。

### 三、 正态总体下的抽样分布 (核心考点)

在正态总体下，样本均值和样本方差构成的统计量服从特定的分布，这是后续参数估计和假设检验的理论基础：

- **（一）一个正态总体的抽样分布 ($X \sim N(\mu, \sigma^2)$)**
    1. **样本均值的分布**：$\overline{X} \sim N(\mu, \frac{\sigma^2}{n})$，标准化后即 $U = \frac{\overline{X} - \mu}{\sigma / \sqrt{n}} \sim N(0,1)$。
    2. **样本方差的分布**：$\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$。**同时，$\overline{X}$ 与 $S^2$ 相互独立**。
    3. **未知方差时的均值分布 ($t$ 统计量)**：将标准化公式中的 $\sigma$ 替换为 $S$，得到 $t = \frac{\overline{X} - \mu}{S / \sqrt{n}} \sim t(n-1)$。
    4. **总体方差与样本的关系**：$\sum_{i=1}^n \left(\frac{X_i - \mu}{\sigma}\right)^2 \sim \chi^2(n)$。
- **（二）两个正态总体的抽样分布 ($X \sim N(\mu_1, \sigma_1^2), Y \sim N(\mu_2, \sigma_2^2)$)**
    1. **方差已知时，均值差的分布**：$U = \frac{(\overline{X} - \overline{Y}) - (\mu_1 - \mu_2)}{\sqrt{\frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}}} \sim N(0,1)$。
    2. **方差未知但相等 ($\sigma_1^2 = \sigma_2^2 = \sigma^2$) 时，均值差的分布**：使用合并样本标准差 $S_w$，构造统计量 $T = \frac{(\overline{X} - \overline{Y}) - (\mu_1 - \mu_2)}{S_w \sqrt{\frac{1}{n_1} + \frac{1}{n_2}}} \sim t(n_1 + n_2 - 2)$，其中 $S_w = \sqrt{\frac{(n_1-1)S_1^2 + (n_2-1)S_2^2}{n_1 + n_2 - 2}}$。
    3. **两个样本方差之比的分布 ($F$ 统计量)**：$F = \frac{S_1^2 / \sigma_1^2}{S_2^2 / \sigma_2^2} \sim F(n_1-1, n_2-1)$ 或 $F = \frac{S_2^2 / \sigma_2^2}{S_1^2 / \sigma_1^2} \sim F(n_2-1, n_1-1)$。
