

# 个人工作总结：资金流入流出预测系统 (可视化大屏开发)

## 一、 项目背景与概述
在“资金流入流出预测系统”项目中，我主要负责**前端可视化架构设计、数据大屏开发以及工程化部署落地**。该项目旨在将底层复杂的机器学习算法（LightGBM / LSTM）以及海量的金融流水数据，转化为高可用、可交互的现代化数据看板，从而辅助业务线进行资金流向预判和决策。

## 二、 核心职责与主要贡献

### 1. 从 0 到 1 搭建前端架构与交互大屏
* **UI/UX 与架构设计**：采用无依赖的原生技术栈（HTML/CSS/JS）结合 CSS Grid 响应式网格布局，从零搭建了整套前端架构。主导制定了深色金融主题（Dark Theme）视觉规范，大幅提升了系统的专业度和沉浸感。
* **数据可视化落地**：深度引入 ECharts 5.5 图表库，独立开发了 10 余种高度定制化的交互式图表。涵盖了：多时间窗口（Lag 1/7/30）的历史资金趋势图、双 Y 轴收益率走势图、用户画像多维看板、双模型（LightGBM/LSTM）训练 Loss 曲线、预测拟合对比图及未来 30 天走势预测等。

### 2. 前后端深度协同与业务逻辑闭环
* **复杂数据降维与清洗**：面对后端返回的复杂/深层嵌套的 JSON 数据结构，我在前端编写了严谨的数据解析适配器。成功处理了各类边界情况，如：自动计算提取嵌套结构中的双模型平均误差率、修复了 LSTM 算法在部分验证集日期上的缺失异常等。
* **高阶交互与智能诊断模块**：开发了基于单选组件的“无刷新模型切换台”。尤其在“误差分析模块”中，我创新性地设计了**条件染色算法**——当预测误差超过业务阈值时，图表会自动将异常日期的柱子高亮为红色，并联动“诊断建议面板”直接输出系统改进建议，完成了“发现异常 -> 定位日期 -> 给出建议”的业务闭环。

### 3. 工程化部署与跨平台异常攻坚
* **环境修复与联调打通**：在前后端联调阶段，主动向下兼容，解决了后端 Flask 框架的跨域请求限制（CORS）；并敏锐排查出 Mac 系统下的端口冲突（将后端平滑迁移至 5001 端口）。
* **底层依赖与版本控制**：修复了原算法仓库中因严格包版本（如 Pandas）导致的构建崩溃问题，排查并解决了 LightGBM 在 macOS 上的 C++ 依赖（`libomp`）缺失；最终规范化地编写了 `.gitignore`，将项目完整、干净地交付推送到 GitHub 远程仓库，保障了项目的完美验收。

## 三、 技术亮点与成果
1. **轻量高效**：没有盲目引入庞大的前端框架，依靠原生 JavaScript 与高效的 DOM 操作，保障了海量金融数据在浏览器端的极速渲染与平滑缩放（DataZoom）。
2. **极高可用**：无论是 Windows 还是 Mac 系统，本项目的环境配置与依赖已全部调优，能够实现克隆后即可“开箱即用”。
3. **业务赋能**：将原本只能在控制台打印的冰冷日志和 Loss 列表，成功转化为业务方一眼就能看懂的图表，直接赋予了算法模型极高的商业展现价值。

## 四、 个人成长与复盘
通过主导该项目的前端及部署工作，我不仅扎实了原生前端开发与数据可视化（ECharts）的核心能力，更重要的是**培养了极其敏锐的全栈排错意识**。从解决环境依赖（pip/brew）、到修复网络通信（CORS/Port）、再到重构数据解析逻辑，我能够跳出前端的局限，站在整体工程架构的角度去定位和解决问题。

未来，我将继续在数据可视化与全栈工程化方向深耕，致力于将更多硬核的算法能力，转化为极致的用户体验。
