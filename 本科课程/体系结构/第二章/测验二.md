### 📝 题目条件梳理

1. **寄存器初始化规则：** * $R_i$ 的初始值为 $i + 2$
    
    - 由此可得：
        
        - $R_1 = 1 + 2 = 3$
            
        - $R_2 = 2 + 2 = 4$
            
        - $R_3 = 3 + 2 = 5$
            
        - $R_4 = 4 + 2 = 6$
            
2. **内存初始化规则：** * 地址为 $a$ 的内存单元，其初始化值为 $(a + 3) \pmod{10}$
    
3. **关键指令说明：**
    
    - `LB` (Load Byte)：从内存加载一个字节到寄存器。
        
    - `SB` (Store Byte)：将寄存器中的一个字节写入到内存。
        

### 🚀 指令序列逐条断点追踪

我们按照代码顺序，一步步来看每个寄存器和内存值的动态变化（只需回答 $R_1 \sim R_4$）：

#### 1. `LB R1, 100(R1)`

- **源地址计算：** 基址寄存器 $R_1$ 当前值为 $3$，加上偏移量 $100$，得到内存地址 $a = 100 + 3 = 103$。
    
- **读取内存值：** 访问地址 $103$ 的内存，该处初始值为 $(103 + 3) \pmod{10} = 106 \pmod{10} = 6$。
    
- **寄存器更新：** 将读出来的数值 $6$ 写入目标寄存器 $R_1$。
    
- **此时状态：** **$R_1 = 6$**，其余寄存器不变 ($R_2=4, R_3=5, R_4=6$)。
    

#### 2. `LB R2, 0(R4)`

- **源地址计算：** 基址寄存器 $R_4$ 当前值为 $6$，偏移量为 $0$，得到内存地址 $a = 6 + 0 = 6$。
    
- **读取内存值：** 访问地址 $6$ 的内存，该处初始值为 $(6 + 3) \pmod{10} = 9 \pmod{10} = 9$。
    
- **寄存器更新：** 将读出来的数值 $9$ 写入目标寄存器 $R_2$。
    
- **此时状态：** $R_1 = 6$, **$R_2 = 9$**，其余不变 ($R_3=5, R_4=6$)。
    

#### 3. `SB R2, 10(R3)`

- **注意：** 这一条是 `SB`（Store 写入内存指令），它**不改变**任何通用寄存器的值，只修改内存！
    
- **目的地址计算：** 基址寄存器 $R_3$ 当前值为 $5$，加上偏移量 $10$，得到内存地址 $a = 10 + 5 = 15$。
    
- **写入内存操作：** 将寄存器 $R_2$ 的当前值（即上一步算出来的 $9$）写入到内存地址 $15$ 处。
    
- **此时状态：** 内存地址 $15$ 的值变为了 $9$。寄存器状态保持不变：$R_1 = 6, R_2 = 9, R_3 = 5, R_4 = 6$。
    

#### 4. `LB R3, 10(R4)`

- **源地址计算：** 基址寄存器 $R_4$ 当前值为 $6$，加上偏移量 $10$，得到内存地址 $a = 10 + 6 = 16$。
    
- **读取内存值：** 访问地址 $16$ 的内存，该处初始值为 $(16 + 3) \pmod{10} = 19 \pmod{10} = 9$。
    
- **寄存器更新：** 将读出来的数值 $9$ 写入目标寄存器 $R_3$。
    
- **此时状态：** $R_1 = 6, R_2 = 9$, **$R_3 = 9$**，$R_4 = 6$。
    

#### 5. `LB R4, 6(R1)`

- **源地址计算：** 基址寄存器 $R_1$ 当前值为 $6$（第一步被修改过），加上偏移量 $6$，得到内存地址 $a = 6 + 6 = 12$。
    
- **读取内存值：** 访问地址 $12$ 的内存，该处初始值为 $(12 + 3) \pmod{10} = 15 \pmod{10} = 5$。
    
- **寄存器更新：** 将读出来的数值 $5$ 写入目标寄存器 $R_4$。
    
- **此时状态：** $R_1 = 6, R_2 = 9, R_3 = 9$, **$R_4 = 5$**。
    

### 🏁 最终提交答案

依次执行完这 5 条指令后，寄存器 $R_1 \sim R_4$ 的最终数值为：

- **$R_1 = 6$**
    
- **$R_2 = 9$**
    
- **$R_3 = 9$**
    
- **$R_4 = 5$**
