**1. 贝叶斯网络**

要求 $P(A|D)$，根据贝叶斯公式展开：

$$P(A|D) = \frac{P(D|A)P(A)}{P(D)}$$

已知 $P(A)=0.5$，则 $P(\neg A)=0.5$。

题目给定了在A条件下B和C的概率，由于B和C条件独立，先计算 $P(D|A)$：

$$P(D|A) = P(D|B,C)P(B|A)P(C|A) = 1 \times 1 \times 1 = 1$$

接着计算 $P(D|\neg A)$，需要把B和C的四种情况通过全概率公式展开：

$$P(D|\neg A) = P(D|B,C)P(B|\neg A)P(C|\neg A) + P(D|B,\neg C)P(B|\neg A)P(\neg C|\neg A) + P(D|\neg B,C)P(\neg B|\neg A)P(C|\neg A) + P(D|\neg B,\neg C)P(\neg B|\neg A)P(\neg C|\neg A)$$

代入数值：

$$P(D|\neg A) = (1 \times 0.5 \times 0.5) + (0.5 \times 0.5 \times 0.5) + (0.5 \times 0.5 \times 0.5) + 0$$

$$P(D|\neg A) = 0.25 + 0.125 + 0.125 = 0.5$$

求出边缘概率 $P(D)$：

$$P(D) = P(D|A)P(A) + P(D|\neg A)P(\neg A) = 1 \times 0.5 + 0.5 \times 0.5 = 0.75$$

代入贝叶斯公式：

$$P(A|D) = \frac{1 \times 0.5}{0.75} = \frac{2}{3}$$

**2. 不确定性的量化**

设 $B$ 表示男生，$G$ 表示女生，$P$ 表示穿裤子。

先求整所学校里抽到男生的全概率：

$$P(B) = 0.4 \times 0.7 + 0.5 \times 0.2 + 0.6 \times 0.1 = 0.44$$

则抽到女生的概率 $P(G) = 1 - 0.44 = 0.56$。

已知男生必穿裤子 $P(P|B) = 1$，女生一半穿一半不穿 $P(P|G) = 0.5$。

求穿裤子条件下是男生的概率 $P(B|P)$：

$$P(B|P) = \frac{P(P|B)P(B)}{P(P|B)P(B) + P(P|G)P(G)}$$

$$P(B|P) = \frac{1 \times 0.44}{1 \times 0.44 + 0.5 \times 0.56} = \frac{0.44}{0.44 + 0.28} = \frac{44}{72} = \frac{11}{18}$$

也就是 11/18（约 61.1%）。

**3. 决策树**

数据集一共7行，F包含4个1，3个0。根据ID3算法算信息增益：

观察数据可以发现，用C分类最明显：

- 当 $C=1$ 时（第2、4、6行），F全为1。这个分支纯度最高，不需要往下分了。
    
- 当 $C=0$ 时（第1、3、5、7行），F的值是 {0, 0, 1, 0}。**所以根节点选C**。
    

在 $C=0$ 的数据子集中继续分：

- 观察属性A：如果 $A=0$，对应的F全是0；如果 $A=1$，F是 {1, 0}。**所以第二个节点选A**。
    

在 $C=0$ 且 $A=1$ 的子集中（只剩第5、7行）：

- 只能用B来区分了：$B=0$ 时对应 $F=1$；$B=1$ 时对应 $F=0$。

**4. 人工神经网络**

阈值感知器的模型是 $y = f(w_1x_1 + w_2x_2 - \theta)$。里面大于等于0就激活输出1，小于0输出0。

- **实现与（AND）**：要求两个输入同时为1才输出1。
    
    让 $w_1=1$, $w_2=1$, 阈值 $\theta=1.5$。
    
    只有 $x_1=1, x_2=1$ 的时候，$1+1-1.5 = 0.5 \ge 0$，输出1。
    
    只要有一个是0（比如 $0+1-1.5 = -0.5 < 0$），就输出0。
    
- **实现或（OR）**：要求只要有一个1就输出1。
    
    让 $w_1=1$, $w_2=1$, 阈值 $\theta=0.5$。
    
    $x_1=0, x_2=0$ 的时候，$0+0-0.5 = -0.5 < 0$，输出0。
    
    只要有一个是1（比如 $1+0-0.5 = 0.5 \ge 0$），就输出1。
    

**5. 深度学习**

深度学习的原理就是通过构建多层的人工神经网络，让模型自己从数据里自动学习特征表示。层数越深，提取的特征就越抽象、越高级。这省去了传统机器学习里人工设计和提取特征的麻烦。底层一般学边缘、线条，高层就能学到物体的整体轮廓和语义。训练过程依赖反向传播算法（BP），靠梯度下降一步步更新网络权重。

以**卷积神经网络（CNN）**为例：这是处理图像最典型的算法。它里面有**卷积层**，用设定好的卷积核在图片上滑动做矩阵乘法，专门用来抓取局部的特征；然后会接**池化层**（比如最大池化），用来把特征图缩小，减少参数和计算量，同时防止过拟合；最后数据被展平送进**全连接层**，用来综合前面所有的特征并输出最终的分类预测。
