

## 1. 贝叶斯网络 (20分)

**题目：** 根据图所给出的贝叶斯网络，计算概率 $P(A|D)$。

**解答过程：**

根据贝叶斯公式，我们有：

$$P(A|D) = \frac{P(D|A)P(A)}{P(D)}$$

为了求出 $P(A|D)$，我们需要分别计算 $P(D|A)$ 和总体概率 $P(D)$。由于 B 和 C 在给定 A 的条件下是条件独立的，且 D 依赖于 B 和 C。

**步骤 1：计算 $P(D|A)$**

根据全概率公式展开，并利用条件独立性 $P(B,C|A) = P(B|A)P(C|A)$：

$$P(D|A) = \sum_{b \in \{B, \neg B\}} \sum_{c \in \{C, \neg C\}} P(D|b,c)P(b|A)P(c|A)$$

已知 $P(B|A) = 1, P(C|A) = 1$，这意味着在给定 A 发生的情况下，B 和 C 必然发生（即 $P(\neg B|A)=0, P(\neg C|A)=0$）。

因此，求和项中只有 $b=B, c=C$ 时不为零：

$$P(D|A) = P(D|B,C) \times P(B|A) \times P(C|A) = 1 \times 1 \times 1 = 1$$

**步骤 2：计算 $P(D|\neg A)$**

同理，展开 $P(D|\neg A)$：

$$P(D|\neg A) = \sum_{b \in \{B, \neg B\}} \sum_{c \in \{C, \neg C\}} P(D|b,c)P(b|\neg A)P(c|\neg A)$$

已知 $P(B|\neg A) = 0.5$（则 $P(\neg B|\neg A) = 0.5$），$P(C|\neg A) = 0.5$（则 $P(\neg C|\neg A) = 0.5$）。代入所有可能组合：

$$P(D|\neg A) = P(D|B,C)P(B|\neg A)P(C|\neg A) + P(D|B,\neg C)P(B|\neg A)P(\neg C|\neg A) + P(D|\neg B,C)P(\neg B|\neg A)P(C|\neg A) + P(D|\neg B,\neg C)P(\neg B|\neg A)P(\neg C|\neg A)$$

$$P(D|\neg A) = (1 \times 0.5 \times 0.5) + (0.5 \times 0.5 \times 0.5) + (0.5 \times 0.5 \times 0.5) + (0 \times 0.5 \times 0.5)$$

$$P(D|\neg A) = 0.25 + 0.125 + 0.125 + 0 = 0.5$$

**步骤 3：计算 $P(D)$**

利用全概率公式：

$$P(D) = P(D|A)P(A) + P(D|\neg A)P(\neg A)$$

已知 $P(A) = 0.5$，则 $P(\neg A) = 0.5$：

$$P(D) = (1 \times 0.5) + (0.5 \times 0.5) = 0.5 + 0.25 = 0.75$$

**步骤 4：计算最终结果 $P(A|D)$**

$$P(A|D) = \frac{P(D|A)P(A)}{P(D)} = \frac{1 \times 0.5}{0.75} = \frac{0.5}{0.75} = \frac{2}{3}$$

**最终答案：** $P(A|D) = \frac{2}{3}$

## 2. 不确定性的量化

**题目：** 计算穿裤子的人是男生的概率。

**解答过程：**

设事件 $B$ 为“该人是男生”，事件 $G$ 为“该人是女生”。设事件 $P$ 为“穿裤子”。

根据题意，男女比例有三种可能的情况（设为 $R_1, R_2, R_3$）：

- $R_1$ (4:6): 男生占 40%，女生占 60%。概率 $P(R_1) = 0.7$
    
- $R_2$ (1:1): 男生占 50%，女生占 50%。概率 $P(R_2) = 0.2$
    
- $R_3$ (6:4): 男生占 60%，女生占 40%。概率 $P(R_3) = 0.1$
    

已知条件概率：

- 所有男生都穿裤子：$P(P|B) = 1$
    
- 女生一半穿裤子：$P(P|G) = 0.5$
    

**步骤 1：计算整所学校中随机抽到男生 $P(B)$ 和女生 $P(G)$ 的先验概率**

$$P(B) = P(B|R_1)P(R_1) + P(B|R_2)P(R_2) + P(B|R_3)P(R_3)$$

$$P(B) = (0.4 \times 0.7) + (0.5 \times 0.2) + (0.6 \times 0.1) = 0.28 + 0.10 + 0.06 = 0.44$$

$$P(G) = 1 - P(B) = 0.56$$

**步骤 2：计算随机抽到一个人穿裤子的全概率 $P(P)$**

$$P(P) = P(P|B)P(B) + P(P|G)P(G)$$

$$P(P) = (1 \times 0.44) + (0.5 \times 0.56) = 0.44 + 0.28 = 0.72$$

**步骤 3：利用贝叶斯公式求 $P(B|P)$**

$$P(B|P) = \frac{P(P|B)P(B)}{P(P)} = \frac{1 \times 0.44}{0.72} = \frac{44}{72} = \frac{11}{18} \approx 0.6111$$

**最终答案：** 问一个穿裤子的人是男生的概率为 $\frac{11}{18}$（约61.11%）。

## 3. 决策树

**题目：** 根据信息增益标准（ID3算法），画出F的决策树。

**解答过程：**

数据集 $S$ 共有 7 个样本，其中目标属性 $F$ 包含 4 个 `1` 和 3 个 `0`。

根据提供的信息量值：$\log_2(\frac{2}{3}) = -0.5842, \log_2(\frac{1}{3}) = -1.5850, \log_2(\frac{3}{4}) = -0.41504$。

注：$\log_2(\frac{1}{4}) = -2$。

**步骤 1：寻找根节点（计算各属性的条件熵，条件熵越小，信息增益越大）**

- **对于属性 A:**
    
    - $A=0$ 的子集 (4个样本): $F$ 有两个 0，两个 1。$H(S_{A=0}) = -(\frac{2}{4}\log_2\frac{2}{4} + \frac{2}{4}\log_2\frac{2}{4}) = 1$
        
    - $A=1$ 的子集 (3个样本): $F$ 有一个 0，两个 1。$H(S_{A=1}) = -(\frac{1}{3}\log_2\frac{1}{3} + \frac{2}{3}\log_2\frac{2}{3}) = \frac{1}{3}(1.585) + \frac{2}{3}(0.5842) \approx 0.9178$
        
    - $H(S|A) = \frac{4}{7} \times 1 + \frac{3}{7} \times 0.9178 \approx 0.9647$
        
- **对于属性 B:**
    
    - $B=0$ 的子集 (4个样本): $F$ 有一个 0，三个 1。$H(S_{B=0}) = -(\frac{1}{4}\log_2\frac{1}{4} + \frac{3}{4}\log_2\frac{3}{4}) = 0.25(2) + 0.75(0.41504) \approx 0.8113$
        
    - $B=1$ 的子集 (3个样本): $F$ 有两个 0，一个 1。$H(S_{B=1}) = -(\frac{2}{3}\log_2\frac{2}{3} + \frac{1}{3}\log_2\frac{1}{3}) \approx 0.9178$
        
    - $H(S|B) = \frac{4}{7} \times 0.8113 + \frac{3}{7} \times 0.9178 \approx 0.8570$
        
- **对于属性 C:**
    
    - $C=0$ 的子集 (4个样本): $F$ 有三个 0，一个 1。$H(S_{C=0}) = -(\frac{3}{4}\log_2\frac{3}{4} + \frac{1}{4}\log_2\frac{1}{4}) \approx 0.8113$
        
    - $C=1$ 的子集 (3个样本): $F$ 全为 1。$H(S_{C=1}) = 0$
        
    - $H(S|C) = \frac{4}{7} \times 0.8113 + \frac{3}{7} \times 0 \approx 0.4636$
        

对比可知，属性 C 的条件熵最小，信息增益最大。因此，**选择属性 C 作为根节点**。

**步骤 2：构建子树**

- **当 C = 1 时：** 剩余样本的 F 值均为 1。因此生成叶子节点：**F = 1**。
    
- **当 C = 0 时：** 剩余样本为第1、3、5、7行。
    
    - 此时样本集 $S_{C=0}$ 包含 4 个样本，F 值为 {0, 0, 1, 0}。
        
    - 在 $S_{C=0}$ 上计算 A 和 B 的信息增益：
        
        - 若按 A 划分：$A=0$ 时，F全是 0，纯度最高 ($H=0$)；$A=1$ 时，F为一个 1 一个 0 ($H=1$)。条件熵 $H(S_{C=0}|A) = 0.5$。
            
        - 若按 B 划分：$B=0$ 时，F为一个 0 一个 1 ($H=1$)；$B=1$ 时，F全是 0 ($H=0$)。条件熵 $H(S_{C=0}|B) = 0.5$。
            
    - 两者增益相同，任选其一。这里**选择属性 A 作为下一个划分节点**。
        
        - 当 $A = 0$ 时：F 均为 0。生成叶子节点：**F = 0**。
            
        - 当 $A = 1$ 时：剩余样本（第5行和第7行），此时还需要用属性 B 区分。
            
            - 当 $B = 0$ 时（对应第5行）：生成叶子节点 **F = 1**。
                
            - 当 $B = 1$ 时（对应第7行）：生成叶子节点 **F = 0**。
                

**最终决策树结构如下：**

Plaintext

```
      [ C ]
      /   \
   =0/     \=1
    /       \
  [ A ]    ( 1 )
  /   \
=0/     \=1
 /       \
( 0 )   [ B ]
        /   \
      =0/     \=1
       /       \
     ( 1 )    ( 0 )
```

_(注：括号内为叶子节点 F 的预测值)_

## 4. 人工神经网络

**题目：** 阈值感知器可以用来执行很多逻辑函数，说明它对二进制逻辑函数与（AND）和或（OR）的实现过程。

**解答过程：**

阈值感知器的基本模型为：$y = f(w_1x_1 + w_2x_2 - \theta)$。

其中，$x_1, x_2$ 为输入，$w_1, w_2$ 为权重，$\theta$ 为阈值。

激活函数 $f(z)$ 是一个阶跃函数：当 $z \ge 0$ 时，输出 $y = 1$；当 $z < 0$ 时，输出 $y = 0$。

**1. 实现逻辑与（AND）函数**

逻辑 AND 的真值表要求：只有当 $x_1=1$ 且 $x_2=1$ 时，输出才为 1；否则为 0。

- **参数设置：** 设 $w_1 = 1$, $w_2 = 1$, 阈值 $\theta = 1.5$。
    
- **验证过程：**
    
    - $x_1=0, x_2=0$: $1\times0 + 1\times0 - 1.5 = -1.5 < 0 \Rightarrow y=0$
        
    - $x_1=0, x_2=1$: $1\times0 + 1\times1 - 1.5 = -0.5 < 0 \Rightarrow y=0$
        
    - $x_1=1, x_2=0$: $1\times1 + 1\times0 - 1.5 = -0.5 < 0 \Rightarrow y=0$
        
    - $x_1=1, x_2=1$: $1\times1 + 1\times1 - 1.5 = 0.5 \ge 0 \Rightarrow y=1$
        
        满足 AND 逻辑。
        

**2. 实现逻辑或（OR）函数**

逻辑 OR 的真值表要求：只要 $x_1$ 或 $x_2$ 至少有一个为 1，输出就为 1；全为 0 时输出为 0。

- **参数设置：** 设 $w_1 = 1$, $w_2 = 1$, 阈值 $\theta = 0.5$。
    
- **验证过程：**
    
    - $x_1=0, x_2=0$: $1\times0 + 1\times0 - 0.5 = -0.5 < 0 \Rightarrow y=0$
        
    - $x_1=0, x_2=1$: $1\times0 + 1\times1 - 0.5 = 0.5 \ge 0 \Rightarrow y=1$
        
    - $x_1=1, x_2=0$: $1\times1 + 1\times0 - 0.5 = 0.5 \ge 0 \Rightarrow y=1$
        
    - $x_1=1, x_2=1$: $1\times1 + 1\times1 - 0.5 = 1.5 \ge 0 \Rightarrow y=1$
        
        满足 OR 逻辑。

## 5. 深度学习

**题目：** 深度学习的原理是什么？以一个典型的深度学习算法为例进行说明。

**解答过程：**

**1. 深度学习的原理**

深度学习是机器学习的一个重要分支，其核心原理是基于多层人工神经网络构建**层次化的特征表示**。

传统机器学习通常依赖人工提取特征，而深度学习通过堆叠多个隐藏层（即“深度”），自动从原始数据中学习从低级到高级的抽象特征。底层网络可能学习到边缘、线条等简单特征；中层网络将这些组合成局部模式；高层网络则综合形成全局的、具有高度语义信息的特征。其训练过程通常基于**反向传播算法（Backpropagation）**，通过计算损失函数相对于网络权重的梯度，利用梯度下降等优化算法不断更新权重参数，最终使网络能够进行精准的分类、回归或生成。

**2. 典型算法示例：卷积神经网络（CNN）**

卷积神经网络（Convolutional Neural Networks）是处理图像、视频等网格化数据的典型深度学习算法。它的核心优势在于保留了空间层级结构，有效降低了参数量。

- **卷积层（Convolutional Layer）：** 利用一组可学习的“卷积核（滤波器）”在图像上滑动，进行局部点乘运算。这体现了**局部感知**的原理，用于提取图像中的边缘、纹理等局部特征。
    
- **激活层（Activation Layer）：** 通常引入 ReLU 等非线性激活函数，增强网络的非线性表达能力，使其能够拟合复杂的映射关系。
    
- **池化层（Pooling Layer）：** 通过降采样（如最大池化 Max Pooling）缩小特征图的空间尺寸。这不仅大幅减少了计算量和参数数量，还赋予了网络一定的**平移不变性**。
    
- **全连接层（Fully Connected Layer）：** 在网络的末端，将前面提取到的高维立体特征展平，连接到传统的全连接网络中，综合所有局部信息进行最终的分类决策。
