

## 1. 实时在线电话翻译系统分析

**性能度量 :**

翻译的准确性（语义是否正确）、翻译的延迟（实时性、速度）、语言的自然度与流畅度、系统的鲁棒性（对口音和噪声的适应能力）。

**环境 :**

电话通信网络、参与通话的用户（英语和日语使用者）、声音传输通道及可能存在的背景噪声。

**执行器 :**

语音合成器（输出翻译后的目标语言语音）、屏幕显示器（若支持文本显示翻译结果）。

**感知器 :**

麦克风（接收用户的语音输入）。

**环境属性分析:**

- **部分可观察 :** 系统无法提前知道用户接下来要说什么，也无法完全掌握背景噪声或电话另一端的全部状态。
    
- **多智能体 :** 涉及多个通信的人类（在这个语境下，人类可以被视为环境中的其他智能体）。
    
- **随机的 :** 用户的语音输入、背景噪音、口音等都具有不确定性，且同一句话可能有多种正确的翻译方式。
    
- **顺序的 :** 当前的翻译高度依赖于之前的对话上下文，并非孤立的片段。
    
- **动态的 :** 在翻译进行时，时间在流逝，且环境（用户的语速、情绪、外界声音）在不断变化。
    
- **连续的 :** 输入和输出的语音信号在时间上和幅度上都是连续的。
    


## 2. 医疗诊断系统的 Agent 选择

**最合适的种类：基于效用的 agent (Utility-based Agent)。**

**解释与结论：**

- **简单 agent :** 仅根据当前感知（如某个症状）做出反应。医疗诊断中，单一症状往往对应多种疾病，无法通过简单的“条件-动作”规则完成准确诊断。
    
- **基于模型的 agent :** 能够维持内部状态（如病人的病史）。虽然比简单 agent 好，但它不知道治疗的最终目的。
    
- **基于目标的 agent :** 拥有一个明确的目标（如“治愈病人”）。然而，医疗不仅需要达到目标，还需要考虑代价和风险。如果有两种方案都能治愈病人，但一种方案痛苦大且昂贵，另一种温和且便宜，基于目标的 agent 无法区分它们的优劣。
    
- **基于效用的 agent:** 是最理想的选择。医疗诊断充满了不确定性（误诊风险、药物副作用），基于效用的 agent 能够综合评估各种治疗方案的概率和结果，权衡健康恢复的收益与检查成本、痛苦、副作用等代价，从而选择一个能使病人“期望效用最大化”的综合最优诊断和治疗方案。
    


## 3. 搜索树建立与算法分析

设起点为 S，终点为 G。这里假设节点扩展时按字母顺序（A 优先于 B）进行。

**(a) 深度优先搜索**

- **搜索过程：** 从 S 开始，扩展到 A；从 A 扩展到 B；从 B 扩展到 C（死胡同）；回溯到 B，扩展到 D；从 D 扩展到 G。
    
    - 展开顺序：S $\rightarrow$ A $\rightarrow$ B $\rightarrow$ C $\rightarrow$ D $\rightarrow$ G。找到路径 S-A-B-D-G。
        
- **完备性：** 在有限状态空间（并使用图搜索避免环路）中是完备的。
    
- **最优性：** 不是最优的（通常会找到一条深长路径，而不是最短路径）。
    
- **时间复杂度：** $O(b^m)$，其中 $b$ 是分支因子，$m$ 是树的最大深度。
    
- **空间复杂度：** $O(bm)$，空间消耗较小。
    

**(b) 宽度优先搜索**

- **搜索过程：** 从 S 开始，扩展到 A, B（第 1 层）；接着扩展 A 得到 D，扩展 B 得到 C, D（第 2 层）；接着扩展 D 得到 G。
    
    - 展开顺序：S $\rightarrow$ A $\rightarrow$ B $\rightarrow$ D $\rightarrow$ C $\rightarrow$ G。找到路径 S-A-D-G。
        
- **完备性：** 只要分支因子有限，BFS 是完备的。
    
- **最优性：** 当所有边的单步代价相等时，BFS 是最优的。
    
- **时间复杂度：** $O(b^d)$，其中 $d$ 是目标节点的最浅深度。
    
- **空间复杂度：** $O(b^d)$，需要将所有边缘节点保存在内存中，空间消耗极大。
    

**(c) 爬山法**

- **搜索过程：** 仅利用当前节点的邻居的 $h(n)$ 进行局部最优选择。
    
    - 当前 S(11)，邻居 A(8), B(9)。选择 A (8 < 11)。
        
    - 当前 A(8)，邻居 B(9), D(5)。选择 D (5 < 8)。
        
    - 当前 D(5)，邻居 G(0)。选择 G (0 < 5)。找到路径 S-A-D-G。
        
- **完备性：** 不完备，容易陷入局部最优解（如山顶、山脊）。
    
- **最优性：** 不是最优的。
    
- **时间复杂度：** 最坏情况为 $O(\infty)$，通常取决于状态空间地形。
    
- **空间复杂度：** $O(1)$，仅在内存中保留当前状态。
    

**(d) 贪婪最佳优先**

- **搜索过程：** 维护一个优先队列，每次扩展 $h(n)$ 最小的节点。
    
    1. 队列：[S(11)] $\rightarrow$ 弹出 S，加入 A, B。
        
    2. 队列：[A(8), B(9)] $\rightarrow$ 弹出 A，加入 D。
        
    3. 队列：[D(5), B(9)] $\rightarrow$ 弹出 D，加入 G。
        
    4. 队列：[G(0), B(9)] $\rightarrow$ 弹出 G，到达目标。找到路径 S-A-D-G。
        
- **完备性：** 树搜索下不完备（可能陷入死循环）；在有限状态空间的图搜索下完备。
    
- **最优性：** 不是最优的。
    
- **时间复杂度：** 最坏情况下为 $O(b^m)$。
    
- **空间复杂度：** 最坏情况下为 $O(b^m)$，因为需要把所有节点保存在内存中。

## 5. 一致性与可采纳性证明

**题目：** 给定一个启发式函数满足 $h(G)=0$，其中 $G$ 是目标状态，证明如果 $h$ 是一致的，那么它是可采纳的。

**证明过程：**

设 $h^*(n)$ 为从状态 $n$ 到达目标状态 $G$ 的实际最优代价。

可采纳性的定义为：对于所有的节点 $n$，均有 $h(n) \le h^*(n)$。

一致性（单调性）的定义为：对于任意节点 $n$ 及其任意后继节点 $n'$，设 $c(n, n')$ 为从 $n$ 转移到 $n'$ 的单步实际代价，均满足：

$$h(n) \le c(n, n') + h(n')$$

并且 $h(G) = 0$。

我们可以使用数学归纳法对节点 $n$ 到目标节点 $G$ 的最优路径长度 $k$（步数）进行归纳证明。

**1. 基础情况 ：**

当 $k = 0$ 时，节点 $n$ 即为目标节点 $G$自身。

此时真实代价 $h^*(G) = 0$。由题设已知 $h(G) = 0$。

显然满足 $h(G) \le h^*(G)$。

**2. 归纳假设 ：**

假设对于任意到达目标节点需要 $k$ 步的最优路径上的节点 $n'$，该定理成立，即：

$$h(n') \le h^*(n')$$

**3. 递推证明 ：**

现在考虑任意一个到达目标节点 $G$ 需要 $k+1$ 步的节点 $n$。

设节点 $n$ 沿着最优路径前往目标 $G$ 的下一个节点为 $n'$。那么从 $n'$ 到目标 $G$ 恰好需要 $k$ 步。

由于 $n \rightarrow n' \rightarrow \cdots \rightarrow G$ 是最优路径，因此从 $n$ 到 $G$ 的真实最优代价等于单步代价加上后续的最优代价，即：

$$h^*(n) = c(n, n') + h^*(n')$$

由于 $h(n)$ 满足一致性，我们有：

$$h(n) \le c(n, n') + h(n')$$

根据归纳假设，我们知道 $h(n') \le h^*(n')$，将其代入上式不等式中，可得：

$$h(n) \le c(n, n') + h^*(n')$$

结合前面推导出的 $h^*(n) = c(n, n') + h^*(n')$，我们得出：

$$h(n) \le h^*(n)$$

**结论：**

由数学归纳法可知，对于状态空间中的任意节点 $n$，均满足 $h(n) \le h^*(n)$。因此，一致的启发式函数必定是可采纳的。证明完毕。
