## 1. `package main` (声明包名)

在 Go 语言里，所有的代码都必须从属于一个“包（Package）”。

- **在 C++ 中**：你可能会用 `namespace` 来组织代码，并且必须要有一个 `int main()` 函数作为程序的唯一入口。
    
- **在 Go 中**：`package main` 是一个非常特殊的声明。它等于是在告诉 Go 编译器：“**请把我编译成一个可以直接运行的独立程序（比如 .exe 文件），而不是一个给别人调用的代码库**”。 只要你声明了 `package main`，在这个文件里就必须包含一个 `func main()` 函数，作为程序启动的入口。
    

## 2. `import (...)` (导入依赖库)

这就完全等价于 C++ 里的 `#include <...>`。它用来把别人写好的、或者系统自带的工具箱搬到你的代码里来用。

在这段代码里，我们搬来了两个官方自带的工具箱：

- **`"fmt"` (Format 工具箱)**：
    
    - **全称**：Format（格式化 I/O）。
        
    - **作用**：负责在屏幕上打印文字，或者从键盘读取输入。
        
    - **C++ 对比**：就相当于 C++ 里的 `#include <iostream>`。后面代码里用到的 `fmt.Println("启动服务器...")` 就相当于 C++ 里的 `std::cout << "启动服务器..." << std::endl;`。
        
- **`"net"` (Network 工具箱)**：
    
    - **全称**：Network（网络操作）。
        
    - **作用**：这是 Go 语言最强大的杀手锏之一。它包含了所有与网络通信相关的底层逻辑（比如 TCP、UDP、Socket 编程）。有了它，你就不需要像在 C 语言或 C++ 里那样去调用底层操作系统繁琐的 `socket()`、`bind()` 函数了。
        
    - **C++ 对比**：在 C/C++ 环境下，你如果要写网络通信，可能需要 `#include <sys/socket.h>`、`#include <arpa/inet.h>` 等等一大堆底层操作系统的头文件。而在 Go 里，一个 `"net"` 包就把这些全搞定了。
        

**总结一下：** 这四行代码的意思就是：“**我要写一个能独立运行的程序（`package main`），为了完成任务，我需要用到屏幕打印工具（`fmt`）和网络通信工具（`net`）。**”
