## 🎯 题目深度解析

> 本题核心考点为**朴素贝叶斯分类器（Naive Bayes Classifier）**的参数估计与分类预测。通过极大似然估计计算先验概率和条件概率，并结合条件独立性假设对未知样本进行类别预测。

## 📝 详细解题步骤

### 1. 统计类别总数与计算先验概率 $P(C)$

首先统计训练数据中总样本数以及各类别（$C=1$ 和 $C=-1$）的出现频数。

- 总样本数 $N = 15$
    
- 类别 $C = 1$ 的样本数 $N_{C=1} = 9$（对应样本编号：3, 4, 8, 9, 10, 11, 12, 13, 14）
    
- 类别 $C = -1$ 的样本数 $N_{C=-1} = 6$（对应样本编号：1, 2, 5, 6, 7, 15）
    

由此计算各类的先验概率：

$$P(C = 1) = \frac{9}{15} = \frac{3}{5} = 0.6$$

$$P(C = -1) = \frac{6}{15} = \frac{2}{5} = 0.4$$

### 2. 计算目标特征在各类别下的条件概率

待预测样本为 $X = (3, S)^T$，即需要计算在不同类别下，特征 $X^{(1)} = 3$ 和 $X^{(2)} = S$ 的条件概率。

#### 当类别 $C = 1$ 时：

- 在 $C = 1$ 的 9 个样本中，统计 $X^{(1)} = 3$ 的样本数：
    
    - 满足条件的样本编号为：11, 12, 13, 14，共 4 个。
        
        $$P(X^{(1)} = 3 \mid C = 1) = \frac{4}{9}$$
        
- 在 $C = 1$ 的 9 个样本中，统计 $X^{(2)} = S$ 的样本数：
    
    - 满足条件的样本编号为：4，共 1 个。
        
        $$P(X^{(2)} = S \mid C = 1) = \frac{1}{9}$$
        

#### 当类别 $C = -1$ 时：

- 在 $C = -1$ 的 6 个样本中，统计 $X^{(1)} = 3$ 的样本数：
    
    - 满足条件的样本编号为：15，共 1 个。
        
        $$P(X^{(1)} = 3 \mid C = -1) = \frac{1}{6}$$
        
- 在 $C = -1$ 的 6 个样本中，统计 $X^{(2)} = S$ 的样本数：
    
    - 满足条件的样本编号为：1, 5, 6，共 3 个。
        
        $$P(X^{(2)} = S \mid C = -1) = \frac{3}{6} = \frac{1}{2}$$
        

### 3. 计算后验概率分子并进行分类决策

根据朴素贝叶斯的条件独立性假设，计算两类的后验概率（忽略共同的分母 $P(X)$）：

#### 计算 $C = 1$ 的概率得分：

$$P(C = 1) \prod_{j=1}^{2} P(X^{(j)} = x^{(j)} \mid C = 1) = P(C = 1) \cdot P(X^{(1)} = 3 \mid C = 1) \cdot P(X^{(2)} = S \mid C = 1)$$

$$\text{得分}_{C=1} = \frac{9}{15} \times \frac{4}{9} \times \frac{1}{9} = \frac{4}{135} \approx \mathbf{0.0296}$$

#### 计算 $C = -1$ 的概率得分：

$$P(C = -1) \prod_{j=1}^{2} P(X^{(j)} = x^{(j)} \mid C = -1) = P(C = -1) \cdot P(X^{(1)} = 3 \mid C = -1) \cdot P(X^{(2)} = S \mid C = -1)$$

$$\text{得分}_{C=-1} = \frac{6}{15} \times \frac{1}{6} \times \frac{3}{6} = \frac{3}{90} = \frac{1}{30} = \frac{4.5}{135} \approx \mathbf{0.0333}$$

### 4. 确定最终类标记

比较两者的计算结果：

$$\text{由于 } \frac{1}{30} > \frac{4}{135} \quad (\text{即 } 0.0333 > 0.0296)$$

根据最大后验概率（MAP）准则，将样本 $X = (3, S)^T$ 划分为概率值更大的那一类。

因此，样本 $X = (3, S)^T$ 的类标记为 **$-1$**。

## 💡 核心考点归纳

### 核心概念与公式

| **知识点**     | **定义 / 公式说明**                                                                                                                                                                                                      |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **条件独立性假设** | 朴素贝叶斯的核心假设。假设分类特征在类确定的条件下都是条件独立的。即：<br><br>  <br><br>$$P(X=x \mid C=c) = \prod_{j=1}^{n} P(X^{(j)}=x^{(j)} \mid C=c)$$                                                                                             |
| **极大似然估计**  | **先验概率：** $P(C = c_k) = \frac{\sum_{i=1}^{N} I(c_i = c_k)}{N}$<br><br>  <br><br>**条件概率：** $P(X^{(j)} = a_{jl} \mid C = c_k) = \frac{\sum_{i=1}^{N} I(x_i^{(j)} = a_{jl}, c_i = c_k)}{\sum_{i=1}^{N} I(c_i = c_k)}$ |
| **分类决策准则**  | **最大后验概率准则（MAP）：**<br><br>  <br><br>$$y = \arg\max_{c_k} P(C = c_k) \prod_{j=1}^{n} P(X^{(j)} = x^{(j)} \mid C = c_k)$$                                                                                            |

### 常见易错点 / 避坑指南

- **计数混淆（分母选择）**：计算条件概率 $P(X^{(1)}=3 \mid C=1)$ 时，分母必须是 **$C=1$ 的样本总数（9）**，而不是全局的总样本数（15），更不能是该特征取值的总数。
    
- **概率为0的极端情况（拉普拉斯平滑）**：若本题中某项条件概率计数为 0，在未要求平滑的情况下直接代入 0 乘积计算即可。若题目明确提到“拉普拉斯平滑（Laplace Smoothing）”，则分子需加 1，分母需加该特征的取值种数（如 $A_1$ 加 3，$A_2$ 加 3），考场上需审清题意。
    
- **最后通分或保留小数**：在比较最终分值大小时，建议保留统一的分母（如本题的 $\frac{4.5}{135}$ 与 $\frac{4}{135}$）或精确到多位小数，避免由于四舍五入导致决策错误。
