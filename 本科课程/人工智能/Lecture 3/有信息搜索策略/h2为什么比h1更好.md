
在A*搜索中，评价启发式函数好坏的核心标准是它对搜索空间的**剪枝能力**。我们一步步来推导为什么在八数码问题中，曼哈顿距离 $h_2$ 比不在位的棋子数 $h_1$ 更好：

**第一步：明确两者的可采纳性（保证最优性）** $h_1$ 和 $h_2$ 都没有高估到达目标的真实代价（要把不在位的棋子移动到正确位置上，每个错位棋子至少要移动一次；而任何移动能做的最多是把棋子向目标移近一步），因此它们都是可采纳的，都能保证A*算法找到最优解。

**第二步：证明 $h_2$ 的“优势”（Dominance）** 从定义很容易看出，对于任意节点 $n$，它的曼哈顿距离之和必定大于或等于错位的棋子数，即必定满足 $h_2(n) \ge h_1(n)$。在人工智能中，如果对所有节点都有 $h_2(n) \ge h_1(n)$，我们就称 **$h_2$ 比 $h_1$ 占优势（Dominance）**。

**第三步：推导优势转化为搜索效率的逻辑（核心证明题踩分点）** 这是期中考试极易考的证明推导题。为什么 $h_2(n) \ge h_1(n)$ 就意味着 $h_2$ 更好？

1. A_算法在寻找最优解 $C^_$ 时，必将扩展所有满足评估函数 $f(n) < C^*$ 的节点。
2. 将 $f(n) = g(n) + h(n)$ 代入，即算法一定会扩展所有满足 $h(n) < C^* - g(n)$ 的节点。
3. 因为对所有的节点都有 $h_2(n) \ge h_1(n)$，所以**任何被 $h_2$ 扩展的节点（即满足 $h_2(n) < C^* - g(n)$），必定也满足 $h_1(n) < C^* - g(n)$，从而必定也会被 $h_1$ 扩展**。
4. 反过来，由于 $h_1$ 估计的值更小，它还可能引起其他额外节点（那些满足 $h_1(n) < C^* - g(n) \le h_2(n)$ 的节点）的扩展。 **结论**：使用 $h_2$ 的A_算法**永远不会**比使用 $h_1$ 的A_算法扩展更多的节点。

**第四步：从有效分支因子 $b^*$ 和复杂度的角度分析**

- **时间与空间复杂度**：A*搜索的时间和空间复杂度在最坏情况下都是指数级的 $O(b^d)$，其中 $b$ 是分支因子，$d$ 是解的深度。
- **有效分支因子（Effective Branching Factor, $b^*$）**：$b^_$ 越接近1，说明由于启发式函数的引导，算法实际探索的分支越少，效率越高。由于 $h_2$ 占优势，它能极大地降低有效分支因子。例如，当解深度 $d=12$ 时，$h_1$ 的A_搜索平均扩展 227 个节点，而 $h_2$ 仅扩展 73 个节点；当深度 $d=24$ 时，$h_1$ 需扩展 39,135 个节点，而 $h_2$ 仅需扩展 1,641 个节点。

**第五步：从松弛问题（Relaxed Problem）的本质来理解（加分项）** 为什么 $h_2$ 能给出更大、更精确的估计值？因为 $h_2$ 对应的松弛问题保留了更多的原问题约束。

- $h_2$（曼哈顿距离）是通过仅仅去掉“B是空的”（即目标格子必须为空）这**一个**限制条件得到的松弛问题的解。
- $h_1$（不在位的棋子数）则是同时去掉了“A与B相邻”和“B是空的”这**两个**限制条件（意味着棋子可以直接“飞”到目标位置）得到的解。 约束条件去掉得越多，松弛问题就越简单，其解的代价就越低于原问题的真实代价。因此，$h_2$ 相比 $h_1$ 更加贴近真实的最小步数，对未来的预估更准确。

在考试中，如果被问及“为什么选择某个启发式函数”，直接写出 **“$h_2(n) \ge h_1(n)$ 构成优势（Dominance）”**，并推导 **“它能导致更少的扩展节点和更小的有效分支因子 $b^*$”**，即可拿满这道题的理论分析分！
