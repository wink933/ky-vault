
在4月19日的期中考试中，**A_搜索（A_ Search）** 是第三章“有信息搜索”的绝对核心，几乎100%会以计算大题和算法特性辨析题的形式出现。你必须对它的评价函数、四大特性以及展开步骤形成肌肉记忆。

### 🎯 核心考点一：评价函数 $f(n)$ 的构成

A*搜索的核心机制是结合了已经花费的代价和对未来的预估代价，以尽可能缩小总评估代价，其评价函数为： **$f(n) = g(n) + h(n)$**。

- **$g(n)$**：是从初始结点到达当前结点 $n$ 已经花费的实际路径代价。
- **$h(n)$**：是从结点 $n$ 到达目标结点的最小代价的估计值（即启发式函数）。
- **$f(n)$**：代表经过结点 $n$ 到达目标结点的最小总代价估计。

### ⚠️ 核心考点二：算法四大特性分析（必考背诵重点）

在考试的简答题或填空题中，当被问及A*算法的性能时，请直接写出以下结论：

1. **完备性（Completeness）**：**完备**。只要每步的行动代价都大于某个正的常数 $\epsilon > 0$，并且分支数 $b$ 是有限的，A*算法一定能保证找到解。
2. **最优性（Optimality）**：**最优**。但考试极爱考它的成立条件，必须严格区分：
    - 对于**树搜索**（Tree Search）版本，启发式函数 $h(n)$ 必须是**可采纳的（Admissible）**，即它绝不会高估到达目标的实际代价（$h(n) \le h^*(n)$）。
    - 对于**图搜索**（Graph Search）版本，启发式函数 $h(n)$ 必须是**一致的（Consistent/单调的）**，即满足三角不等式 $h(n) \le c(n, a, n') + h(n')$。
3. **时间复杂度（Time Complexity）**：最坏情况下是指数级的 **$O(b^\Delta)$** 或 $O(b^d)$。但一个好的启发式函数可以极大地降低“有效分支因子 $b^*$”，从而大幅减少实际搜索扩展的结点数。
4. **空间复杂度（Space Complexity）**：**$O(b^\Delta)$** 或 $O(b^d)$。由于A_算法需要将所有生成的结点保存在内存中（边缘集和探索集），指数级的空间需求是A_算法的主要缺点，通常在计算完之前就会耗尽内存。

### 📝 解题实战：一步步（Step-by-step）推导 A* 搜索步骤

**【经典考题模型】**：给定带有单步实际代价（如罗马尼亚地图的距离）和直达目标预估代价 $h$ 的状态图，要求用 A* 算法画出从起点 Arad 到终点 Bucharest 的搜索树展开过程。

**【标准大题推导步骤】**： _(考试时，每次扩展都必须在选定结点旁边清晰写出 $f(n) = g(n) + h(n)$ 的代入计算过程)_

1. **初始状态**：计算根结点 Arad 的评价函数 $f(Arad) = g(Arad) + h(Arad) = 0 + 366 = 366$。
    - 边缘队列 (Frontier) = `{Arad(366)}`。
2. **第一次选择**：弹出当前 $f$ 值最小的 Arad (366) 并扩展，生成子结点 Sibiu, Timisoara, Zerind。
    - $f(Sibiu) = 140 + 253 = 393$
    - $f(Timisoara) = 118 + 329 = 447$
    - $f(Zerind) = 75 + 374 = 449$
    - Frontier = `{Sibiu(393), Timisoara(447), Zerind(449)}`。
3. **第二次选择**：弹出当前最小的 Sibiu (393) 并扩展，生成 Arad, Fagaras, Oradea, Rimnicu Vilcea。
    - $f(Rimnicu Vilcea) = (140+80) + 193 = 413$
    - $f(Fagaras) = (140+99) + 176 = 415$
    - $f(Arad) = (140+140) + 366 = 646$
    - $f(Oradea) = (140+151) + 380 = 671$
    - Frontier = `{Rimnicu Vilcea(413), Fagaras(415), Timisoara(447), ...}`。
4. **后续关键步骤与陷阱**：
    - 算法会依次弹出 $f$ 值最小的 Rimnicu Vilcea (413) 和 Fagaras (415) 进行扩展。
    - 当扩展 Fagaras 生成目标结点 Bucharest 时，计算得到 $f(Bucharest) = (140+99+211) + 0 = 450$。
    - **【考场致命陷阱】**：此时绝对不能因为生成了 Bucharest 就终止算法！因为边缘队列中 Pitesti 的 $f$ 值为 $417$，小于 $450$，极有可能存在经过 Pitesti 的更优解。
    - 必须弹出 Pitesti (417) 并扩展，生成另一条通往 Bucharest 的路径，计算得到新路径的 $f(Bucharest) = (140+80+97+101) + 0 = 418$。
    - 因为 $418 < 450$（且此时 418 是队列中的最小值），最终算法弹出 $f=418$ 的 Bucharest 结点，在此刻执行目标测试成功，A* 算法正式结束并返回这条最优解路径。

熟练掌握 $f = g + h$ 的更新和**“绝不提早终止（必须等目标结点被选中弹出时才结束）”**的目标测试机制，期中考试这道综合大题你就能拿满分！
