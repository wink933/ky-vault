### 📌 考点定义：抽象矩阵多项式的相似映射

- **核心定义**：设 $A, B$ 是同阶方阵，若 $A \sim B$（即存在可逆矩阵 $P$，使得 **$P^{-1}AP = B$**），那么对于任意的多项式 $f(x) = a_kx^k + \dots + a_1x + a_0$，矩阵多项式 $f(A)$ 与 $f(B)$ 依然保持相似关系，记作 **$f(A) \sim f(B)$**。
- **核心恒等式**：映射的最直接代数体现是，**过渡矩阵 $P$ 保持绝对不变**，即 **$P^{-1}f(A)P = f(B)$**。

### 📐 几何意义与代数本质

- **几何直观（视角锁定的同步演化）**：相似关系 $A \sim B$ 本质上是"同一个线性变换在不同坐标系下的不同代数表现"（其中 $P$ 是观察视角的转换桥梁）。既然 $A$ 和 $B$ 在骨子里是同一个变换，那么当这个变换进行高次迭代（$A^k$）或线性组合（$f(A)$）时，它们在各自坐标系下的表现形式 $f(A)$ 和 $f(B)$ 必然发生**完全同步的映射**，且"观察的视角" $P$ 根本不需要改变。

### 📝 常用结论（张宇"联动共享定理"）

只要已知 $P^{-1}AP = B$，就可直接无脑推导出一系列相似映射结论：

1. **方幂映射**：$A^k \sim B^k$，且 $B^k = P^{-1}A^k P$。
2. **多项式映射**：$f(A) \sim f(B)$，且 $f(B) = P^{-1}f(A)P$。
3. **逆矩阵映射**：若 $A$ 可逆，则 $A^{-1} \sim B^{-1}$，且 $B^{-1} = P^{-1}A^{-1}P$。
4. **伴随矩阵映射**：$A^* \sim B^*$，且 $B^* = P^{-1}A^* P$。
5. **转置映射**：$A^T \sim B^T$（注意：转置的过渡矩阵会变成 $P^T$，即 $P^T A^T (P^T)^{-1} = B^T$）。

### 🔄 跨章节关联分析

- **关联"特征值与特征向量"**：若令 $B$ 为对角阵 $\Lambda$，即 $A \sim \Lambda$。那么 $f(A) \sim f(\Lambda)$。这意味着 $f(A)$ 也可以被同一个矩阵 $P$ 相似对角化，且 $f(A)$ 的特征值直接就是 $f(\lambda_i)$。
- **关联"矩阵的秩"**：因为相似必等价，等价必定同秩。所以从 $f(A) \sim f(B)$ 可以直接暴推出 **$r(f(A)) = r(f(B))$**。这在证明抽象多项式的秩的等式时是绝佳的桥梁。
- **关联"二次型"**：如果 $A, B$ 都是实对称矩阵且相似，那么它们必定也合同。此时多项式的演化同样保留了正负惯性指数的绝对一致性。

### 🎯 考题套路

- **套路一：利用 $P^{-1}(\dots)P$ 整体剥离化简**
    - _场景_：考题要求计算 $P^{-1}(A^3 - 2A^2 + 5E)P$。
    - _做法_：利用分配律和联动映射，直接将其合体转化为 $(P^{-1}AP)^3 - 2(P^{-1}AP)^2 + 5E = B^3 - 2B^2 + 5E$。将复杂的矩阵 $A$ 运算转化为更简单的对角阵 $B$ 的运算。
- **套路二：抽象相似判定**
    - _场景_：已知 $A \sim B$，问 $A^2 + A^{-1}$ 是否相似于 $B^2 + B^{-1}$？
    - _做法_：直接依据联动共享定理，它们不仅相似，连联系它们的桥梁都是同一个 $P$。

### ⚠️ 纠错警示（考场致命陷阱）

1. **特征向量的张冠李戴（极其致命）**：多项式演化 $A \to f(A)$ 时，**$A$ 和 $f(A)$ 完全共享特征向量**。但是，相似变换 $A \sim B$ 中，**$A$ 和 $B$ 绝对不共享特征向量！** $A$ 的特征向量是 $\xi$，$B$ 的特征向量会跟着坐标系改变变成 $P^{-1}\xi$。千万别把"共享过渡矩阵 $P$"和"共享特征向量"混为一谈！
2. **伴随矩阵的秩的断崖式判定**：如果考察 $A^* \sim B^*$ 的相关性质，务必先检查 $r(A)$。**若 $r(A) < n-1$，则 $A^*$ 直接是零矩阵，从而 $B^*$ 也必然是零矩阵**。不要在零矩阵上做无谓的复杂展开。
3. **多项式常数项的映射**：在将 $f(A)$ 转化为 $f(B)$ 时，多项式末尾的常数项 $a_0 E$，在两边乘上 $P^{-1}$ 和 $P$ 后，依然是 **$P^{-1}(a_0 E)P = a_0 E$**。常数项的系数绝不会因为相似变换而改变。

设 $A, B$ 为 $n$ 阶方阵，且 $A \sim B$，则下列结论**错误**的是（ ）。

A. $A^2 \sim B^2$  
B. $A^* \sim B^*$  
C. $A$ 与 $B$ 有相同的特征向量  
D. $r(A) = r(B)$

<details>

**答案：C**

**解析：**
- **A 正确**：根据联动共享定理，$A \sim B \Rightarrow A^k \sim B^k$。

<details>
<summary>👉 点击查看答案解析</summary>

**答案：$B^3 - 2B^2 + 5B - 3E$**

$$P^{-1}f(A)P = f(P^{-1}AP) = f(B)$$

**考点**：矩阵多项式的相似映射恒等式。

### 题目三：伴随矩阵与秩的判定（简答）

设 $A, B$ 为 $4$ 阶方阵，且 $A \sim B$。已知 $r(A) = 2$，求 $r(A^*)$ 和 $r(B^*)$。

<details>
<summary>👉 点击查看答案解析</summary>

**答案：$r(A^*) = 0$，$r(B^*) = 0$**

**解析：**
根据伴随矩阵秩的判定公式：
$$r(A^*) = \begin{cases} n, & r(A) = n \\ 1, & r(A) = n-1 \\ 0, & r(A) < n-1 \end{cases}$$

本题中 $n = 4$，$r(A) = 2 < 4-1 = 3$，所以：
$$r(A^*) = 0 \Rightarrow A^* = O$$

又因为 $A \sim B \Rightarrow A^* \sim B^*$，相似矩阵同秩，所以：
$$r(B^*) = r(A^*) = 0 \Rightarrow B^* = O$$

**考点**：伴随矩阵秩的断崖式判定（笔记中的陷阱二）。
</details>

### 题目四：特征值与多项式（计算）

设 $A$ 为 $3$ 阶方阵，特征值为 $\lambda_1 = 1, \lambda_2 = 2, \lambda_3 = 3$。令 $f(x) = x^2 - 3x + 2$，求 $f(A)$ 的特征值。

<details>
<summary>👉 点击查看答案解析</summary>

**答案：$0, 0, 2$**

**解析：**
根据联动共享定理的跨章节关联：
若 $A \sim \Lambda = \text{diag}(\lambda_1, \lambda_2, \lambda_3)$，则 $f(A) \sim f(\Lambda) = \text{diag}(f(\lambda_1), f(\lambda_2), f(\lambda_3))$。

计算各特征值：
- $f(\lambda_1) = f(1) = 1^2 - 3 \times 1 + 2 = 0$
- $f(\lambda_2) = f(2) = 2^2 - 3 \times 2 + 2 = 0$
- $f(\lambda_3) = f(3) = 3^2 - 3 \times 3 + 2 = 2$

所以 $f(A)$ 的特征值为 **$0, 0, 2$**。

**考点**：多项式映射下特征值的传递性。

### 题目五：综合应用（证明）

设 $A, B$ 为 $n$ 阶方阵，且 $A \sim B$。证明：$A^2 + A^{-1} \sim B^2 + B^{-1}$（假设 $A, B$ 均可逆）。

<details>
<summary>👉 点击查看答案解析</summary>

**证明：**

已知 $A \sim B$，即存在可逆矩阵 $P$，使得 $P^{-1}AP = B$。

**步骤1：证明 $A^2 \sim B^2$**
$$P^{-1}A^2P = P^{-1}A \cdot AP = P^{-1}A \cdot P \cdot P^{-1}AP = (P^{-1}AP)(P^{-1}AP) = B^2$$
所以 $A^2 \sim B^2$。

**步骤2：证明 $A^{-1} \sim B^{-1}$**
由 $P^{-1}AP = B$，两边同时取逆：
$$(P^{-1}AP)^{-1} = B^{-1} \Rightarrow P^{-1}A^{-1}P = B^{-1}$$
所以 $A^{-1} \sim B^{-1}$。

**步骤3：证明 $A^2 + A^{-1} \sim B^2 + B^{-1}$**
利用线性性质：
$$P^{-1}(A^2 + A^{-1})P = P^{-1}A^2P + P^{-1}A^{-1}P = B^2 + B^{-1}$$

因此 $A^2 + A^{-1} \sim B^2 + B^{-1}$，证毕。

**考点**：联动共享定理的综合应用、相似关系的传递性。
</details>
