# CPU 的功能

---

## 📌 5.1.1 CPU 的核心功能

CPU 的核心功能是 **执行程序**。在程序运行过程中，可能会遇到各类异常或外中断事件，如译码阶段发现非法操作码、外部设备发出中断请求等。因此，CPU 不仅需要高效执行指令，还要具备检测并响应各类异常与中断的能力。

其基本功能包括：

| 功能 | 说明 |
| --- | --- |
| **取指令并译码** | 从主存中取出指令，解析操作码，并生成相应的控制信号 |
| **更新程序计数器（PC）** | 确定下一条指令地址，以支持顺序执行或程序转移 |
| **执行算术与逻辑运算** | 通过 ALU 对操作数进行算术或逻辑运算 |
| **取操作数或写结果** | 访问主存或 I/O 接口，读取操作数或将运算结果写回 |
| **处理异常或中断** | 检测异常或中断请求，并在必要时转入相应的处理程序 |
| **时序控制** | 通过时钟信号协调各操作的执行顺序和持续时间，确保指令按序执行 |

---

## 📌 5.1.2 CPU 的基本结构

上述功能需求决定了 CPU 的内部结构组成。为实现完整的指令执行流程，CPU 必须包含若干关键功能部件：

- **指令控制**：程序计数器（PC）、指令寄存器（IR）、指令译码器（ID）
- **控制单元（CU）**：综合译码结果、时序信号与状态标志，生成微操作控制信号序列
- **数据通路**：算术逻辑单元（ALU）和通用寄存器组（GPRs）
- **中断机构**：响应异常与外部中断请求
- **存储器接口**：存储器地址寄存器（MAR）和存储器数据寄存器（MDR）

---

### 📌 主要功能部件说明

| 部件 | 功能说明 | 位数决定因素 |
| --- | --- | --- |
| **程序计数器（PC）** | 存放即将执行的指令地址。顺序执行时自动递增；遇到转移类指令时，更新为目标地址 | 地址总线宽度 |
| **指令寄存器（IR）** | 暂存当前正在执行的指令，供指令译码器使用 | 指令字长 |
| **通用寄存器组（GPRs）** | 暂存操作数、中间结果或地址指针，减少对主存的频繁访问 | 数据总线宽度 |
| **标志寄存器（FR）** | 保存 ALU 运算产生的状态信息，用于条件判断与转移控制 | 状态标志数量 |
| **存储器地址寄存器（MAR）** | 存放当前要访问的主存地址，通过地址总线传至存储器 | 地址总线宽度 |
| **存储器数据寄存器（MDR）** | 暂存从主存读出的数据或将要写入主存的数据，起到缓冲与同步作用 | 数据总线宽度 |
| **指令译码器（ID）** | 对 IR 中的操作码进行分析，识别指令类型，并输出对应的译码信号 | 指令字长 |
| **算术逻辑单元（ALU）** | 执行数据运算的核心部件，完成算术与逻辑运算 | 数据位宽 |

---

### 📌 其他关键部件

| 部件 | 功能说明 |
| --- | --- |
| **时序信号产生部件** | 以系统时钟为基础，生成指令执行所需的周期、节拍和工作脉冲 |
| **操作控制信号形成部件** | 综合译码信号、时序信号和状态标志，生成微操作控制信号 |
| **总线控制逻辑** | 实现对总线传输的控制，包括对数据和地址信息的缓冲与控制 |
| **中断机构** | 实现对异常情况和外部中断请求的处理 |

---

## 📌 5.1.3 CPU 中的寄存器分类

CPU 中的寄存器可根据 **汇编语言（或机器语言）程序是否能够直接访问**，分为两类：

---

### 1️⃣ 用户可见寄存器

这类寄存器可被用户程序直接读取或修改，用于暂存数据、地址或状态信息，从而减少对主存的访问次数，提高程序执行效率。

| 寄存器类型 | 说明 |
| --- | --- |
| **通用寄存器组（GPRs）** | 供用户程序灵活使用 |
| **专用地址寄存器** | 如基址寄存器、变址寄存器、堆栈指针等 |
| **程序计数器（PC）** | 存放下一条指令地址 |
| **标志寄存器（FR）** | 只读型，内容由 ALU 运算结果自动生成，用户程序不能直接修改其值 |

---

### 2️⃣ 用户不可见寄存器

这类寄存器对用户程序完全透明，既不能被读取，又不能被修改，仅由 CPU 硬件或操作系统内核在特权模式下使用。

| 寄存器类型 | 说明 |
| --- | --- |
| **指令寄存器（IR）** | 暂存当前指令 |
| **存储器地址寄存器（MAR）** | 存放访问主存的地址 |
| **存储器数据寄存器（MDR）** | 暂存主存读写数据 |
| **页表基址寄存器** | 用于虚拟内存管理 |

---

## 📌 核心要点总结

> 💡 **记忆口诀**：PC 存地址，IR 存指令，MAR 送地址，MDR 传数据，ALU 做运算，FR 记状态

| 分类 | 寄存器 | 用户可见 | 主要作用 |
| --- | --- | --- | --- |
| **程序控制** | PC | ✅ | 下一条指令地址 |
| **指令处理** | IR、ID | ❌ | 指令暂存与译码 |
| **数据运算** | GPRs、ALU、FR | ✅/❌ | 运算与状态记录 |
| **存储器接口** | MAR、MDR | ❌ | 主存访问缓冲 |
| **控制与中断** | CU、中断机构 | ❌ | 时序与异常处理 |

---

## 📌 易错点提示

| 易错点 | 正确理解 |
| --- | --- |
| PC 的位数 | 由地址总线宽度决定，反映可直接寻址的内存空间大小 |
| IR 的位数 | 等于指令字长，不是数据总线宽度 |
| FR 的访问权限 | 用户程序不能直接修改，只能由 ALU 运算结果自动生成 |
| MAR 与 MDR 的区别 | MAR 存地址，MDR 存数据 |
| 用户可见寄存器 | 包括 PC、GPRs、FR（只读），不包括 IR、MAR、MDR |
