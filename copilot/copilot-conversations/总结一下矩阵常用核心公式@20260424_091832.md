## 一、基本运算公式

| 运算类型 | 公式 |
| --- | --- |
| 矩阵加法 | $A + B = B + A$ |
| 矩阵乘法 | $A(BC) = (AB)C$ |
| 分配律 | $A(B + C) = AB + AC$ |
| 数乘结合 | $k(AB) = (kA)B = A(kB)$ |
| 转置运算 | $(AB)^T = B^T A^T$ |
| 转置性质 | $(A^T)^T = A$ |
| 逆矩阵转置 | $(A^{-1})^T = (A^T)^{-1}$ |

---

## 二、行列式相关公式

| 公式 | 说明 |
| --- | --- |
| $|AB| = |A||B|$ | 乘积的行列式等于行列式的乘积 |
| $|kA| = k^n|A|$ | $n$阶矩阵数乘 |
| $|A^T| = |A|$ | 转置不改变行列式 |
| $|A^{-1}| = \frac{1}{|A|}$ | 逆矩阵行列式 |
| $|A^*| = |A|^{n-1}$ | 伴随矩阵行列式 |

---

## 三、逆矩阵与伴随矩阵

| 公式 | 说明 |
| --- | --- |
| $AA^* = A^*A = |A|E$ | 逆矩阵与伴随矩阵关系 |
| $A^{-1} = \frac{1}{|A|}A^*$ | 逆矩阵计算公式 |
| $(A^{-1})^{-1} = A$ | 逆矩阵的逆 |
| $(AB)^{-1} = B^{-1}A^{-1}$ | 乘积的逆矩阵 |
| $(A^T)^{-1} = (A^{-1})^T$ | 转置与逆可交换 |

---

## 四、秩相关公式

| 公式 | 说明 |
| --- | --- |
| $r(A) = r(A^T)$ | 矩阵与其转置秩相等 |
| $r(AB) \le \min\{r(A), r(B)\}$ | 乘积秩不超过任一因子 |
| $r(A + B) \le r(A) + r(B)$ | 和的秩不超过秩的和 |
| $r(kA) = r(A)$ | $k \ne 0$时 |
| $r(A) = r(A^*)$ | 当 $r(A) = n$ 时 |
| $r(A) = r(A^T A) = r(AA^T)$ | 重要性质 |

---

## 五、特征值与特征向量

| 公式 | 说明 |
| --- | --- |
| $A\alpha = \lambda\alpha$ | 特征值定义 |
| $|A - \lambda E| = 0$ | 特征方程 |
| $\sum \lambda_i = tr(A)$ | 特征值之和等于迹 |
| $\prod \lambda_i = |A|$ | 特征值之积等于行列式 |
| $A^n \alpha = \lambda^n \alpha$ | 幂运算性质 |
| $A^{-1}\alpha = \frac{1}{\lambda}\alpha$ | 逆矩阵特征值 |

---

## 六、特殊矩阵性质公式

| 矩阵类型 | 核心公式/性质 |
| --- | --- |
| **对称矩阵** | $A = A^T$ |
| **反对称矩阵** | $A = -A^T$，主对角线全为0 |
| **正交矩阵** | $A^T A = E$，即 $A^{-1} = A^T$ |
| **数量矩阵** | $kE$，与任何矩阵可交换 |
| **秩为1矩阵** | $A = \alpha\beta^T$，$A^n = [tr(A)]^{n-1}A$ |

---

## 七、重要等式

| 公式 | 说明 |
| --- | --- |
| $A^* = |A|A^{-1}$ | 伴随与逆的关系 |
| $(A + B)^2 = A^2 + AB + BA + B^2$ | 注意乘法不可交换 |
| $E - A$ 可逆 $\iff$ $1$不是$A$的特征值 | 常用于证明题 |
| $A^2 = A \implies A$ 是幂等矩阵 | 幂等矩阵性质 |
| $A^2 = E \implies A$ 是对合矩阵 | 对合矩阵性质 |

---

## 📌 记忆小贴士

1. **行列式与秩**：$|A| \ne 0 \iff r(A) = n \iff A$ 可逆
2. **特征值与行列式**：特征值之积 = 行列式，特征值之和 = 迹
3. **转置与逆**：$(AB)^T = B^T A^T$，$(AB)^{-1} = B^{-1} A^{-1}$（顺序相反）
4. **秩为1矩阵**：$A = \alpha\beta^T$ 时，$A^n = (\beta^T\alpha)^{n-1}A$
