人工智能的定义是期中考试第一章的基础概念考点，通常以选择题、填空题或概念辨析题的形式出现。为了在4月19日的考试中准确拿分，你需要熟练掌握人工智能定义的四大类基本途径，以及课程教材所采用的核心视角。

**核心考点一：人工智能定义的四个维度** 关于人工智能的定义，主要沿着两个维度进行划分：一是关注**思维过程与推理**还是关注**行为**；二是根据**像人类一样**还是**合理地（追求正确或最佳结果）**来衡量。这就构成了人工智能的四种代表性观点：

1. **像人一样行动（图灵测试的途径）**：由阿兰·图灵提出，强调让计算机在行为表现上无法与人类区分。考试中常考的细节是，为了通过图灵测试，计算机必须具备四项能力：自然语言处理、知识表示、自动推理和机器学习。如果要通过包含物理交互的“完全图灵测试”，还需要加上计算机视觉和机器人学。
2. **像人一样思考（认知建模的途径）**：强调不仅要解决问题，还要让程序的推理轨迹与人类思维轨迹相同。这往往需要通过内省、心理实验或脑成像等方式来了解人类是如何思考的。
3. **合理地思考（“思维法则”或逻辑的途径）**：源于古希腊亚里士多德的三段论逻辑，强调利用精确的逻辑形式和推理程序来求解问题。但这一途径的考点在于它的局限性：不是所有问题都能轻易用严格的逻辑形式表示，且容易在推理时耗尽计算机资源。
4. **合理地行动（合理Agent的途径）**：这是追求在给定条件下，做出能实现最佳期望结果的行动。

**核心考点二：教材与课程的终极落脚点（必考重点）** 在答题时你必须明确指出：《人工智能：一种现代的方法》教材以及我们这门课程，都将人工智能的定义严格落脚在**“合理地行动”（Acting rationally）**上。

这在考试中具有统领全局的意义，因为无论是后续考察的 A*搜索、α-β 剪枝，还是贝叶斯网络，本质上都是在为不同环境下的智能 Agent 设计数学机制，从而帮助 Agent 在面临不确定性或有限计算资源时，依然能实现最佳的性能度量（即合理行动）。

**🔥 期中考试实战自测：** 为了检验你的理解，请看这道经典的概念辨析题：

> “如果在设计一个医疗诊断系统时，系统不仅要给出诊断结果，还要求其内部的诊断推理步骤必须与真正的人类医生的思考过程完全一致。请问这符合人工智能四种定义中的哪一种？”

**【Step-by-step 解题推导】：**

- **第一步，找线索**：题目强调了“推理步骤必须与真正的人类医生思考过程完全一致”。
- **第二步，套维度**：这属于关注“思维过程”（内部如何想）而非单纯的“行为结果”，并且是对标“人类（Humanly）”而非单纯的客观“合理性（Rationally）”。
- **第三步，得结论**：因此，这属于**“像人一样思考（认知建模的途径）”**。
