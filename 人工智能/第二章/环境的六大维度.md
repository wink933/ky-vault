人工智能中研究的任务环境可以定义数量相当少的维度来进行分类，这些维度在很大程度上不仅决定了适当的Agent设计，也是4月19日期中考试选择题和分析题的核心考点。根据教材和PPT，环境的六大核心维度（性质）如下：

**1. 完全可观察的与部分可观察的 (Fully observable vs. Partially observable)** 如果Agent的传感器在每个时间点上都能获取环境的完整状态，那么任务环境就是完全可观察的。完全可观察的环境非常方便，因为Agent不需要维护任何内部状态来记录外部世界。相反，如果由于噪音、不精确的传感器，或者传感器丢失了部分状态数据，环境就成为部分可观察的。

**2. 单Agent与多Agent (Single agent vs. Multi-agent)** 单Agent环境是指Agent独自运行，而多Agent环境是指环境中存在多个Agent同时运行。关键的区别在于，环境中的另一个实体（B）的行为是否在寻求让依赖于当前Agent（A）的性能度量值最大化或最小化。例如，下国际象棋时对手试图最小化A的性能度量，所以它是竞争性的多Agent环境；而出租车驾驶中避免发生冲撞能使所有Agent性能度量最大化，所以它是部分合作的多Agent环境。

**3. 确定的与随机的 (Deterministic vs. Stochastic)** 如果环境的下一个状态完全取决于当前状态和Agent执行的动作，那么我们说该环境是确定的；否则，它就是随机的。大多数现实环境（如出租车驾驶）相当复杂，难以跟踪到所有未观察到的信息，从实践角度考虑通常必须处理成随机的。

**4. 片段式的与延续式的 (Episodic vs. Sequential)** 在片段式的任务环境中，Agent的经历被分成一个个原子片段，在每个片段中Agent感知信息并完成单个行动，且下一个片段不依赖于以前的片段中采取的行动。例如，装配线上检验次品零件的机器人每次决策只需考虑当前零件，不用考虑以前的行动决策。与之相反，在延续式环境中（如下棋和出租车驾驶），当前的决策会影响到所有未来的决策。片段式的环境要简单得多，因为Agent不需要前瞻。

**5. 静态的与动态的 (Static vs. Dynamic)** 如果环境在Agent计算（思考）的时候会发生变化，那么我们称该环境是动态的；否则环境则是静态的。静态环境相对容易处理，因为Agent在决策时不需要顾虑时间的流逝。如果环境本身不随时间变化而变化，但是Agent的性能评价随时间变化，我们则称这样的环境是半动态的（Semi-dynamic）。

**6. 离散的与连续的 (Discrete vs. Continuous)** 环境的状态、时间的处理方式以及Agent的感知信息和行动，都有离散或连续之分。例如，国际象棋环境中的状态是有限的，其感知信息和行动也是离散的。而出租车驾驶则是一个连续状态和连续时间问题，车辆的速度和位置都在连续空间内变化，其驾驶行动（如转弯角度）也是连续的。

_(注：除了这六大基本维度外，教材中还提到了_*“已知的与未知的 (Known vs. Unknown)”**，但这严格来说指的是Agent的知识状态或它是否了解环境的“物理法则”，而不是环境本身的固有客观性质。)*

### 📝 “医疗诊断系统”的标准答案推导

#### 第一部分：PEAS 描述

在考试中写 PEAS，必须紧扣 Agent 与环境交互的四个维度：

- **P（性能度量 / Performance）**：病人的健康性、病人花费。
- **E（环境 / Environment）**：病人、医院、工作人员。
- **A（执行器 / Actuators）**：显示屏（用于提出询问、进行测试、给出诊断和治疗方案）。
- **S（传感器 / Sensors）**：键盘（用于输入症状、现场检测结果以及病人的回答）。

#### 第二部分：环境性质判定（附得分理由）

考试时如果只写出属性而不写理由是拿不到全分的。请参考以下标准分析逻辑：

1. **部分可观察 (Partially observable)**：系统无法直接获取病人身体内部的完整状态，只能通过外部症状、提问和化验结果来推断。
2. **单Agent (Single agent)**：在这个任务中，通常把病人的疾病过程当作 Agent 模型并不经济，因此常被列为单 Agent 环境。不过，如果考虑需要面对不听话的病人和疑心的职员，该环境也可以有多 Agent 的因素。
3. **随机的 (Stochastic)**：疾病的发展、病理反应和症状显现具有不确定性，同样的治疗在不同病人身上可能有不同的反应，下一个状态不是完全由系统当前行动决定的。
4. **延续式的 (Sequential)**：如果医疗诊断任务包括提出一系列的检验、对治疗过程的进展进行评价等，那么前一步的行动会严重影响后续的决策，问题环境就变成延续式的了。
5. **动态的 (Dynamic)**：在系统进行思考、计算或等待化验结果的过程中，病人的病情可能会随时间发生变化。
6. **连续的 (Continuous)**：病人的生理体征（如血压、体温的数值等）都是在连续空间内变化的。
