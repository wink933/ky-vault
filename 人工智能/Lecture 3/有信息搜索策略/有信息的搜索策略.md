
同学你好！距离期中考试越来越近了。在第三章中，**有信息（启发式）的搜索策略**是期中考试名副其实的“核心得分区”，特别是**A*搜索算法**的推导与**启发式函数**的性质分析，几乎是每年必考的计算大题。

有信息搜索策略的核心在于：它不仅使用问题本身的定义，还利用了额外的特定领域知识——即**启发式函数 $h(n)$**（结点 $n$ 到目标结点的最小代价估计值）来进行更有效的搜索。

为了应对考试，你必须精准掌握以下两大经典算法的特性分析，以及A*算法的推导过程。

---

### 🎯 核心考点一：贪婪最佳优先搜索 (Greedy Best-First Search)

- **核心机制**：评价函数 **$f(n) = h(n)$**。算法只看眼前，试图扩展离目标最近的结点（纯看预估代价）。
- **【必考特性分析】**：
    - **完备性**：**不完备**。在有限状态空间中，跟深度优先搜索类似，它可能会陷入死循环（如从A走到B，又从B走回A）；只有在避免重复状态的图搜索下在有限空间才完备，但在无限空间中不完备。
    - **最优性**：**不最优**。它目光短浅，找到的往往是次优路径。
    - **时间复杂度**：最坏情况下为 **$O(b^m)$**（$m$ 为最大深度）。
    - **空间复杂度**：最坏情况下为 **$O(b^m)$**（需要把所有结点保存在内存中）。

### 🎯 核心考点二：A* 搜索 (A* Search) —— 考试绝对重点

- **核心机制**：评价函数 **$f(n) = g(n) + h(n)$**。其中 $g(n)$ 是到达此结点已经花费的实际代价，$h(n)$ 是到目标的估计代价。$f(n)$ 即为经过结点 $n$ 到达目标的最小总代价估计。
- **【必考特性分析】**：
    - **完备性**：**完备**。前提是每步代价大于某个大于0的常数 $\epsilon$，且分支因子 $b$ 有限。
    - **最优性**：**最优**。这是A*最大的卖点（需要 $h(n)$ 满足特定条件，见下文考点三）。
    - **时间复杂度**：最坏情况下是指数级的 **$O(b^d)$** 或 $O(b^\Delta)$。但好的启发式函数可以大大降低“有效分支因子 $b^*$”，从而大幅提速。
    - **空间复杂度**：**$O(b^d)$**。这是 A* 算法的主要缺点，由于要保存所有生成的结点，内存通常会在计算时间耗尽前先被耗尽。

### ⚠️ 核心考点三：保证A*最优性的两大条件（必考简答/证明题）

在考试中，如果问到“A*搜索在什么情况下能保证找到最优解？”，你必须准确回答以下两点：

1. **可采纳性 (Admissibility)**：$h(n) \le h^*(n)$。启发式函数**绝不能高估**到达目标的实际代价。只要 $h(n)$ 是可采纳的，A*的**树搜索**版本就是最优的。
2. **一致性 (Consistency / 单调性)**：$h(n) \le c(n, a, n') + h(n')$。满足三角不等式，即当前结点到目标的估计代价，不大于单步实际代价加上子结点到目标的估计代价。如果 $h(n)$ 是一致的，A_的**图搜索**版本是最优的，且沿着任何路径的 $f(n)$ 值都是非递减的。_(注意：一致的启发式必定是可采纳的)*。

### 🎯 核心考点四：启发式函数的推导（松弛问题）

考试极爱考经典的**八数码问题（8-puzzle）**：

- **$h_1(n)$** = 不在位的棋子数（错位棋子数）。
- **$h_2(n)$** = 所有棋子到目标位置的曼哈顿距离之和（市街区距离）。
- **优势 (Dominance)**：对于任何结点，$h_2(n) \ge h_1(n)$。因此我们说 **$h_2$ 比 $h_1$ 占优势**。在考试中一定要写明：使用 $h_2$ 的 A* 搜索永远不会比使用 $h_1$ 扩展更多的结点，效率更高。
- **松弛问题 (Relaxed Problem)**：$h_1$ 和 $h_2$ 是怎么来的？是通过**减少行动限制**推导出来的。原规则是“棋子可移到相邻且为空的方格”。如果去掉“为空”的限制，代价就是 $h_2$；如果同时去掉“相邻”和“为空”的限制（即棋子可以随便飞），代价就是 $h_1$。松弛问题的确切代价就是原问题的可采纳启发式。

### 📝 解题实战：一步步 (Step-by-Step) 推导 A* 搜索过程

**【经典考题模型】**：给定罗马尼亚地图和各城市间的单步实际距离 $g$，以及各城市到目标 Bucharest 的直线距离 $h_{SLD}$，要求用 A* 算法推导从 Arad 到 Bucharest 的搜索树展开过程。

**Step-by-step 答题推导步骤**： _(考试时，必须在每个结点旁边清晰标出 $f(n) = g(n) + h(n)$ 的计算过程！)_

1. **初始状态扩展**：
    - 将起点放入边缘队列 (Frontier)。
    - 计算 Arad: $f(Arad) = g(Arad) + h(Arad) = 0 + 366 = 366$。
    - `Frontier = {Arad(366)}`。
2. **第一次选择**：
    - 弹出并扩展 Arad。生成子结点 Sibiu, Timisoara, Zerind。
    - $f(Sibiu) = g(Arad \to Sibiu) + h(Sibiu) = 140 + 253 = 393$。
    - $f(Timisoara) = 118 + 329 = 447$。
    - $f(Zerind) = 75 + 374 = 449$。
    - `Frontier = {Sibiu(393), Timisoara(447), Zerind(449)}`。
3. **第二次选择**：
    - 选择 $f$ 值最小的 **Sibiu(393)** 进行扩展。生成 Arad, Fagaras, Oradea, Rimnicu Vilcea。
    - $f(Fagaras) = g(Arad \to Sibiu \to Fagaras) + h(Fagaras) = (140+99) + 176 = 415$。
    - $f(Rimnicu Vilcea) = (140+80) + 193 = 413$。
    - `Frontier = {Rimnicu Vilcea(413), Fagaras(415), Timisoara(447), ...}`。
4. **第三次选择**：
    - 选择当前 $f$ 值最小的 **Rimnicu Vilcea(413)** 扩展。生成 Pitesti 等。
    - $f(Pitesti) = (140+80+97) + 100 = 417$。
    - `Frontier = {Fagaras(415), Pitesti(417), Timisoara(447), ...}`。
5. **第四次选择**：
    - 选择当前最小的 **Fagaras(415)** 扩展。生成 Bucharest。
    - **【核心得分点/易错点】**：此时 $f(Bucharest) = (140+99+211) + 0 = 450$。此时**绝对不能停止搜索**！因为 $450 > f(Pitesti)$ 的 $417$。必须把 Bucharest 加入队列继续！
6. **后续选择与终止**：
    - 接下来算法会扩展 **Pitesti(417)**，生成另一条到达 Bucharest 的路径：$f(Bucharest') = (140+80+97+101) + 0 = 418$。
    - 因为 $418 < 450$，算法发现了一条更优路径。最终弹出 $f=418$ 的 Bucharest 结点，执行目标测试成功，A* 算法结束并返回最优解。

掌握了 A* 的评价函数、四大特性、以及不提早终止的目标测试机制，这一章的计算大题分数你就已经稳稳拿下了！
