
**迭代加深的深度优先搜索（Iterative Deepening Search, IDS）**是期中考试第三章“无信息搜索”的绝对重点算法。它被设计出来的核心目的，是为了**完美结合宽度优先搜索（BFS）和深度优先搜索（DFS）的优点**。

### 🎯 核心考点一：算法运行机制

IDS 的工作原理是不断增大深度限制（首先设深度界限 $l=0$，接着设为 $1$，然后为 $2$，依此类推），在每一次迭代中调用**深度受限搜索（Depth-Limited Search, DLS）**，直到找到最浅的目标节点。简单来说，它就像是以 BFS 的层序扩展方式，一层一层地向下执行 DFS 操作。

### ⚠️ 核心考点二：算法四大特性（必考分析重点）

在期中考试里，如果题目要求分析 IDS 的性能，你必须毫无犹豫地默写出以下四点结论：

1. **完备性（Completeness）**：**完备**。只要分支因子 $b$ 是有限的，该算法一定能保证找到解。
2. **最优性（Optimality）**：**最优**。前提是单步行动代价相同，它总是能像 BFS 一样找到深度最浅的最优解。
3. **空间复杂度（Space Complexity）**：**$O(bd)$**（其中 $d$ 是目标节点的深度）。这是 IDS 最大的杀手锏！它保持了 DFS 的线性内存优势，只需保存一条从根节点到当前叶节点的路径，空间需求极小。
4. **时间复杂度（Time Complexity）**：**$O(b^d)$**。与 BFS 处于同一量级。

### 📝 解题实战：核心大题辨析与步骤推导

考试中经常会出一道经典的分析题：**“IDS 在每次增加深度限制时，都会把上层的节点重新生成一遍，这会不会导致时间严重浪费？”**

**【标准满分推导答法】**： 答案是**不会**。原因是，在分支因子相同（或近似）的搜索树中，绝大多数的节点都集中在底层，所以上层节点的重复生成对总时间的额外影响并不大。

我们结合老师课堂 PPT 上的具体公式进行一步步（step-by-step）推导验证：

1. 在迭代加深的深度优先算法中，底层（深度 $d$）节点只被生成 1 次，倒数第二层被生成 2 次，依此类推，直到根节点被生成 $d+1$ 次。
2. 迭代加深产生的节点总数公式为： $N(IDS) = (d+1) + (d)b + (d-1)b^2 + \dots + (1)b^d$
3. **代入具体数据（PPT 原题重现）**：当分支因子 $b = 10$，目标深度 $d = 5$ 时：
    - 单纯运行一次深度为 5 的深度受限搜索（DLS）产生的节点数为： $N(DLS) = 1 + 10 + 100 + 1,000 + 10,000 + 100,000 = 111,111$
    - 而使用迭代加深（IDS）产生的总节点数为： $N(IDS) = 6 + 50 + 400 + 3,000 + 20,000 + 100,000 = 123,456$
4. **得出结论**：如数据所示，$123,456$ 相比 $111,111$ 仅增加了约 11% 的额外代价，其时间复杂度依然稳稳保持在 $O(b^d)$ 量级。

**💡 考前冲刺一句话总结（可直接作答）**： **一般来讲，当搜索空间较大且不知道解所在深度时，迭代加深的深度优先搜索（IDS）是首选的无信息搜索方法。**
