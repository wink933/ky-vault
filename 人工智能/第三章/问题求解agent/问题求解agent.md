距离4月19日的期中考试越来越近了。我们正式进入第三章的核心考点：**问题求解Agent（Problem-solving Agent）**。

在考试中，问题求解Agent通常被设定为在一个确定的、可观察的、静态的和完全可知的环境中运行。这类Agent属于基于目标的Agent，它的核心特征是使用**原子（atomic）表示**，即把世界的状态视为一个整体，对搜索算法而言没有可见的内部结构（就像一个个黑盒子）。

### 🎯 核心考点一：问题求解Agent的工作流程

问题求解的完整工作流程可以精炼为以下四个步骤：

1. **目标形式化（Goal formulation）**：基于当前的情形和性能度量，确定Agent要达到的目标状态。
2. **问题形式化（Problem formulation）**：在给定目标下，确定Agent需要考虑哪些行动和状态，这一步必须去除无关细节进行抽象。
3. **搜索（Search）**：寻找一个从初始状态到达目标的行动序列作为解。
4. **执行（Execute）**：按照问题求解给出的解步骤逐一实施。

**【期中考试易错点辨析】**：在**执行阶段**，Agent是“闭着眼睛”的（这在控制理论中被称为开环系统）。因为假设环境是确定的和完全可知的，Agent十分确定每个行动的后果，所以它在执行计划时会**无视一切感知信息**。

### 🎯 核心考点二：良定义问题的5个组成部分（必考推导大题）

期中考试的大题经常会给出一个全新的场景（如罗马尼亚度假、八数码、传教士与野人过河等），要求你“对该问题进行精确形式化”。你必须在答卷上清晰列出以下5个部分：

1. **初始状态（Initial state）**：Agent开始时的状态（例如 `In(Arad)`）。
2. **行动（Actions）**：给定一个状态 $s$，Agent可以执行的动作集合 `ACTIONS(s)`。
3. **转移模型（Transition model）**：描述行动的后果，通常用函数 `RESULT(s, a)` 表示在状态 $s$ 执行行动 $a$ 后达到的新状态。 _(注：初始状态、行动和转移模型共同定义了问题的**状态空间**，即一个有向图)_。
4. **目标测试（Goal test）**：判断当前状态是否满足目标条件。
5. **路径耗散（Path cost）**：为每条路径赋予一个代价，通常是单步耗散（$c(s, a, s')$）的总和。所有解中路径耗散值最小的解称为**最优解**。

### 📝 解题实战：一步步（Step-by-Step）形式化“真空吸尘器世界”

针对你前面“直接给出答案”的要求，我为你直接演示考试中遇到**“真空吸尘器世界（Vacuum World）”**时的标准满分作答过程：

**题目背景**：只有A和B两个方格，每个方格都可能有灰尘，Agent位于其中一个方格。

**【标准形式化解答】**：

- **1. 初始状态**：8种可能状态中的任何一个都可被设为初始状态（如：Agent在方格A，且A和B都有灰尘）。
- **2. 行动**：每个状态下可执行的行动只有3个：向左移动（`Left`），向右移动（`Right`），吸尘（`Suck`）。
- **3. 转移模型**：行动会产生期待的后果。例如，在有灰尘的位置执行 `Suck` 会使该位置变干净；在最左边位置执行 `Left` Agent将保持在原地不动，在最右边位置执行 `Right` 同理。
- **4. 目标测试**：检查所有位置（方格A和B）是否都已经干净。
- **5. 路径耗散**：每执行一步行动（无论是移动还是吸尘）的耗散值为1，因此整个路径的耗散值就是行动的总步数。

掌握了如何定义问题，下一步就是利用搜索树来寻找解。期中考试接下来的绝对重头戏是各种搜索策略（如BFS、DFS、一致代价搜索，以及**A*搜索**），必须精准掌握它们的**完备性、最优性、时间复杂度 $O(b^d)$ 与空间复杂度**。
