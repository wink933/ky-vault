
最佳优先搜索（Best-First Search）是一般树搜索或图搜索算法的一个实例，其核心机制是**基于评价函数 $f(n)$ 的值来选择要扩展的结点**。在实现上，它将边缘结点集（Frontier）组织成一个按 $f$ 值升序排列的优先级队列，总是优先选择评估值最低的结点进行扩展。

在期中考试中，非贪婪的最佳优先搜索最核心的考点就是 **A_搜索（A_ Search）**。与只看预估代价的贪婪最佳优先搜索（$f(n)=h(n)$）不同，A*搜索综合考虑了已经花费的代价和对未来的预估代价，以缩小总评估代价。

### 🎯 核心考点一：A*搜索的评价函数

A*搜索的评价函数定义为 **$f(n) = g(n) + h(n)$**：

- **$g(n)$**：是从初始结点到达当前结点 $n$ 的实际路径代价。
- **$h(n)$**：是从结点 $n$ 到达目标结点的最小代价的估计值（即启发式函数）。
- **$f(n)$**：代表经过结点 $n$ 的最小代价解的估计代价。

这种设计既避免了贪婪搜索的短视（引入了 $g(n)$），又利用了启发信息来引导搜索方向（引入了 $h(n)$），从而尽可能高效地寻找最优解。

### ⚠️ 核心考点二：算法四大特性分析（必考重点）

在试卷上分析A*搜索的性能时，必须准确写出以下特性结论：

1. **完备性（Completeness）**：**完备**。只要每步的行动代价都大于某个正的常数 $\epsilon > 0$，并且分支数 $b$ 是有限的，A*算法一定能保证找到解。
2. **最优性（Optimality）**：**最优**。但考试时必须严格写明其成立的前提条件：
    - 对于**树搜索**版本，启发式函数 $h(n)$ 必须是**可采纳的（Admissible）**，即 $h(n)$ 绝不会高估到达目标的实际代价（$h(n) \le h^*(n)$）。
    - 对于**图搜索**版本，启发式函数 $h(n)$ 必须是**一致的（Consistent / 单调的）**，即满足三角不等式 $h(n) \le c(n, a, n') + h(n')$。
3. **时间复杂度（Time Complexity）**：最坏情况下是指数级的 **$O(b^d)$**（或 $O(b^\Delta)$，其中 $d$ 为解的深度）。但一个好的启发式函数可以极大地降低“有效分支因子 $b^*$”，从而大幅减少实际搜索所扩展的结点数。
4. **空间复杂度（Space Complexity）**：**$O(b^d)$**。由于A_算法需要将所有生成的结点保存在内存中，指数级的空间需求是A_算法的主要缺点，通常在计算完之前就会耗尽内存。

### 📝 解题实战：一步步（Step-by-Step）推导 A* 搜索步骤

**【经典考题模型】**：给定带有单步实际代价和启发式估计值的状态图（如罗马尼亚地图或八数码问题），推导 A* 搜索的展开过程。 _(注：考试时，每次扩展都必须在选定结点旁边清晰写出 $f(n) = g(n) + h(n)$ 的代入计算过程)_

**Step-by-step 答题推导步骤：**

1. **初始化**：利用问题的初始状态建立根结点 $Start$，计算其评价函数 $f(Start) = 0 + h(Start)$，并将其加入优先级队列 Frontier 中。
2. **选择结点**：从 Frontier 中弹出当前 $f(n)$ 值最小的结点 $n$ 进行扩展。
3. **目标测试**：在此结点被选择扩展时对其进行目标测试。如果它包含目标状态，算法终止并返回对应的最优解路径。
4. **扩展与计算子结点**：若 $n$ 不是目标结点，则生成其所有合法的后继结点 $n'$。
5. **更新评价函数**：对每个后继结点 $n'$，计算其实际代价 $g(n') = g(n) + c(n, a, n')$，并获取其启发式估计值 $h(n')$，从而得出 $f(n') = g(n') + h(n')$。
6. **加入队列查重**：将后继结点加入 Frontier 中。如果使用图搜索机制，当在 Frontier 中发现同一状态的旧结点时，若新到达该状态的 $f$ 路径代价更小，则必须用新结点替换掉旧结点。
7. **循环**：不断重复步骤 2~6，直至找到目标或 Frontier 为空（表明无解）。

记住，在 A* 搜索的推导大题中，**绝不能在目标结点刚刚生成时就终止搜索**，必须等到目标结点作为 $f(n)$ 值最小的结点被从队列中**弹出（选择扩展）**时，才能宣布找到最优解。
