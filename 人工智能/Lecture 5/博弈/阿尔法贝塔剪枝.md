同学你好！针对4月19日的90分钟期中考试，**$\alpha-\beta$ 剪枝（Alpha-Beta Pruning）**是第五章“对抗搜索（博弈）”中必考的压轴大题，通常要求你手画博弈树的展开过程，并清晰标记出剪枝位置和 $\alpha, \beta$ 值的传递。

极小极大（Minimax）算法的致命问题是需要检查的游戏状态数目随深度呈指数级增长。$\alpha-\beta$ 剪枝的核心思想是：我们可以有效地将指数增长减半，通过消除对部分分支的搜索（剪掉那些不可能影响最终决策的分支），依然返回和极小极大算法一模一样的结果。

### 🎯 核心考点一：剪枝参数与触发条件

在画图推导之前，你必须牢记这两个用来在路径上回传的参数的精确含义：

- **$\alpha$（Alpha）**：到目前为止路径上发现的 **MAX** 的最佳（即极大值）选择。
- **$\beta$（Beta）**：到目前为止路径上发现的 **MIN** 的最佳（即极小值）选择。

**【考场必背剪枝条件】**：

1. **在 MIN 结点**：如果当前探测到的值 $v \le \alpha$，则停止评估该结点的其他后继分支（直接返回 $v$）。因为 MAX 玩家在更上层已经有了一个更好的保底选择 $\alpha$，绝不会容忍你走到这个对 MAX 来说更差的结点。
2. **在 MAX 结点**：如果当前探测到的值 $v \ge \beta$，则停止评估（直接返回 $v$）。因为 MIN 玩家在更上层已经有了一个更好的保底选择 $\beta$，绝不会让你占到这么大的便宜。

### ⚠️ 核心考点二：算法四大特性分析（必考重点）

在试卷上分析 $\alpha-\beta$ 剪枝算法性能时，必须严格写出以下结论：

1. **完备性（Completeness）**：**完备**（前提是博弈树是有限的）。
2. **最优性（Optimality）**：**最优**。它依然返回和极小极大算法完全一样的最佳招数。
3. **时间复杂度（Time Complexity）**：很大程度上依赖于检查后继状态的顺序（行棋排序）。
    - **最坏情况**（最差排序）：完全没有剪枝发生，时间复杂度仍为极小极大算法的 **$O(b^m)$**。
    - **最佳情况**（最佳行棋排序）：算法只需检查 **$O(b^{m/2})$** 个结点来做出决策。这意味着它的有效分支因子从 $b$ 降到了 $\sqrt{b}$，在相同时间内 $\alpha-\beta$ 算法比极小极大算法向前预测大约两倍的步数。
4. **空间复杂度（Space Complexity）**：**$O(bm)$**。因为它本质上还是深度优先搜索，只需要保存一条路径和兄弟结点即可。

### 📝 解题实战：一步步（Step-by-Step）推导 $\alpha-\beta$ 剪枝过程

**【经典考题模型】**：给定一个三层博弈树，根结点为 MAX，第二层为三个 MIN 结点（记为 B、C、D），要求写出遍历更新过程，并标出哪条边被剪枝。

**【标准大题推导步骤】**：

1. **初始化**：算法深度优先地沿着最左侧路径向下走，根结点 MAX 将 $\alpha=-\infty, \beta=+\infty$ 传给左侧第一个 MIN 结点 B。
2. **处理左侧子树（B结点）**：
    - B 遍历它的第一个叶结点，得到值 3。此时 B 作为一个 MIN 结点，它的值至多为 3（即 $v \le 3$）。
    - B 继续遍历剩下的叶结点（假设为 12 和 8），更新其精确值为 $\min(3, 12, 8) = 3$。
    - B 将值 3 返回给根结点 MAX。此时 MAX 发现了一个保底收益 3，更新 **$\alpha = 3$**。
3. **处理中间子树（C结点）**：
    - 根结点将更新后的参数 $\alpha=3, \beta=+\infty$ 传给中间的 MIN 结点 C。
    - C 遍历它的第一个叶结点，得到值 2。此时 C 作为一个 MIN 结点，它的值至多为 2（即 $v \le 2$）。
4. **🔥🔥触发 $\alpha-\beta$ 剪枝🔥🔥**：
    - 在 C 结点，当前探测到的值 $v = 2$。
    - 因为 C 是 MIN 结点，它只会让这个值越来越小（$\le 2$）。然而，MAX 在之前已经找到了一个保底选择 $\alpha = 3$。
    - 由于 $v \le \alpha$（$2 \le 3$），MAX 绝对不会选择走到 C 分支。因此，**C 结点剩下的所有子结点都不需要再被计算，直接被剪枝**。
5. **处理右侧子树（D结点）**：
    - 根结点将 $\alpha=3, \beta=+\infty$ 传给右侧 MIN 结点 D。
    - D 遍历它的第一个叶结点，得到 14。D 的值至多为 14，因为 $14 > 3$（未满足 $v \le \alpha$），无法剪枝，继续探索。
    - D 遍历第二个叶结点，得到 5。D 的值至多为 5，因为 $5 > 3$，继续探索。
    - D 遍历第三个叶结点，得到 2。D 的确切值为 $\min(14, 5, 2) = 2$。
6. **最终决策**：
    - 根结点 MAX 在 B(3)、C(被剪枝定格在 $\le 2$)、D(2) 之间进行选择。
    - 最终 MAX 做出决策选择 B 结点分支，返回极小极大值 3。

在考试画图时，**务必在 C 结点的其余分支上画上大大的叉号“X”**，并在一旁批注写明 `因为 v=2 <= α=3，触发剪枝`。只要把参数传递和这个条件写清楚，你的步骤分就一分都不会丢。
