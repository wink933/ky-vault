### 结论

在计算机网络中，**网络核心（Network Core）**是由大量的网络以及连接这些网络的**路由器（Router）**相互连接构成的网状结构。

如果说网络边缘（端系统）的作用是运行应用程序并产生数据，那么网络核心的核心目标就是：**为网络边缘提供连通性和数据交换服务**，确保数据分组能够跨越异构网络，从源主机正确、高效地传输到目的主机。在现代互联网中，网络核心起关键作用的设备是路由器，其依赖的核心机制是**基于存储转发（Store-and-Forward）的分组交换（Packet Switching）**。

---

### 关键机制

网络核心的动态交互过程主要围绕**路由选择**与**分组转发**展开。当一个数据报文进入网络核心时，其数据流向和封装状态经历以下过程：

1. **物理层接收与解封：** 核心路由器从输入链路的物理层接收光电信号，将其还原为比特流，并上交给数据链路层。
2. **链路层校验与解封：** 数据链路层剥离 `MAC 帧头`和 `FCS 帧尾`，检查帧的完整性。若无差错，则将提取出的 `IP 数据报`（网络层 PDU）上交给网络层。
3. **网络层寻址（查表转发）：**
    - 路由器提取 IP 数据报首部中的**目的 IP 地址**字段。
    - 利用该目的 IP 地址与路由器内部的**转发表（Forwarding Table）**进行最长前缀匹配（Longest Prefix Match）。
    - 同时，路由器会将 IP 首部中的 **`TTL`（生存时间）字段减 1**，若 `TTL` 减为 0，则丢弃该报文并向源主机发送 ICMP 超时报文，以防止路由环路。
    - 若报文长度超过输出链路的 MTU（最大传输单元），且 `DF`（不分片）标志位为 0，路由器还会利用首部中的 `标识`、`标志`、`片偏移` 字段对 IP 数据报进行分片。
4. **重新封装与发送：** 确定输出端口后，报文被送往下移层。数据链路层使用**下一跳的 MAC 地址**（通过 ARP 动态解析获得）作为目的 MAC 地址，重新封装成新的 MAC 帧，最后经物理层发送至下一跳路由器。
5. **逐跳传递（Hop-by-Hop）：** 上述过程在网络核心的每一个路由器中不断重复。**注意：在此过程中，源和目的 IP 地址始终保持不变（除 NAT 外），而源和目的 MAC 地址在每一跳都会发生改变。**

### 协议与设备对比（表格化）

网络核心的主力设备是路由器，而网络边缘或局域网内部的主力设备是交换机。辨析两者的区别是 408 考试的极高频考点：

|**维度**|**路由器 (Router) - 网络核心设备**|**以太网交换机 (Switch) - 局域网设备**|
|---|---|---|
|**工作层次**|网络层（实现跨网段互联）|数据链路层（实现同网段互通）|
|**连接特性**|无连接（IP 协议，尽最大努力交付）|无连接（透明桥接）|
|**通信方式**|路由转发（单播/组播）|泛洪（广播/未知单播）/ 选路转发|
|**关键技术/算法**|路由协议 (OSPF/Dijkstra, RIP/距离向量)|逆向学习算法 (自学习 MAC 地址表), CSMA/CD|
|**冲突域/广播域**|**既隔离冲突域，又隔离广播域**|**隔离冲突域，不隔离广播域**|

### 易错/易混点

在 408 命题陷阱中，关于网络核心的考察常集中在以下几点：

1. **分组交换与电路交换的本质区别：**
    - 电路交换在通信前必须建立专用的物理通路，数据直达，无存储转发时延。
    - 分组交换（网络核心的实际应用）采用**存储转发**技术。路由器必须**完整接收**整个分组，进行差错校验后，才能向下一跳转发。这带来了**排队时延**和**处理时延**，并且在网络拥塞时可能会导致分组丢失（丢包）。
2. **端到端流量控制 vs 核心拥塞控制：**
    - **流量控制**是点对点的（如 TCP 的 `Window` 字段），存在于端系统之间，网络核心路由器不参与。
    - **拥塞控制**是全局性的，网络核心的拥塞状态（如路由器缓存溢出）会通过丢包或 ECN（显式拥塞通知）反馈给端系统，触发 TCP 的慢开始和拥塞避免算法。
3. **转发（Forwarding）与路由选择（Routing）的区分：**
    - **转发**是路由器内部的局部动作（数据平面），即根据转发表将分组从输入端口移到输出端口，时间极短（硬件实现）。
    - **路由选择**是网络全局的动作（控制平面），即多个路由器通过运行路由协议（如 OSPF、BGP）计算出转发表的选路过程，时间较长（软件实现）。

### 网络计算（性能量化）：分组交换时延分析

理解网络核心，必须掌握数据穿过核心路由器时的时延量化公式。

**核心公式：** $总时延 = 发送时延 + 传播时延 + 处理时延 + 排队时延$

- $发送时延 = \frac{分组长度 (L)}{链路发送速率 (R)}$
- $传播时延 = \frac{链路长度 (D)}{电磁波传播速率 (V)}$

**【推导算例】** 假设主机 A 通过一个网络核心路由器 R 连接到主机 B（拓扑：`A —— R —— B`，共 2 段链路）。 已知：分组大小 $L = 1000B$（字节），两段链路的带宽（速率）均为 $R = 100Mbps$，链路传播时延、处理时延与排队时延均忽略不计。

**求解：从 A 开始发送到 B 接收完该分组的总时间。**

- **单位换算严警提示：** 带宽 $R = 100Mbps = 100 \times 10^6\ bit/s$（速率用 $10^3$ 进位）；分组长度 $L = 1000B = 1000 \times 8\ bit = 8000\ bit$。
- **计算发送时延：** 每段链路的发送时延 $t_{send} = \frac{8000\ bit}{100 \times 10^6\ bit/s} = 8 \times 10^{-5}\ s = 0.08\ ms$。
- **动作时间轴追踪：**
    1. $T = 0$：A 开始发送分组。
    2. $T = 0.08\ ms$：A 发送完毕，此时路由器 R 刚刚**完整接收**该分组（存储转发机制）。
    3. $T = 0.08\ ms$：路由器 R 立刻开始向 B 发送该分组。
    4. $T = 0.08\ ms + 0.08\ ms = 0.16\ ms$：路由器 R 发送完毕，B 完整接收到该分组。
- **结论：** 忽略其他时延，单分组经过 1 个路由器（2 段链路）的总时延为 $2 \times 发送时延 = 0.16\ ms$。如果存在 $n$ 个同构路由器，则经过 $n+1$ 段链路，单分组总时延为 $(n+1) \times t_{send}$。
