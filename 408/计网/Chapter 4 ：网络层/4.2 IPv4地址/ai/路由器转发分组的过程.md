### 结论

路由器转发分组的核心过程是：将接收到的帧**解封**至网络层，提取**目的 IP 地址**，利用**最长前缀匹配（Longest Prefix Match）**原则在路由表中查找最优的下一跳，更新 IP 首部（如生存时间 TTL 和首部检验和），最后将分组**重新封装**为新的 MAC 帧向下一跳转发。

---

### 关键机制

路由器完整的数据流转与协议交互图景如下（请特别注意数据在各层的封装状态及地址变化）：

1. **数据接收与解封（下层到上层）：**
    - 路由器在其某个接口收到物理层传来的比特流，组装成数据链路层的 MAC 帧。
    - 检查 MAC 帧首部的**目的 MAC 地址**。若与该接口的 MAC 地址匹配，则接收并剥离 MAC 帧的首部和尾部（**解封**），将网络层的 IP 数据报送交路由器的处理模块。
2. **首部字段检查与修改（网络层处理）：**
    - **提取目的 IP 地址：** 路由器只根据目的 IP 地址（设为 `D`）来进行转发决策。
    - **更新 TTL（生存时间）：** 将 IP 首部中的 `TTL` 字段减 1。若 `TTL` 减至 0，则丢弃该分组，并向源主机发送 ICMP 超时差错报告报文。
    - **重算检验和：** 因为 `TTL` 发生了改变，路由器必须重新计算 IP 首部中的**首部检验和**字段。
3. **路由表查询（核心算法）：**
    - 采用 CIDR 编址时，路由表由“网络前缀”和“下一跳地址”组成。
    - 路由器将目的 IP 地址 `D` 与路由表中各个表项的子网掩码进行**按位与（AND）**操作，得到网络地址。
    - **查找顺序：** 特定主机路由 -> 网络路由 -> 默认路由。
    - **最长前缀匹配：** 若有多个表项匹配成功，路由器必须选择网络前缀最长（即子网掩码中 1 的个数最多）的路由，因为前缀越长，路由越具体。
4. **重新封装与发送（上层到下层）：**
    - 确定了下一跳的 IP 地址和出口接口后，路由器需要将 IP 数据报交递给数据链路层。
    - 通过 **ARP 协议** 查出下一跳 IP 地址对应的 **MAC 地址**。
    - 在数据链路层，将 IP 数据报**重新封装**成新的 MAC 帧。**此时报文的首部状态发生关键变化：**
        - **源 IP / 目的 IP：** 始终**保持不变**（端到端寻址）。
        - **源 MAC：** 变为**路由器当前出口的 MAC 地址**。
        - **目的 MAC：** 变为**下一跳设备（路由器或目的主机）的 MAC 地址**（点到点寻址）。

---

### 易错/易混点

- **地址变化的终极辨析（必考陷阱）：**
    - 在普通的路由转发过程中，**IP 地址是不变的**（指引最终方向），而 **MAC 地址是逐跳改变的**（指引下一步该怎么走）。注意与 NAT 路由器区分开来，只有 NAT 路由器才会篡改 IP 地址。
- **最长前缀匹配 vs 首次匹配：**
    - 408 考题中常设陷阱：目的 IP 地址可能同时匹配多个路由表项（例如同时匹配 `/24` 和 `/25` 的网段）。切记不能匹配到一个就直接转发，必须遍历并选择掩码最长（`/25`）的那个表项。
- **默认路由与特定主机路由的表示：**
    - 默认路由的 CIDR 表示为 `0.0.0.0/0`，它只有在路由表中找不到任何匹配项时才会被使用。
    - 特定主机路由的 CIDR 表示为对应的 IP 地址后加 `/32`，即掩码全为 1，优先级最高。

### 示例 / 推导 / 拓扑结构

**【CIDR 路由表查找与最长前缀匹配算例】**

假设某路由器的路由表包含以下三个表项：

1. `192.168.2.0/24` （下一跳接口：Interface 1）
2. `192.168.2.128/25` （下一跳接口：Interface 2）
3. `0.0.0.0/0` （默认路由，下一跳接口：Interface 3）

**情况 A：** 收到目的 IP 为 `192.168.2.130` 的分组。

- 与表项 1 的掩码（255.255.255.0）按位与：结果为 `192.168.2.0`，**匹配成功**。
- 与表项 2 的掩码（255.255.255.128）按位与：`130` 的二进制为 `10000010`，与 `128` (`10000000`) 逻辑与得到 `128`。结果为 `192.168.2.128`，**匹配成功**。
- **决策：** 因为表项 2 的前缀长度（`/25`）大于表项 1（`/24`），根据**最长前缀匹配**原则，选择 Interface 2 转发。

**情况 B：** 收到目的 IP 为 `192.168.2.50` 的分组。

- 与表项 1 按位与：结果为 `192.168.2.0`，**匹配成功**。
- 与表项 2 按位与：`50` 的二进制为 `00110010`，与 `128` (`10000000`) 逻辑与得到 `0`。结果为 `192.168.2.0`，与表项的 `192.168.2.128` 不一致，**匹配失败**。
- **决策：** 只有表项 1 匹配，从 Interface 1 转发。
