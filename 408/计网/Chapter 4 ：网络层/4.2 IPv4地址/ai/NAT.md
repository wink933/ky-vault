### 结论

**NAT（Network Address Translation，网络地址转换）** 是一种将专用网络（局域网）内的**私有 IP 地址**映射为**全局公有 IP 地址**的技术。它的核心作用是缓解 IPv4 地址耗尽的问题，使得多个内网主机能够“共享”一个或少量公网 IP 地址来访问 Internet。

---

### 关键机制

- **私有 IP 地址空间：** IANA 预留了三块专用的私网地址段，这些地址只能在局域网内使用，**路由器遇到目的地址为私有 IP 的分组会直接丢弃**，不予在公网上转发。
    - A 类：`10.0.0.0` ~ `10.255.255.255` (1个A类网)
    - B 类：`172.16.0.0` ~ `172.31.255.255` (16个B类网)
    - C 类：`192.168.0.0` ~ `192.168.255.255` (256个C类网)
- **NAPT（网络地址与端口号转换）：** 实际网络中最常用的 NAT 形式。它不仅转换 IP 地址，还利用**传输层的端口号**来进行区分，使得多个私有 IP 主机可以通过同一个公有 IP 的不同端口号同时访问外网。
- **报文首部篡改（封装/解封状态）：**
    - **IP 首部：** 源 IP（出网时）或目的 IP（入网时）被修改。
    - **传输层首部（TCP/UDP）：** 源端口（出网时）或目的端口（入网时）被修改。
    - **校验和：** 因为 IP 和端口号都发生了变化，NAT 路由器必须重新计算 IP 首部校验和以及 TCP/UDP 报文段的校验和。

**【NAT 动态交互与数据流向过程】** 假设内网主机向公网服务器发送请求，数据在网络中的流转与 NAT 解析步骤如下：

1. **内网发送（主机 -> NAT路由器）：** 内网主机生成报文。此时报文首部状态为：`源 IP = 私网 IP`，`源端口 = x`；`目的 IP = 公网服务器 IP`，`目的端口 = y`。报文在数据链路层封装目标 MAC 为 NAT 路由器的内网接口 MAC。
2. **出网转换（NAT路由器 -> 公网）：** NAT 路由器接收报文，解封至网络层和传输层，检查其 NAT 转换表。若无记录则新建表项，将报文首部修改为：`源 IP = NAT路由器的公网 IP`，`源端口 = 新分配的端口 z`。重新计算校验和后，将其转发到 Internet。
3. **公网响应（公网服务器 -> NAT路由器）：** 服务器处理请求并响应。此时返回报文首部为：`源 IP = 公网服务器 IP`，`源端口 = y`；`目的 IP = NAT路由器的公网 IP`，`目的端口 = z`。
4. **入网转换（NAT路由器 -> 内网主机）：** NAT 路由器收到响应，解封并查询 NAT 转换表，找到 `公网IP:z` 对应的 `私网IP:x`。将报文首部修改为：`目的 IP = 私网 IP`，`目的端口 = x`。重新计算校验和后，向内网转发，主机成功接收。

### 易错/易混点

- **工作层次陷阱：** 普通路由器仅工作在**网络层**（只看 IP 地址转发）；但 NAT 路由器因为需要查看和修改 TCP/UDP 的端口号，所以它实际上工作在**网络层和传输层**。
- **地址变化辨析：**
    - **普通路由转发：** 源 IP 和目的 IP 始终**不变**（端到端），只有 MAC 地址在逐跳**改变**（点到点）。
    - **NAT 路由转发：** 源 IP 或目的 IP 会发生**实质性改变**。这是 408 选择题中常考的根本区别。
- **通信连通性限制：** 普通 NAT 主要是“单向”的，即只能由内网主机主动发起连接。**外网主机无法主动向内网主机发起连接**（因为外网无法路由私有 IP），除非在 NAT 路由器上提前配置了静态端口映射（如暴露内网 Web 服务器）。

### 示例 / 推导 / 拓扑结构

**【NAPT 转换表推导算例】**

- **拓扑结构：**
    
    - 局域网内有两台主机：`主机A (192.168.1.10)` 和 `主机B (192.168.1.20)`。
    - NAT 路由器的公网接口 IP 为：`202.1.1.1`。
    - 两台主机同时使用端口 `3000` 访问公网同一台 Web 服务器 `8.8.8.8:80`。
- **NAT 路由器生成的转换表（NAPT 表项）：**
    

|WAN 端 (公网端)|LAN 端 (内网端)|说明|
|:--|:--|:--|
|`202.1.1.1 : 5001`|`192.168.1.10 : 3000`|主机 A 的映射|
|`202.1.1.1 : 5002`|`192.168.1.20 : 3000`|主机 B 的映射|

- **报文地址推导：** 当主机 A 发送数据时：
    
    - **转换前（局域网内）：** 源端 `192.168.1.10:3000` $\rightarrow$ 目的端 `8.8.8.8:80`
    - **转换后（Internet上）：** 源端 `202.1.1.1:5001` $\rightarrow$ 目的端 `8.8.8.8:80`
    
    服务器返回数据时：
    
    - **转换前（Internet上）：** 源端 `8.8.8.8:80` $\rightarrow$ 目的端 `202.1.1.1:5001`
    - **转换后（局域网内）：** 源端 `8.8.8.8:80` $\rightarrow$ 目的端 `192.168.1.10:3000`

通过 NAPT 表的端口区分（5001 vs 5002），NAT 路由器就能精准判断公网返回的报文到底该交给主机 A 还是主机 B。
