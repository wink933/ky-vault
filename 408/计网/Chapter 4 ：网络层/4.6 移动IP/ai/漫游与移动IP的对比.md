### 结论

在 408 考纲中，**普通的网络漫游**（通常借助 DHCP 实现）与 **移动 IP** 技术的根本区别在于：**终端在跨网段切换物理接入点时，是否改变其原本的 IP 地址，以及是否会导致已建立的传输层（TCP）连接中断。**

普通漫游会获取新 IP，导致连接断开；而移动 IP 采用“代理注册+隧道封装”机制，使得终端能够保持永久 IP 不变，实现网络层的透明无缝切换。

---

### 关键机制

两者在网络漫游切换时的数据流转与动态交互过程有着本质差异：

**1. 普通漫游（非移动 IP）交互过程：**

- 移动主机进入新网络后，通过 DHCP 协议动态申请一个新的 IP 地址。
- **断连机制：** 由于 TCP 连接是由“源IP、源端口、目的IP、目的端口”四元组唯一标识的，源 IP 的突然改变会导致网络中原有的 TCP 连接被迫中断。应用程序（如大文件下载、视频会议）必须用新 IP 重新发起连接。

**2. 移动 IP 动态交互与数据流转（无缝切换）：** 移动 IP 定义了三个核心实体：**移动节点、归属代理（Home Agent）、外地代理（Foreign Agent）**。其流转过程如下：

- **阶段一（获取转交地址与注册）：** 移动节点到达被访网络（外地网络），向外地代理注册，并获得一个临时的**转交地址（Care-of Address）**。随后，通过外地代理向自己的归属代理注册该转交地址。
- **阶段二（外部通信发往移动节点——隧道封装）：**
    - 通信对端（外部节点）依然将数据发往移动节点的**永久 IP（归属地址）**。
    - 归属代理截获该数据报，并进行 **IP-in-IP 隧道封装**。
    - **报文封装状态变化：** `[ 新 IP 首部 (源=归属代理, 目的=转交地址) [ 原 IP 首部 (源=外部节点, 目的=永久 IP) [ TCP/UDP 数据 ] ] ]`。
- **阶段三（解封交付）：**
    - 外地代理收到隧道数据报后，剥离外层的新 IP 首部（解封），将内层的原 IP 数据报交付给移动节点。
- **阶段四（移动节点发往外部节点——直接发送）：**
    - 移动节点向外发送数据时，通常将其**永久 IP 作为源地址**，外部节点的 IP 作为目的地址，直接通过外地代理路由出去，**无须通过归属代理转发**。

### 协议对比（表格化）

| **维度**           | **普通网络漫游 (借助 DHCP)**      | **移动 IP 技术**                     |
| :--------------- | :------------------------ | :------------------------------- |
| **IP 地址变化**      | 动态改变为当前被访网络的 IP           | 保持**归属地址（永久 IP）不变**，隐藏转交地址       |
| **传输层 (TCP) 连接** | **被迫中断**（因源 IP 改变导致四元组失效） | **保持不断开**（对 TCP 层绝对透明，无缝切换）      |
| **核心支撑技术**       | DHCP 动态分配                 | 外地代理注册 + **IP-in-IP 隧道封装（隧道技术）** |
| **通信路由路径**       | 双向直接通信（对称路由）              | 存在不对称路由现象（外部发来经代理，发往外部通常直达）      |
| **网络开销与时延**      | 较小                        | 较大（存在额外的首部封装开销及绕路时延）             |

### 易错/易混点

- **“三角路由”陷阱（408 经典辨析）：** 在移动 IP 中，数据流向通常是**不对称的**。外部发来的数据必须先绕道“归属代理”，再走隧道发给“外地代理”；而移动主机发出去的数据，可以直接由外地网关发给目标。选择题中常考察这种“收发路径不一致”的特性。
- **地址可见性（层次混淆）：**
    - **传输层（TCP/UDP）及应用层**：始终只能看到**永久 IP（归属地址）**。它们完全不知道主机换了位置。
    - **网络层**：归属代理和外地代理必须使用**转交地址**来进行底层的真实隧道路由寻址。
- **转交地址的归属：** 转交地址既可以是外地代理的 IP 地址，也可以是通过动态分配给移动节点本身的地址（配置转交地址），但在 408 考试中，通常默认转交地址是指向**外地代理**的接口地址。
