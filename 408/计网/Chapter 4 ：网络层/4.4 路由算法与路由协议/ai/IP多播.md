### 结论

在 408 考纲中，**IP 多播（Multicast，也称组播）** 是一种允许一个或多个发送者发送单一数据包，通过网络节点（路由器）的复制，最终送达到多个接收者（多播组）的技术。

理解 IP 多播的核心在于掌握三个维度的映射与协议配合：**D 类 IP 地址的特性**、**IP 多播地址到 MAC 地址的截断映射机制**，以及**网际组管理协议（IGMP）的动态交互过程**。它能极大地节省发送者的 CPU 资源和网络链路的带宽。

---

### 关键机制

多播在网络层和数据链路层有着特殊的地址分配与封装规则，其完整的数据流转机制如下：

- **多播 IP 地址分配：**
    - 多播采用**D 类 IP 地址**，其高四位固定为 `1110`，地址范围是 `224.0.0.0` ~ `239.255.255.255`。
    - 多播数据报使用 **UDP** 协议传送（因为多播是一对多，无法使用面向连接的 TCP，且只提供尽最大努力交付）。
- **硬件多播（MAC 地址映射）：**
    - 在局域网中，IP 多播数据报最终需要封装成 MAC 帧才能在物理网络上传输。
    - IANA 规定，以太网多播 MAC 地址的高 24 位固定为 `01-00-5E`，且第 25 位固定为 `0`。
    - **截断映射：** 路由器或主机会提取 IP 多播地址的**低 23 位**，直接拼接在 `01-00-5E-0` 的后面，生成多播 MAC 地址。
- **IGMP 协议（网际组管理协议）动态交互：**
    - IGMP 用于让本地多播路由器知道局域网内是否有主机（的进程）参加或退出了某个多播组。
    - **阶段一（主动加入）：** 主机向某个多播组地址发送 IGMP 报文声明加入。本地多播路由器收到后，利用多播路由协议向外转发，将其纳入多播转发树。
    - **阶段二（周期探询）：** 本地路由器周期性发送 IGMP 询问报文。局域网内同一多播组的主机只要有**一个**响应即可（延迟响应与抑制机制），路由器据此得知该组仍然活跃。若连续探询无响应，则停止转发该组数据。

### 易错/易混点

这是 408 选择题中最常设陷阱的几个考点，请务必高度警惕：

- **多播地址的使用限制（必考避坑）：** IP 多播地址**只能作为目的地址**，绝对不能作为源地址！同时，它也不能用于 PING 命令的测试。
- **ICMP “四不发”陷阱：** 路由器或主机对具有多播地址的数据报**绝不发送 ICMP 差错报告报文**。如果多播包在传输中丢失或出错，就让它悄悄消失。
- **MAC 地址映射的“重叠/冲突”问题（计算陷阱）：**
    - D 类 IP 地址中，除了前 4 位固定，还有 28 位可用作多播组号。
    - 但在映射为 MAC 地址时，只取了低 23 位。
    - 这意味着 IP 地址中有 5 位（$28 - 23 = 5$）在映射时被无视（丢弃）了。因此，会有 $2^5 = 32$ 个不同的 IP 多播地址被映射到了**同一个** MAC 地址上。
    - **结论：** 收到多播 MAC 帧的主机网卡，在硬件层面无法彻底过滤掉不属于自己的多播数据，必须将其解封交至网络层，由 IP 层通过软件检查完整的目的 IP 地址来进行最终过滤。

### 示例 / 推导 / 拓扑结构

**【经典计算：多播 IP 地址到 MAC 地址的映射推导】**

此类题型在 408 统考中多次出现。假设给定一个 IP 多播地址 `224.215.145.230`，求其对应的太网多播 MAC 地址。

**推导流向：**

1. **地址转换与分析：** 将 IP 地址的后三个字节转换为二进制： `215` = `1101 0111` `145` = `1001 0001` `230` = `1110 0110` 完整 IP 结构：`11100000 . 11010111 . 10010001 . 11100110`
2. **执行 23 位截断：** 抛弃高 9 位（即 `11100000` 和次高字节的最高位 `1`），只提取最后的 23 位： `[抛弃1] 101 0111 . 1001 0001 . 1110 0110`
3. **计算低位十六进制：** 保留下来的低 23 位转换为十六进制为：`57-91-E6`。
4. **拼接固定前缀：** 将固定的以太网多播前缀 `01-00-5E` 与上述结果拼接。 **最终结果：`01-00-5E-57-91-E6`**。

_(反思验证：哪怕 IP 地址变成了 `225.87.145.230`，由于其低 23 位完全相同，最终计算出的 MAC 地址依然是 `01-00-5E-57-91-E6`。这就是前文提到的 32 个 IP 地址共享同一个 MAC 地址的直接体现。)_
