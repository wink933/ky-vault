### 结论

在介质访问控制（MAC）中，**CSMA（载波监听多路访问）协议**是在 ALOHA 协议的基础上引入了“载波监听”机制（即“先听后发”），以降低冲突概率并提高信道利用率。根据侦听信道及处理方式的不同，CSMA 协议被划分为三种类型：**1-坚持 CSMA**、**非坚持 CSMA** 和 **p-坚持 CSMA**。三者的核心区别在于**当检测到信道状态（空闲或忙）时所采取的后续动作策略**。

### 协议对比（表格化）

|**维度**|**1-坚持 CSMA**|**非坚持 CSMA**|**p-坚持 CSMA**|
|---|---|---|---|
|**工作层次**|数据链路层 (MAC子层)|数据链路层 (MAC子层)|数据链路层 (MAC子层)|
|**信道空闲时动作**|**立即发送**（概率为 1）|**立即发送**|以概率 **$p$ 发送**，概率 **$1-p$ 推迟**到下一时隙|
|**信道忙碌时动作**|**持续监听**，直至信道变为空闲|**放弃监听**，等待一个随机时间后再重新监听|**持续监听**，直到信道空闲再按概率 $p$ 策略执行|
|**冲突概率**|**最高**（多个站点同时监听并在空闲时同时发送必定冲突）|**较低**（随机等待错开了重传时间）|**折中**（取决于 $p$ 值的设定）|
|**信道利用率/延迟**|信道利用率高，传输延迟低|延迟较大，信道利用率低（可能存在多站点等待而信道空闲的情况）|结合前两者优点，有效折中|

_(注：数据参考来源表 3.1 三种不同类型的 CSMA 协议比较)_

### 关键机制

- **1-坚持 CSMA (1-persistent CSMA)：**
    - **监听逻辑：** 站点欲发送数据时，先监听信道。若信道空闲，则**立即发送**；若信道忙，则**持续监听**，直到信道变为空闲，立刻发送（“1-坚持”中的“1”表示信道一旦空闲，发送的概率为 1）。
    - **优缺点：** 避免了多节点均想发送时信道的空闲浪费；但致命弱点是，如果两个以上的节点在信道忙时都在等待，一旦信道变为空闲，它们必然会同时发送，导致 100% 发生冲突。
- **非坚持 CSMA (Non-persistent CSMA)：**
    - **监听逻辑：** 若信道空闲，立即发送；若信道忙，则**放弃监听**，并等待一个**随机时间**后再重新监听。
    - **优缺点：** 采用随机退避策略有效避免了多个站点同时侦听并在信道空闲时同时发送导致的冲突；代价是数据传输延迟增加，且可能出现在一段“随机等待”的时间内，信道其实已经空闲，却无人发送，降低了信道利用率。
- **p-坚持 CSMA (p-persistent CSMA)：**
    - **监听逻辑：** 主要用于时分信道。若信道空闲，则以概率 **$p$** 直接发送，以概率 **$1-p$** 推迟到下一个时隙再重新监听。若信道忙，则持续监听直至信道空闲，然后再次按照概率 $p$ 执行操作。
    - **优缺点：** 它是 1-坚持和非坚持的折中方案。既克服了 1-坚持容易引发重叠冲突的缺点，又克服了非坚持因随机等待导致的过长延迟问题。

### 易错/易混点

- **陷阱：CSMA 协议能“完全消除冲突”吗？** 不能。408 考题中经常考察，尽管 CSMA 引入了监听，但由于**电磁波在物理链路上的传播时延（记为 $\tau$）**，站点 A 检测到信道空闲并开始发送时，站点 B 可能刚好在此期间（信号还未到达 B）也检测到信道空闲并发送，从而产生冲突。
- **辨析：“监听”与“碰撞检测（CD）”的区别。** 这三种基础的 CSMA 协议**只有“发前监听”的功能，没有“边发边听（冲突检测）”的功能**。一旦发生冲突，发送站并不知道，它会将整个数据帧发送完毕，造成大量带宽浪费。后续引入的 CSMA/CD 协议才具备了冲突检测能力。
- **避坑：p-坚持 CSMA 的“推迟”逻辑。** 在 p-坚持 CSMA 中，如果节点以 $1-p$ 的概率决定推迟，它推迟的单位是一个**基础时隙**，并在下一个时隙到来时**重新评估信道状态并重新掷骰子**（而不是一直等到别人发完再发）。

### 示例 / 推导 / 拓扑结构

**【过程描述：三种协议在“信道拥挤”场景下的动态交互图景】**

假设当前总线上站点 A 正在发送一个长报文（信道为**忙**），此时站点 B 和站点 C 的网络层几乎同时下发了数据，需要通过 MAC 层发送：

1. **若采用 1-坚持 CSMA：**
    - B 监听，发现信道被 A 占用 $\rightarrow$ B 死死盯住信道（持续监听）。
    - C 监听，发现信道被 A 占用 $\rightarrow$ C 死死盯住信道（持续监听）。
    - A 发送完毕，信道转为**空闲**。
    - B 和 C 同时发现信道空闲，且由于是“1-坚持”，两者概率均为 1 地**立即发送数据**。
    - **结果：B 和 C 的报文在总线上发生严重冲突。**
2. **若采用 非坚持 CSMA：**
    - B 监听，发现忙 $\rightarrow$ B 放弃监听，自己设定一个随机定时器（如等 5ms）。
    - C 监听，发现忙 $\rightarrow$ C 放弃监听，自己设定一个随机定时器（如等 12ms）。
    - A 发送完毕。
    - B 定时器先结束，监听发现信道空闲，B **立刻发送**。
    - C 定时器随后结束，监听发现信道被 B 占用，再次退避。
    - **结果：成功错峰，避免了冲突，但存在一段空闲等待期。**
3. **若采用 p-坚持 CSMA（设 $p=0.3$）：**
    - B 和 C 监听，发现忙 $\rightarrow$ B 和 C 都持续监听。
    - A 发送完毕，信道**空闲**。
    - B 掷骰子落在 $0.3$ 内 $\rightarrow$ B **立刻发送**。
    - C 掷骰子落在 $0.7$ 内 $\rightarrow$ C 决定退避到下一个时隙。
    - **结果：B 成功发送。如果 B 和 C 恰好都落在 0.3 内，依然会发生冲突，但概率（0.09）已大大小于 1-坚持 CSMA。**
