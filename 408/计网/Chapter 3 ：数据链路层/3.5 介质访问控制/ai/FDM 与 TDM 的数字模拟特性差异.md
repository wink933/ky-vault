### 结论

在计算机网络物理层的信道复用技术中，**频分复用（FDM）** 本质上是一种模拟多路复用技术，最适合传输**连续的模拟信号**；而 **时分复用（TDM）** 本质上是一种数字多路复用技术，最适合传输**离散的数字信号**。

现代计算机网络更多地采用 TDM 而非 FDM，核心原因在于：TDM 传输的数字信号抗干扰能力极强，可以通过物理层中继设备进行**逐级再生整形**，从而避免了噪声干扰的积累；而 FDM 传输模拟信号时，放大器在放大信号的同时也会放大噪声，且多路信号间容易产生串扰，必须引入额外的“保护频带”导致带宽浪费。

---

### 关键机制

FDM 与 TDM 在处理数字/模拟信号时的底层物理流转与协议机制差异，可拆解为以下动态过程：

1. **多路信号的复用与隔离机制：**
    - **FDM（频带划分）：** 发送端将整个信道的总频带划分为多个子频带，每路模拟信号被调制到不同的高频载波上，在信道中**并行传输**。为了防止相邻子信道间的电磁波相互干扰，必须在子频带之间强行插入不传数据的**隔离频带（保护频带）**。
    - **TDM（时间划分）：** 发送端将信道的传输时间划分为等长的 TDM 帧，每个用户的数字比特流被放入固定的时隙中**串行传输**。由于数字信号（0和1）在时间维度上界限分明，不需要像频段那样留出物理缓冲带。
2. **信号衰减与抗干扰的物理层处理（解封/封装状态）：**
    - **数字信号的再生（TDM 优势）：** 数据在长距离链路中流转时必然衰减和畸变。TDM 链路上的节点（如中继器）在接收到衰减的数字信号后，会直接**判决并重新生成（再生+整形）**出极其干净的“0”和“1”脉冲，彻底滤除本段链路产生的噪声，**实现无误差的逐跳转发**。
    - **模拟信号的放大（FDM 劣势）：** FDM 链路上的节点（如放大器）在增强衰减的模拟波形时，无法区分原始波形与叠加在上面的背景噪声。因此，**噪声会随着传输距离的增加和放大次数的增多而被不断累积**。
3. **硬件电路的转换逻辑：**
    - 数字信号在 TDM 系统中比较容易利用数字逻辑电路实现时隙的分配、交叉和自动转换；而 FDM 需要复杂的模拟带通滤波器和调制解调器，设备成本高且不易微型化。

### 易错/易混点

针对 408 命题陷阱，关于 FDM 与 TDM 的特性差异需警惕以下考点：

- **陷阱：表面上的“信道利用率”错觉**
    - **辨析：** 从直观感觉上看，FDM 允许多个用户在同一时刻“同时”发送数据，似乎比 TDM（必须等待自己的时间片）能更好地利用信道传输能力。但实际上，**现代计算机网络极少使用 FDM，而是普遍采用 TDM（及其改进型 STDM）**。这是因为网络传输的主体是计算机生成的数字数据，TDM 天然契合数字信号的离散特性，且不需要耗费大量带宽去设置 FDM 必须的“隔离频带”。
- **陷阱：中继器 vs 放大器的功能混淆**
    - **避坑：** 在第 1 层（物理层）设备中，**放大器**（处理模拟信号）的作用是仅将信号的振幅同比例放大；而**中继器**（处理数字信号）的作用是“再生数字脉冲”，即将失真的信号还原为标准的 0/1 电平。TDM 的成功高度依赖中继器的再生能力。

### 协议/技术对比辨析

在 408 考纲定义的复用维度上，FDM 与 TDM 的核心特性对比如下：

|**维度**|**频分复用 (FDM)**|**时分复用 (TDM)**|
|---|---|---|
|**工作层次**|物理层 / 介质访问控制|物理层 / 介质访问控制|
|**连接特性**|无连接（预先划分好连续频带）|无连接（预先分配好固定时隙）|
|**通信方式**|广播介质上的**并行**多路划分|广播介质上的**串行**时序划分|
|**关键技术/算法**|载波调制、带通滤波隔离、隔离频带|周期轮询、时钟同步、脉冲再生|
|**冲突域/广播域**|从频率维度消除冲突，不隔离广播|从时间维度消除冲突，不隔离广播|
|**适用信号类型**|**模拟信号**（如传统有线电视、广播）|**数字信号**（如计算机网络比特流）|
|**抗干扰能力**|较弱（易受交调干扰，噪声会随放大积累）|**极强**（逐级再生整形，避免干扰积累）|

### 示例 / 推导 / 拓扑结构

**FDM 与 TDM 在长距离链路中的噪声累积推导模型**

假设存在一个跨越 3 个物理节点的长距离线性网络拓扑： `主机 A` $\rightarrow$ `节点 R1` $\rightarrow$ `节点 R2` $\rightarrow$ `主机 B`

- **场景 1：使用 FDM 传输模拟信号**
    
    1. 主机 A 发出原始信噪比为 $S/N$ 的波形数据。
    2. 信号传播到达 R1 时，叠加了第一段链路的噪声 $N_1$。R1 是一个模拟放大器，为了弥补信号衰减，它将 $(S + N_1)$ 整体放大 $k$ 倍，输出 $kS + kN_1$。
    3. 信号到达 R2 时，再次叠加第二段链路的噪声 $N_2$。R2 再次放大，输出 $k(kS + kN_1) + kN_2$。
    4. 到达主机 B 时，接收端看到的不仅仅是放大的原始信号，还有**被多次级联放大的累积背景噪声**。这种信噪比的恶化直接限制了 FDM 在大规模广域网中的级联深度。
- **场景 2：使用 TDM 传输数字信号**
    
    1. 主机 A 发出 `1011` 的标准数字电平信号（例如高电平为5V，低电平为0V）。
    2. 信号到达 R1 时，由于衰减和噪声，电平变成了 3.8V 和 1.2V。
    3. R1 作为**数字中继器**，通过判决门限（如 2.5V），将 3.8V 重新整形生成干净的 5V，将 1.2V 重新生成干净的 0V。第一段链路的噪声 $N_1$ 在此被**彻底清零**。
    4. R1 向 R2 发送全新的 `1011` 信号。整个过程无论经过多少跳路由器或中继器，只要噪声幅度未超过判决门限引起误码，到达主机 B 时的信号永远如初生般干净。这就是 TDM 及数字传输在现代计算机网络中取得统治地位的根本物理逻辑。
