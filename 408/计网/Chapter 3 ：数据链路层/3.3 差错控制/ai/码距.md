### 结论

在数据链路层的差错控制中，**码距（也称海明距离，Hamming Distance）**是衡量一种编码方案检错与纠错能力的核心量化参数。简单来说，两个等长码字之间的码距，就是它们对应位上不同的比特数。而对于整个网络协议的编码方案而言，其码距决定了接收方能在多大程度上发现（检错）甚至修复（纠错）传输过程中发生的比特翻转。

### 关键机制

- **单对码字的码距计算：** 对两个等长的位串进行**按位异或（XOR）运算**，结果中 `1` 的个数即为这两个码字的码距。
- **编码集的码距（全局性）：** 在一个包含多个有效码字（合法数据）的编码集中，**任意两个有效码字之间码距的最小值**，才被称为该编码系统的码距。
- **网络性能量化（检错与纠错能力公式）：** 设编码方案的码距为 $l$，能检测出的出错位数为 $d$，能纠正的出错位数为 $c$，则数据链路层差错控制的核心关系式为： **$l = d + c + 1$ （且要求 $d \ge c$）**
    - **仅检错（$c=0$）：** 若只需检测出 $d$ 位错误，编码方案的码距至少应为 **$d + 1$**。原理是：发生 $d$ 位比特翻转后，原本的有效码字绝不会变成另一个有效码字，接收方必能识别其为非法码字。
    - **仅纠错（$d=c$）：** 若要纠正 $c$ 位错误，编码方案的码距至少应为 **$2c + 1$**。原理是：即使发生了 $c$ 位改变，错误后的码字依然离原本正确的有效码字“距离最近”，接收方可借此唯一确定原始码字并自动纠正。

### 易错/易混点

- **陷阱：混淆“检测（Detect）”与“纠正（Correct）”的代价。** 408 考题中常考两者的区别：检错只需要确保出错后不变成其他合法码字（留出 $d+1$ 的缓冲即可）；而纠错不仅要发现非法，还要能明确推断出它原本是哪个合法码字（错误码字必须严格偏向原来的合法码字，故需留出 $2c+1$ 的距离）。
- **辨析：编码集码距的决定因素。** 题目若给定一组有效码字（如 `0000`, `0011`, `1100`, `1111`），计算该集合的码距必须遍历所有两两组合，找出**最小**的那一个差异值（本例中为2），切忌只比较某两个码字就下定论。

### 示例 / 推导 / 拓扑结构

**【码距计算与检错/纠错能力推导算例】**

1. **异或计算演示：**
    - 假设有两个合法码字 $A = 0110$ 和 $B = 0011$。
    - 进行按位异或运算：$011\underline{0} \oplus 0\underline{0}1\underline{1} = 0101$。
    - 结果中包含 2 个 `1`，说明这两个码字有 2 位不同，两者的码距为 2。
2. **编码设计推导：**
    - 假设某数据链路层协议需要能够**纠正 2 位比特错误**，且**同时能够检测出 3 位错误**。
    - **核心公式提取：** 已知纠错能力 $c=2$，检错能力 $d=3$。
    - **代入计算：** $l = d + c + 1 = 3 + 2 + 1 = 6$。
    - **结论：** 设计该底层编码方案时，其有效码字集合的最小码距至少必须设定为 6。
3. **退化推导（海明码常见考法）：**
    - 如果只要求该网络能纠正 2 位错误（此时默认 $d=c=2$），则所需最小码距 $l = 2 \times 2 + 1 = 5$。
