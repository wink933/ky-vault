在 408 考纲的“CPU 调度与上下文切换”这一节中，广义的**调度程序（Scheduler）**并不是一个单一的函数，而是由**排队器、分派器（Dispatcher）和上下文切换器**三个底层软件模块精密配合构成的复合体。理解它们之间的区别与流水线协作关系，是搞懂底层“控制权移交”的关键。

以下为你详细对比这三个组件的底层逻辑与核心考点：

### 结论

- **排队器**是“组织者”，负责将系统中所有就绪状态的进程按照特定策略组织成队列，为调度提供候选池。
- **分派器（分派程序）**是“执行者”，负责将 CPU 的控制权真正移交给被调度算法选中的那一个目标进程。
- **上下文切换器**是“搬运工”，在分派器的指挥下，负责完成底层硬件寄存器级别的数据保存与恢复工作。

---

### 关键机制（核心维度对比）

在 408 的命题视角下，这三个组件的职责对比如下表：

| **维度**   | **排队器 (Queuer)**    | **分派器 (Dispatcher)**       | **上下文切换器 (Context Switcher)** |
| :------- | :------------------ | :------------------------- | :---------------------------- |
| **核心职责** | 按照调度策略，将就绪进程放入就绪队列  | 根据选定结果，将目标进程从就绪队列移出并移交 CPU | 在剥夺和赋予 CPU 控制权时，搬运硬件级的现场数据    |
| **工作时机** | 当有进程状态转为“就绪态”时触发    | 当调度算法选出了“下一个要运行的进程”后触发     | 紧随分派器之后，发生于态切换和指令跳转的瞬间        |
| **设计定位** | 实施调度策略（Policy）的底层基础 | 实施进程切换机制（Mechanism）的指挥枢纽   | 实施进程切换机制的纯物理级别操作（寄存器读写）       |

#### 动态执行过程：上下文切换器的“两对”切换

408 极其喜欢在“上下文到底怎么切的”这里挖坑。当 CPU 控制权发生转移时，上下文切换器必须严格执行**序号列表**中的**两对**动作：

1. **第一对切换（旧进程 $\rightarrow$ 分派程序）：**
    - 将当前正在运行（被剥夺 CPU）的进程的上下文（PC、PSW、通用寄存器等）保存到该进程自己的 PCB 中。
    - 然后**装入分派程序的上下文**，让分派程序能够在 CPU 上运行起来，以便它去执行移交工作。
2. **第二对切换（分派程序 $\rightarrow$ 新进程）：**
    - 分派程序完成必要工作后，移出它自己的上下文。
    - 将新选中的目标进程的 PCB 中保存的 CPU 现场信息，原样装入 CPU 的各个物理寄存器中，最后跳转到新进程的代码处恢复执行。

### 易错/易混点

针对 408 统考中极其高频的调度陷阱，请对以下逻辑边界保持绝对清醒：

- **陷阱 1：上下文切换是一次性直接把旧进程的寄存器丢给新进程吗？（致死考点！）**
    - **辨析：绝对不是！** 如上文所述，旧进程和新进程之间**不能直接交接**。必须先切入内核的“分派程序”作为中转，这必然会产生两对上下文的保存与恢复操作。这种切换是非常耗费时间的系统开销。
- **陷阱 2：“分派器”本身需要上下文切换吗？**
    - **辨析：需要。** 分派器本身也是操作系统内核里的一段代码。要让它在 CPU 上运行去完成任务交接，它自己也必须被载入 CPU（占用寄存器和 PC），这就是为什么要有“第一对切换”。
- **陷阱 3：我们在前面学的调度算法（如先来先服务、时间片轮转），作用在哪个模块？**
    - **辨析：作用在“排队器”及调度决策逻辑上。** 算法决定了排队器如何对就绪队列进行排序，也决定了每次从队列头部挑选谁。但无论什么算法，最后“把人请上 CPU”的动作，永远是由分派器和上下文切换器以相同的机制完成的（体现了机制与策略分离）。

### 记忆提示

- **形象类比：“去大医院看病排队与叫号就诊”**
    - **排队器（导诊台护士）：** 根据你的病情严重程度（优先级），或者你挂号的先后顺序（先来先服务），把你安排在候诊大厅的椅子上排队，建立了一个**就绪队列**。
    - **分派器（诊室门口的叫号系统）：** 当医生看完上一个病人空闲时，系统决定下一个轮到你，把你从候诊大厅里叫出来，指示你走进 1 号诊室（**移出队列，准备移交 CPU 控制权**）。
    - **上下文切换器（交接动作）：**
        - _第一对切换：_ 上一个病人把他的病历本收起来放回自己包里（**保存旧进程上下文**），保洁阿姨进来收拾一下桌子并呼叫下一个（**装入分派程序上下文**）。
        - _第二对切换：_ 保洁阿姨退出去（**移出分派程序上下文**），你坐下，把你自己的病历本和化验单铺在桌子上，医生开始给你看病（**装入新进程上下文并执行**）。
