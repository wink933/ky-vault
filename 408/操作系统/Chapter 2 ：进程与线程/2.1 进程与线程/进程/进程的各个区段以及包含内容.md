
### 结论

在操作系统中，当程序被加载到内存运行时，操作系统会为其建立一个独立的**虚拟地址空间**，这被称为**进程的内存映像**。 一个进程的内存映像严格划分为多个区段，以实现指令、数据、动态内存及内核数据结构的安全隔离。其最核心的原则是：**代码段只读、数据段分类存储全局变量、堆栈负责动态伸缩、内核区严格保护**。

### 关键机制

结合经典的 C 语言程序，进程虚拟地址空间自下而上（从低地址到高地址，再到最高地址的内核区）的典型区段划分及内容对应如下：

1. **代码段（Text Segment / Code Segment）**
    - **内容**：存放程序的机器指令（如 `main` 函数及用户自定义函数的指令）、系统自动调用的初始化代码（`.init`）以及**只读常量**（`.rodata`，如字符串字面量 `"Hello World!"`）。
    - **特性**：通常是**只读**的，以防止程序在运行时意外修改或破坏自身的指令代码。
2. **数据段（Data Segment）**
    - **内容**：专门用于存放**全局变量**和**静态变量（static 变量）**。
    - **细分**：
        - **`.data` 段**：存放**已初始化**且初值非零的全局/静态变量（例如 `int x = 5;`）。
        - **`.bss` 段**：存放**未初始化**或初值为零的全局/静态变量（例如 `int y;`）。这部分在程序文件中不占实际空间，加载时由操作系统清零。
3. **堆（Heap）**
    - **内容**：用于存放程序运行期间**动态申请**的内存。例如 C 语言中通过 `malloc()` 分配的内存，或 C++ 中通过 `new` 创建的对象。
    - **特性**：堆的大小在程序加载时未定，运行时向**高地址**方向动态扩展。
4. **共享存储映射区（Memory Mapping Segment）**
    - **内容**：存放动态链接库（如 `printf()` 等标准库函数）的共享代码、或者通过 `mmap` 映射的共享内存与文件区。
5. **栈（Stack）**
    - **内容**：用于支持函数调用，存放**局部变量**、**函数参数**、**返回地址**以及部分寄存器状态。
    - **特性**：遵循后进先出（LIFO）原则。每调用一次函数，相关信息就会被压入栈中。栈向**低地址**方向动态扩展（即与堆的扩展方向相反）。
6. **内核区（Kernel Space） / 进程控制块（PCB）**
    - **内容**：存放操作系统的内核代码、内核数据结构以及该进程的**进程控制块（PCB）**。
    - **特性**：这部分属于进程虚拟地址空间的最高部分，**普通用户程序绝对不可见且无权直接访问**。进程必须通过系统调用陷入内核态才能由操作系统代为操作。

### 易错/易混点

针对 408 极爱考查的变量内存归属，必须死记以下陷阱：

- **陷阱 1：PCB 到底在哪里？（极高频）** 408 明确考查过：虽然 PCB 是进程存在的唯一标志，但它**绝对不存放在用户的虚拟地址空间中**，而是存放在受硬件保护的**内核空间**内。用户代码（如 C 语言指针）绝对无法访问自身的 PCB。
- **陷阱 2：指针变量与其所指数据的空间分离** 分析 `int *ptr = (int*)malloc(4);` 时，极其容易混淆！
    - `ptr` 本身是一个局部变量，它存放在**栈区（Stack）**。
    - `malloc(4)` 申请出来的那 4 个字节的物理存储空间，位于**堆区（Heap）**。
- **陷阱 3：字符串常量的归属** 例如局部声明 `char *str = "OS";`。局部指针变量 `str` 在**栈区**；但是字符串字面量 `"OS"` 并不在栈上，也不在数据段，而是位于代码段的只读数据区（`.rodata`）中。

### 典型计算示例（内存归属分析）

408 的综合题极常给出一小段 C 代码，要求写出各变量所在的内存区段。

- **代码场景**：
    
    ```
    int global_x = 0;              // 变量 1
    int global_y = 100;            // 变量 2
    void main() {
        int local_len = 50;        // 变量 3
        char *ptr = malloc(100);   // 变量 4 和 5
        ...
    }
    ```
    
- **归属分析与推理过程**：
    1. **变量 1 (`global_x`)**：全局变量，且初值为 0。属于**数据段的 `.bss` 区**（未初始化或零初始化区）。
    2. **变量 2 (`global_y`)**：全局变量，且初值非 0。属于**数据段的 `.data` 区**（已初始化区）。
    3. **变量 3 (`local_len`)**：在 `main` 函数内部定义的局部变量，随函数调用动态分配。属于**栈区（Stack）**。
    4. **变量 4 (`ptr` 变量本身)**：它是一个局部指针变量，保存着分配内存的地址。属于**栈区（Stack）**。
    5. **变量 5 (`malloc(100)` 分配的内存)**：程序员显式动态申请的 100 字节内存块。属于**堆区（Heap）**。
    6. _(额外补充)_：如果上述代码调用了 `scanf()` 或触发了时钟中断，硬件会自动将 `main` 函数的程序计数器（PC）和状态字（PSW）压入**内核区的内核栈**中进行断点保护。
