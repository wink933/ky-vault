在 408 考纲中，鼠标作为典型的**低速字符设备**，其工作流程是理解**“中断驱动 I/O 控制方式”**以及**“中断处理底层机制”**的最完美载体。它串联了 I/O 接口（控制器）、中断隐指令、内核态模式切换等诸多核心考点。

以下为你详细拆解以鼠标为例的 I/O 工作流程与 408 核心命题点：

### 结论

鼠标的工作流程严格遵循 **中断驱动 I/O 方式（Interrupt-Driven I/O）**。 其核心思想是：外设动作（机械信号）转化为电信号后，由 I/O 控制器缓冲并向 CPU 发出中断请求；CPU 不必死等，而是在**每条指令执行结束时**检测中断；一旦响应，CPU 会暂停当前程序，通过“硬件+OS内核”的协同，将鼠标数据从控制器寄存器读入内存。

---

### 关键机制（动态执行图景）

当你的手移动了一下鼠标，到屏幕上光标跟着移动，底层的动态执行步骤如下：

1. **物理采集与缓冲（外设与接口层面）：**
    - 鼠标本体（机械/光电部件）捕捉到移动或点击信号，将其转化为底层电信号传给主机。
    - 主板上的 **USB I/O 控制器** 接收到信号，将鼠标状态数据存入其内部的 **数据缓冲寄存器** 中。
2. **发出中断请求：**
    - 数据准备就绪后，I/O 控制器通过控制总线中的中断请求线（INTR），向 CPU 抛出一个**可屏蔽中断**请求。
3. **检测并响应中断（当前指令周期末尾）：**
    - CPU 在正常执行某用户程序的**当前指令结束之后**，检测到中断信号的存在。
4. **硬件隐指令执行（进入内核前奏）：**
    - **关中断：** CPU 硬件自动将状态寄存器（PSW）中的中断允许位清零，屏蔽其他新的可屏蔽中断，确保接下来的保存动作不被打断。
    - **保存断点：** 硬件自动将当前被中断程序的 **PC（程序计数器）和 PSW** 压入内核栈中保存。
    - **引出中断服务程序：** 硬件根据 I/O 控制器发来的中断号（向量），查询内存中的**中断向量表**，找到鼠标设备驱动程序的入口地址，并装入 PC。此时，CPU 已经切换至**内核态**。
5. **中断服务程序运行（软件层面）：**
    - **保存现场：** 操作系统内核通过入栈指令，保存当前被中断程序的通用寄存器数据（以防被驱动程序覆盖）。
    - **执行读数动作（核心 I/O）：** CPU 执行 `IN` 等端口指令，从 USB I/O 控制器的数据寄存器中，将鼠标移动的坐标数据**读取到主存的缓冲区**中。
    - **恢复现场并开中断：** 数据搬运完毕，内核从栈中恢复之前保存的通用寄存器，执行中断返回指令（如 `IRET`），硬件自动恢复 PC 和 PSW，同时**重新开中断**。CPU 切回用户态，继续执行原程序。

### 易错/易混点

针对 408 I/O 管理与中断系统的命题陷阱，你必须对以下几个细节保持绝对清醒：

- **陷阱 1：鼠标数据搬运是用 DMA 还是中断？（极高频）**
    - **辨析：** 408 选择题常考不同设备的控制方式。鼠标、键盘属于**低速、字符型设备**，数据量极小，因此采用**中断驱动方式**，每次中断由 CPU 亲自参与把数据读入内存。而磁盘等高速块设备才会使用 DMA（直接存储器存取），DMA 方式下 CPU 只在整块数据传输的开头和结尾才介入。
- **陷阱 2：“保存断点”与“保存现场”是谁干的？（计算机组成原理交叉考点）**
    - **辨析：**
        - **保存断点（PC、PSW）：** 是由 CPU **硬件**在执行“中断隐指令”时自动完成的，不需要操作系统写代码实现。
        - **保存现场（通用寄存器）：** 是由**操作系统内核**（中断服务程序的最开始）通过软件指令（如 PUSH）压栈保存的。
- **陷阱 3：CPU 是随时随地响应鼠标中断的吗？**
    - **辨析：绝对不是！** CPU 只能在**当前指令执行结束之后（即指令周期的最后一个阶段：中断周期）**才会去检查中断引脚。如果当前 CPU 正在执行一条很长的除法指令，它绝不会在指令执行到一半时响应鼠标。

### 记忆提示

- **形象类比：“老板审批文件与助理接快递（中断驱动）”**
    - **日常工作：** 老板（CPU）正在低头审批一份长文件（执行用户程序）。
    - **数据到达：** 楼下前台助理（USB I/O 控制器）收到了一个鼠标厂商寄来的小包裹（鼠标数据缓冲），助理在门口按了一下呼叫铃（发出 INTR 中断请求）。
    - **响应时机：** 老板**不会立刻停笔**，而是坚持把**当前这一句话写完（当前指令执行完毕）**，才抬头看是谁按铃。
    - **处理过程：** 老板喊了一句“谁都别进来（关中断）”，并在文件上夹了个书签（硬件保存 PC 断点）。老板起身去把包裹拿进屋（CPU 亲自读取数据），拿完后取下书签，继续坐下审批文件（恢复现场，开中断并返回）。
