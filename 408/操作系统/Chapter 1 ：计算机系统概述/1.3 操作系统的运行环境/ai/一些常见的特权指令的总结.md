### 结论

**特权指令（Privileged Instruction）** 是一类具有极高底层操作权限的机器指令，它们可能导致系统崩溃或被恶意篡改。为了保障系统的绝对安全，硬件（CPU）严格限制这类指令 **仅能在内核态（管态）下执行**。

---

### 关键机制（全景盘点）

书中按功能将特权指令进行了分类，以下为你全面列举：

1. **中断管理类指令**
    - **关中断指令 / 开中断指令：** 控制硬件是否响应外部中断请求。
    - **设置中断屏蔽字指令：** 用于调整不同中断的响应优先级和屏蔽状态。
    - **修改中断向量表指令：** 更改中断处理程序的入口地址映射。
2. **系统设备与底层控制类指令**
    - **启动外设 / 关闭硬件设备：** 直接对底层 I/O 设备发号施令的指令（即 I/O 操作指令）。
    - **停机指令 / 重启指令：** 改变整个物理机器运行状态的最高控制指令。
    - **存取特殊寄存器的指令：** 直接读写底层的控制寄存器或状态寄存器。
3. **处理机模式与状态切换类指令**
    - **修改模式位指令：** 直接修改程序状态字（PSW）来切换 CPU 的运行模式（例如强制从内核态切换到用户态）。
    - **返回用户态指令：** 操作系统处理完异常/中断后，将控制权交还给用户程序时的专门指令。
4. **内存、时间与进程管理类指令**
    - **置时钟（设置系统时钟）指令：** 修改系统的基准时间（直接影响进程调度的时间片分发）。
    - **修改虚存页表指令：** 直接操纵内存映射机制，更改页表内容。
    - **切换进程指令：** 强制剥夺当前 CPU 的执行权并进行上下文切换。
    - **分配系统资源 / 调整用户访问权限指令：** 更改系统资源归属或改变用户安全级别的操作。

### 易错/易混点

在 408 统考有关“指令分类”的选择题中，命题人极其喜欢用以下几个“障眼法”来挖坑：

- **陷阱 1：陷入指令（Trap/访管指令）是特权指令吗？（致死考点！）**
    - **辨析：绝对不是！它是非特权指令。** 陷入指令是一条专门供用户程序在**用户态**下调用的指令，其唯一作用是故意触发一个内部异常，从而“敲开内核的大门”，让 CPU 切入内核态。如果它是特权指令，用户态一执行就会被硬件判定为“非法指令”而直接杀掉该进程，根本无法完成系统调用！
- **陷阱 2：“读取时间”与“设置时钟”的权限差异**
    - **辨析：** **“设置系统时钟”** 会影响全局系统定时器和所有的调度逻辑，是绝对的**特权指令**。但用户程序调用 API 去**“读取（获取）当前时间”**，由于不影响系统安全，通常并不需要特权指令的权限。
- **陷阱 3：发生除零、地址越界等错误的操作，是因为执行了特权指令吗？**
    - **辨析：不是。** 诸如普通的整数除法（DIV）、跳转、加减乘除、数据传送等，都是非特权指令。即使它们在执行时发生异常（如除以零、缺页），那也是“执行非特权指令时引发了硬件中断/异常”，而不是因为它们本身是特权指令。
