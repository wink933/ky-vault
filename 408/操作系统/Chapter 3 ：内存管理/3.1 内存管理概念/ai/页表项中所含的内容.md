### 结论

**页表项（PTE, Page Table Entry）** 是操作系统实现 **逻辑页号向物理页框号映射** 的核心数据结构。

- **基本分页存储管理：** 页表项的核心内容仅为 **物理页框号（物理块号）**；
- **请求分页存储管理（虚拟内存）：** 为了配合请求调页与页面置换，页表项进行了功能扩充，包含 **物理页框号、状态位（存在位 P）、访问位（A）、修改位（M）、外存地址** 以及 **保护位** 等控制字段。

---

### 关键机制

一个完整的请求分页系统页表项结构（如 408 统考常考模型）包含以下核心字段：

- **1. 物理页框号（Physical Frame Number, PFN / 块号）：【核心映射字段】**
    - 记录该逻辑页在物理内存中对应的 **物理块（页框）起始编号**。与逻辑地址中的页内偏移量（W）拼接后即可得到真实的物理地址。
- **2. 状态位 / 存在位（Present / Valid Bit, P）：【缺页判断依据】**
    - **\(P = 1\)**：表示该页已调入主存，MMU 可直接进行地址转换。
    - **\(P = 0\)**：表示该页尚未调入主存（或已被换出），CPU 访问时硬件 MMU 自动触发 **缺页中断（Page Fault）**。
- **3. 访问位 / 引用位（Access / Referenced Bit, A）：【页面置换依据】**
    - 记录该页在近期内是否被访问过（读或写）。
    - CPU 读写该页时硬件自动将 \(A\) 位置 1。操作系统根据 \(A\) 位配合 **Clock / LRU 页面置换算法** 挑选最近未使用的页面淘汰换出。
- **4. 修改位 / 脏位（Dirty / Modify Bit, M）：【写回外存依据】**
    - 记录该页调入主存后是否被执行过 **写入/修改操作**。
    - **\(M = 1\)**：页面被修改过，换出淘汰时必须 **写回外存（对换区/磁盘）**；
    - **\(M = 0\)**：页面未被修改，换出淘汰时可 **直接丢弃/覆盖**，节省一次昂贵的磁盘 I/O 开销。
- **5. 外存地址 / 磁盘块号（Disk / Swap Block Address）：【调页定位依据】**
    - 指出该页在外存（如对换区或文件区）中的具体物理存储地址，供缺页中断处理程序将该页调入内存时使用。
- **6. 保护位 / 权限位（Protection Bits）：【访问控制】**
    - 记录该页的访问权限（如：只读 R、读写 RW、只执行 X），防止非法访问与越权写操作。

### 易错/易混点

针对 408 统考中关于页表项的高频命题陷阱，请保持绝对清醒：

- **陷阱 1：页表项中包含“逻辑页号”吗？（408 绝杀考点！）**
    - **辨析：不包含！** 逻辑页号在内存页表中是 **隐式索引**（类似于 C 语言数组的下标）。页表在内存中连续存放，第 \(i\) 个页表项的起始地址 \(= \text{页表始址 } F + i \times \text{页表项大小}\)，因此页表项内部 **不需要** 显式保存逻辑页号。
- **陷阱 2：页表项大小是随意规定的吗？**
    - **辨析：** 页表项大小必须能够存下物理内存的最大块号。在 408 计算题中，为了防止页表项跨越页面并保证内存对齐，页表项大小通常向上取整为 2 的幂次（例如物理块号需 20 位，即 2.5B，实际页表项通常设计为 **4B**）。
- **陷阱 3：TLB（快表）项与内存页表项的内容一样吗？**
    - **辨析：不一样！** TLB 是相联存储器（按内容并行查找），只存储部分活跃页表项。由于 TLB 中的项不是连续按页号排列的，所以 TLB 项中 **必须显式包含“逻辑页号（Tag）”**，才能进行比对与命中检测。

### 例子 / 推导 / 记忆提示

#### 1. 408 典型计算题型：计算页表项大小与地址拆分

- **已知条件：** 某 32 位系统（逻辑地址与物理地址均为 32 位），按字节编址，页面大小为 \(4\text{KB} = 2^{12}\text{B}\)。
- **物理块号位数推导：**
    - 物理块数 \(= \frac{4\text{GB}}{4\text{KB}} = 2^{20}\) 个 \(\rightarrow\) 物理页框号至少需要 **20 位**。
- **页表项结构与分配：**
    - 若取页表项大小为 **4B（32 位）**，其中高 20 位用于存储物理页框号；
    - 剩余的 \(32 - 20 = 12\) 位，恰好可以留给存在位 P、访问位 A、修改位 M、保护位等状态控制字段。

#### 2. 记忆口诀

- **物理块号指明路，页号隐式作下标；**
- **请求分页五标记：**
    - **存在位（P）判缺页，访问位（A）供淘汰，**
    - **修改位（M）决写回，外存地址拿数据，保护位定权限！**
