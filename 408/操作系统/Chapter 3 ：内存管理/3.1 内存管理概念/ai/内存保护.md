### 结论

内存保护（Memory Protection）是存储器管理的核心功能之一。其核心目的是：确保每个进程在自己独立的内存空间中运行，防止一个用户进程有意或无意地访问、破坏操作系统内核或其他并发运行的用户进程的内存数据。内存保护的越界检查必须由**硬件（MMU）**在访问内存的瞬间自动完成。

### 关键机制

根据内存分配方式的不同，408 大纲中常考的内存保护机制主要有以下几种（动态执行过程）：

**1. 连续分配方式下的保护机制** 在连续分配管理中，通常采用两种硬件寄存器组合来实现越界检查：

- **方法一：上、下限寄存器法**
    - 1）硬件中设置一对上限寄存器和下限寄存器，分别存放该用户进程在物理内存中的最高和最低地址。
    - 2）CPU 每次访问内存时，硬件自动将目标物理地址与这两个寄存器进行比较。
    - 3）若物理地址不在该区间内，则触发越界中断（内部异常）。
- **方法二：重定位寄存器与界地址寄存器法（最常用）**
    - 1）设置一个**重定位寄存器（基址寄存器）**存放进程的物理起始地址，一个**界地址寄存器（限长寄存器）**存放进程的最大逻辑地址。
    - 2）CPU 发出访问请求（给出逻辑地址）。
    - 3）硬件首先将**逻辑地址**与**界地址寄存器**进行比较。若逻辑地址 $\ge$ 界地址，则判定为越界，触发越界异常。
    - 4）若未越界，硬件将逻辑地址与重定位寄存器相加，生成最终的物理地址并访问内存。

**2. 分页存储管理下的保护机制** 在分页机制中，越界检查融入到了地址转换的第一步：

- 1）CPU 给出逻辑地址，硬件将其拆分为页号 $P$ 和页内偏移量 $W$。
- 2）硬件将页号 $P$ 与页表寄存器（PTR）中存放的**页表长度 $M$** 进行比较。
- 3）若页号 $P \ge$ 页表长度 $M$，说明该页号超出了进程的有效空间，立即产生越界中断。

### 易错/易混点

- **陷阱：是谁在进行越界检查？** 408 选择题极易在此挖坑。很多考生误以为是“操作系统软件”在检查。**错误！** 每条指令的访存频率极高，若由 OS 软件检查会导致系统彻底瘫痪。越界检查必须由**硬件（内存管理单元 MMU）**在每次地址转换时自动完成。操作系统只负责在进程切换时，把属于新进程的寄存器值（如基址/限长、页表基址/长度）加载到硬件寄存器中。
- **辨析：“越界中断” vs “缺页中断”**
    - **越界中断：** 属于致命错误（Abort/故障），说明进程试图访问不属于自己的逻辑地址空间，操作系统通常会直接强制终止该进程（报段错误 Segfault）。
    - **缺页中断：** 属于可恢复异常（Fault），说明进程访问的逻辑地址是合法的，只是该页数据暂时不在物理内存中。操作系统会将其从磁盘调入内存后，让进程继续执行。
- **陷阱：重定位寄存器 vs 界地址寄存器比较的对象。** 界地址（限长）寄存器比较的是**逻辑地址**（尚未转换的地址）；而上下限寄存器比较的是**物理地址**。

### 典型计算示例

**【利用基址与限长寄存器进行内存保护的计算】**

**变量含义：**

- $BR$：重定位寄存器（基址寄存器），进程物理内存的起始地址。
- $LR$：界地址寄存器（限长寄存器），进程允许访问的最大逻辑地址范围（即装入模块的长度）。
- $Logical_Addr$：CPU 发出的逻辑地址。

**计算与判断过程：** 假设操作系统将某用户进程调度上 CPU 运行，并在进程切换时设置了其硬件上下文： 物理基址 $BR = 20000$ ；限长 $LR = 5000$。

- **场景 1：合法访问** CPU 执行指令试图读取逻辑地址 $Logical_Addr = 1500$ 处的数据。
    
    1. 硬件比较：$1500 < LR\ (5000)$，**未越界**。
    2. 硬件计算物理地址：$Physical_Addr = BR + Logical_Addr = 20000 + 1500 = 21500$。
    3. 正常访问物理地址 21500。
- **场景 2：非法越界访问** CPU 执行指令，可能因为指针错误，试图读取逻辑地址 $Logical_Addr = 6000$ 处的数据。
    
    1. 硬件比较：$6000 \ge LR\ (5000)$，**发生越界！**
    2. MMU 立即阻断该访存请求，并向 CPU 发出越界陷入信号（Trap）。
    3. CPU 状态切换到内核态，操作系统接管并往往会撤销该违规进程，从而保护了物理地址 `26000` 处其他进程的数据绝对安全。
