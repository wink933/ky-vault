你好！我是你的 **408 操作系统复习助手**。

经历了“空闲表法”的碎片危机和“空闲链表法”的 I/O 惩罚与管理复杂性后，我们迎来了 408 外存空间管理中最优雅、考查频率最高的方案——**位示图法（Bitmap）**。它也是现代主流操作系统（如 Linux）底层广泛采用的空闲空间管理基石。

以下为你详细拆解位示图法的核心考点与必考计算：

### 结论

**位示图法**利用一串二进制位（Bit）来映射磁盘中每一个物理盘块的使用状态。 通常情况下，“0”表示对应的盘块空闲，“1”表示对应的盘块已分配（反之亦可）。这种方法将庞大的磁盘空间状态压缩成了一个紧凑的二维比特矩阵。

---

### 关键机制与执行过程

在 408 考纲中，位示图法最核心的机制就是**“盘块号”与“矩阵行列号”之间的相互转换**。系统通常将这串二进制位组织成一个 $m \times n$ 的二维数组（$n$ 通常为计算机的字长，如 16 或 32）。

#### 1. 盘块的分配过程

当文件系统需要分配空闲盘块时，动态执行流程如下：

1. **顺序扫描：** 操作系统在内存中顺序扫描位示图，寻找一个或一组其值为“0”的二进制位。
2. **坐标转换公式：** 假设找到的空闲位位于第 $i$ 行、第 $j$ 列，且每行有 $n$ 个位。利用公式将其转换为外存物理盘块号 $b$。
3. **修改位示图：** 将找到的位 `map[i, j]` 修改为“1”，表示该盘块已被占用。

#### 2. 盘块的回收过程

当文件被删除，需要释放盘块时，动态执行流程如下：

1. **获取盘块号：** 操作系统获取准备回收的物理盘块号 $b$。
2. **反向转换公式：** 将盘块号 $b$ 转换成位示图中的行号 $i$ 和列号 $j$。
3. **修改位示图：** 将对应的位 `map[i, j]` 重新清零（即改为“0”），完成回收。

#### 3. 优缺点剖析

- **优点：**
    - **占用内存极小，支持常驻：** 因为每个盘块只用 1 个 Bit 表示。几百 GB 的硬盘，其位示图大小不过几 MB，可以完全常驻内存，**查找空闲块时几乎不需要磁盘 I/O**。
    - **查找速度极快：** 可以利用位运算的高速特性，利用硬件指令一次扫描一个字（如 32 个盘块的状态）。
    - **极度灵活：** 它**既支持连续分配，也支持离散分配**。想连续分配就找连续的“0”，想离散分配就随便找散落的“0”。
- **缺点：** 当磁盘容量达到极大的 TB 级别时，位示图本身也会变大。但在现代内存容量下，这往往通过将磁盘分组（如 Linux 的块组）来解决。

### 易错/易混点

针对 408 的计算题命题陷阱，你必须对以下考法保持**绝对敏锐**：

- **陷阱 1：起始编号到底是从 `0` 还是从 `1` 开始？（生死陷阱）**
    
    - **辨析：** 408 经常在这个细节上“疯狂挖坑”。
    - **如果行号、列号、盘块号均从 `1` 开始**（王道教材默认基准）：
        - 已知 $(i, j)$ 求盘块号 $b$：**$b = n \times (i - 1) + j$**
        - 已知盘块号 $b$ 求 $(i, j)$：**$i = (b - 1) \div n + 1$**；**$j = (b - 1) \bmod n + 1$**
    - **如果行号、列号、盘块号均从 `0` 开始**（真题最喜欢考的形式）：
        - 已知 $(i, j)$ 求盘块号 $b$：**$b = n \times i + j$**
        - 已知盘块号 $b$ 求 $(i, j)$：**$i = b \div n$**；**$j = b \bmod n$**
    - **做题铁律：** 在考场上看到位示图计算题，第一件事就是拿笔圈出题目规定的起始索引是 0 还是 1！
- **陷阱 2：“字”与“字节”的概念混淆。**
    
    - **辨析：** 题目常说“计算机字长为 32 位，采用位示图法”。这意味着二维数组的列数 **$n = 32$**。如果要问位示图占几个“字节(Byte)”，记得要除以 8。

### 典型计算示例

**【408 经典计算题型】** 假设某系统磁盘共有 10000 个盘块，计算机字长为 32 位（即位示图每行 32 个位），系统采用位示图法管理磁盘。 **条件设定：** 盘块号、字号（行号）、位号（列号）**均从 0 开始编号**。 **问题 1：** 第 6000 号盘块，对应在位示图的第几个字？第几位？ **问题 2：** 该位示图至少需要多少个字？

**【推导过程】**

1. **解决问题 1（地址转换）：**
    - 由于从 0 开始编号，直接使用整除和取余公式。
    - 行号（字号） $i = 6000 \div 32 = \mathbf{187}$
    - 列号（位号） $j = 6000 \bmod 32 = \mathbf{16}$
    - 即第 6000 号盘块在位示图的第 187 个字的第 16 位。
2. **解决问题 2（容量计算）：**
    - 需要的总位数 = 10000 位。
    - 需要的字数 = $\lceil 10000 / 32 \rceil = \lceil 312.5 \rceil = \mathbf{313}$ **个字**。
    - _(注意：哪怕最后几个位用不完，也必须向上取整分配一个完整的字)_
