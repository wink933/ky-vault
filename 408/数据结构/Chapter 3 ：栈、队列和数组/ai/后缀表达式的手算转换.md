- **结论** 手算将中缀表达式转换为后缀表达式的核心思想是**“通过全括号化明确运算优先级，再将运算符号整体右移”**。这种方法在 408 考场上是解决表达式转换类选择题最直观、最不容易出错的方法，其手算结果与二叉树的后序遍历结果完全等价。

### 关键点（手算“三步法”）

**1. 第一步：按优先级逐层加括号**

- **操作**：严格按照实际计算的优先级，对整个表达式逐层加满括号。确保每一对括号内**仅包含一个运算符**及其对应的左右操作数。

**2. 第二步：将每个运算符移至对应括号之后**

- **操作**：找到每个运算符所属的那对括号，将该运算符移到其对应的**右括号 `)` 的正后方**。此时局部形成了“左操作数 右操作数 运算符”的结构。

**3. 第三步：删除所有括号**

- **操作**：直接抹除表达式中所有的左右括号，按原顺序保留剩下的数字/字母和运算符，即得到最终的后缀表达式。

---

### 💡 经典手推案例（源自 408 教材）

以中缀表达式 `A + B * (C - D) - E / F` 为例：

- **① 加满括号**：`( (A + (B * (C - D))) - (E / F) )` _(解析：先算减法 `(C-D)`，再算乘法 `(B*(C-D))` 和除法 `(E/F)`，接着算加法 `A+(...)`，最后算最外层的减法)_
- **② 符号右移**：`( (A (B (C D )- )* )+ ) (E F )/ )-`
- **③ 去除括号**：最终得到后缀表达式 **`A B C D - * + E F / -`**。

---

### 易错点 / 易混点辨析（408 致命陷阱）

- **陷阱 1：同级运算加括号顺序错误（未遵守“左优先原则”）**
    - **易错点**：遇到 `A + B - C` 时，部分考生为了图方便随意加括号为 `(A + (B - C))`。
    - **辨析**：**大错特错！** 408 考纲要求机算的后缀表达式必须是**唯一**的。因为四则运算具有“左结合性”，在遇到同级运算符时，**必须先给左边的式子加括号**。正确的加法是 `((A + B) - C)`，转换结果为 `A B + C -`。如果错误结合成右边，会导致最终结果完全不符合计算机栈扫描的出栈逻辑。
- **陷阱 2：后缀转法与前缀转法的混淆**
    - **易混点**：记混了符号该往左移还是往右移。
    - **辨析**：
        - 求**后**缀表达式（逆波兰表达式）：符号移动到属于它的右括号 **`)` 之后**。
        - 求**前**缀表达式（波兰表达式）：操作逻辑完全对称，符号移动到属于它的左括号 **`(` 之前**。

### 💡 复习检查清单（考场口诀）

在考场上遇到手工转换表达式的选择题，请立刻默念：

1. **“一加（加满括号），二移（符号右移），三去（抹除括号）”**。
2. **“同级运算先算左，括号千万别包错”**。
3. **“后缀符号往右扔，前缀符号往左抛”**。
