- **结论** 在 408 考纲中，对称矩阵、三角矩阵和三对角矩阵都属于**特殊矩阵**。对比它们的核心主线是**“压缩存储策略”**：即利用它们元素分布的数学规律，将原本需要 $O(n^2)$ 空间的二维矩阵，通过精确的坐标映射公式，压缩存储到一维数组中，从而消除冗余空间的浪费。

---

### 核心对比卡片

|对比维度|对称矩阵 (Symmetric Matrix)|三角矩阵 (Triangular Matrix)|三对角矩阵 (Tridiagonal/Band Matrix)|
|:--|:--|:--|:--|
|**元素分布特征**|关于主对角线完全对称，即 $a_{i,j} = a_{j,i}$。|分为下/上三角矩阵。主对角线一侧为有效数据，另一侧**全部为同一个常数 $c$**。|非零元素集中在主对角线及其上下紧邻的两条对角线上。即当 $\|
|**压缩存储策略**|只存储主对角线及其中一侧（例如下三角区）的元素。|存储有效数据区（类似对称矩阵），**外加 1 个额外空间**来存放那个常数 $c$。|按行优先顺序，仅存储这 3 条对角线上的有效元素。|
|**一维数组大小**|**$\frac{n(n+1)}{2}$**|**$\frac{n(n+1)}{2} + 1$**|**$3n - 2$**|
|**映射逻辑 (找另一半)**|若访问未存储的那一半，**直接交换行列坐标 $(i, j \rightarrow j, i)$** 去已存储区找。|若访问全为常数的那一半，直接定位到一维数组的**最后 1 个位置**。|不存在“另一半”，越界元素直接返回 0。|

---

### 关键点（核心映射公式，以“行优先+存储下三角+下标从1开始”为例）

**1. 对称矩阵与三角矩阵的有效区映射**

- 前 $i-1$ 行共有 $\frac{i(i-1)}{2}$ 个元素，加上本行的 $j$ 个元素。
- **对称矩阵**：当下三角区 $i \ge j$ 时，映射到一维数组的下标 $k = \frac{i(i-1)}{2} + j - 1$。若 $i < j$（访问上三角），因为 $a_{i,j} = a_{j,i}$，公式变为 $k = \frac{j(j-1)}{2} + i - 1$。
- **三角矩阵**：下三角区公式同上；若访问上三角区（$i < j$），则直接访问常数区，下标 $k = \frac{n(n+1)}{2}$。

**2. 三对角矩阵的极客公式（必考）**

- **正向映射**：在三对角矩阵中，除了第一行和最后一行只有 2 个元素外，其余中间行都有 3 个元素。推导可得，元素 $a_{i,j}$ 在一维数组中的下标 **$k = 2i + j - 3$**（前提：矩阵下标 1 开始，数组下标 0 开始）。

---

### 🚨 易错点 / 易混点辨析（408 极高频陷阱）

- **陷阱 1：“坐标起点”带来的公式变异（最致命陷阱）**
    - **易错点**：做选择题时死记硬背公式 $k = \frac{i(i-1)}{2} + j - 1$，结果算出错误答案。
    - **辨析**：408 的题目极其狡猾！做题前**必须第一秒确认两个起点**：
        1. 矩阵的行列下标是从 0 开始还是从 1 开始？
        2. 一维数组的下标是从 0 开始还是从 1 开始？ 资料中的标准公式是基于矩阵下标从 1 开始、数组下标从 0 开始推导的。如果题目说数组从 1 开始，那结果必须 $+1$；如果矩阵从 0 开始，公式里的 $i$ 和 $j$ 就要替换成 $i+1$ 和 $j+1$。**绝招：不要死记公式，用特殊值（如代入 $a_{1,1}$ 或 $a_{2,1}$）去逆向验证选项。**
- **陷阱 2：三角矩阵的“+1 遗忘症”**
    - **易错点**：认为三角矩阵和对称矩阵的存储空间一模一样大。
    - **辨析**：**大错特错！** 对称矩阵另一半的数据可以通过坐标交换找到，因此不需要额外空间；但三角矩阵的另一半是常数，**必须在数组末尾额外开辟 1 个空间来存储这个常数**，所以它的总大小必定是对称矩阵的大小 **$+1$**。
- **陷阱 3：三对角矩阵的“逆向查行号”**
    - **易错点**：知道 $a_{i,j}$ 求 $k$ 容易，但题目如果给出一维数组的下标 $k$，反问你它对应矩阵的第几行（求 $i$），瞬间卡壳。
    - **辨析**：利用三对角矩阵的性质，前 $i-1$ 行一共有 $3(i-1) - 1$ 个元素。已知一维数组下标为 $k$ 的元素是第 $k+1$ 个元素，因此推导出逆向公式：**$i = \lfloor(k+1)/3\rfloor + 1$**，算出 $i$ 后再代入 $k = 2i + j - 3$ 即可求出列号 $j$。

### 💡 题目中如何识别与应对

- **遇到“对称矩阵 / 三角矩阵计算下标”** $\rightarrow$ **画图代入法**。在草稿纸画一个 $3 \times 3$ 的矩阵，标上 $a_{1,1}, a_{2,1}, a_{2,2}$，看它们分别对应一维数组的第 0, 1, 2 个位置，直接把坐标代入 ABCD 四个选项排雷。
- **遇到“带状矩阵（三对角）”** $\rightarrow$ 默写规模 **$3n-2$**，映射关系 $k = 2i + j - 3$。
