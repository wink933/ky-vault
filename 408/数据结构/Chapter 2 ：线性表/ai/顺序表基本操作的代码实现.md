- **结论** 顺序表基本操作的核心逻辑完全建立在**“物理连续的存储结构”**之上。在进行代码实现时，必须严密关注三个维度：**合法性校验（容量与边界）、位序与数组下标的转换（$i$ 与 $i-1$）、以及为保持连续性而产生的元素批量移动方向**。

以下基于 408 大纲标准（C/C++ 语言），为你详细拆解核心操作的代码实现与底层逻辑。

### 关键点（核心代码实现与步骤解析）

**1. 结构定义与初始化（以动态分配为例）**

- **代码实现**：
    
    ```c
    #define InitSize 100          // 表长度的初始定义
    typedef struct {
        ElemType *data;           // 指示动态分配数组的指针
        int MaxSize, length;      // 数组的最大容量和当前个数
    } SeqList;
    
    void InitList(SeqList &L) {
        // 用 malloc 申请一片连续的存储空间
        L.data = (ElemType *)malloc(sizeof(ElemType) * InitSize);
        L.length = 0;             // 结论：初始化时，当前长度必须设为 0
        L.MaxSize = InitSize;
    }
    ```
    
- **关键机制**：动态分配的优势在于空间存满时，可以另外开辟一块更大的空间（通过 `malloc` 或 `realloc`），将原数据复制过去，从而实现扩容，但其本质仍然是连续的顺序存储结构。

**2. 插入操作 (ListInsert)**

- **代码实现**：
    
    ```c
    bool ListInsert(SqList &L, int i, ElemType e) {
        if(i < 1 || i > L.length + 1) // 1. 判断 i 的范围是否有效
            return false;
        if(L.length >= MaxSize)       // 2. 当前存储空间已满，不能插入
            return false;
        for(int j = L.length; j >= i; j--) // 3. 将第 i 个元素及之后的元素后移
            L.data[j] = L.data[j-1];
        L.data[i-1] = e;              // 4. 在位置 i 处放入 e (注意数组下标为 i-1)
        L.length++;                   // 5. 线性表长度加 1
        return true;
    }
    ```
    
- **时间复杂度**：平均情况需移动一半的元素，时间复杂度为 **$O(n)$**。

**3. 删除操作 (ListDelete)**

- **代码实现**：
    
    ```c
    bool ListDelete(SqList &L, int i, ElemType &e) {
        if(i < 1 || i > L.length)     // 1. 判断 i 的范围是否有效
            return false;
        e = L.data[i-1];              // 2. 将被删除的元素赋值给 e
        for(int j = i; j < L.length; j++) // 3. 将第 i 个位置之后的元素前移
            L.data[j-1] = L.data[j];
        L.length--;                   // 4. 线性表长度减 1
        return true;
    }
    ```
    
- **时间复杂度**：平均情况需移动剩余的元素，时间复杂度为 **$O(n)$**。

**4. 按值查找 (LocateElem)**

- **代码实现**：
    
    ```c
    int LocateElem(SqList L, ElemType e) {
        for(int i = 0; i < L.length; i++)
            if(L.data[i] == e)
                return i + 1;         // 查找成功，返回其位序 i+1 (非下标)
        return 0;                     // 查找失败，返回 0
    }
    ```
    
- **时间复杂度**：从头到尾遍历比对，平均时间复杂度为 **$O(n)$**。

### 易错点 / 易混点辨析（408 考场手写代码避坑指南）

- **陷阱 1：位序 $i$ 与数组下标的错位**
    - **易错点**：当题目要求“在第 $i$ 个位置插入”时，直接操作 `L.data[i] = e`。
    - **辨析**：**大错特错！** 线性表的位序（人的视角）是从 **1** 开始的，而 C 语言数组下标（机器视角）是从 **0** 开始的。因此，**第 $i$ 个元素的绝对物理下标永远是 `i-1`**。在手写大题时，凡是涉及 `L.data[...]` 的访问，务必核对是否做了 `-1` 的偏移。
- **陷阱 2：插入与删除的“移动方向”惨案**
    - **易错点**：死记硬背 `for` 循环，导致移动元素时自己覆盖了自己的数据。
    - **辨析（请严格画图辅助记忆）**：
        - **插入操作（必须从后往前）**：`for(j = L.length; j >= i; j--)`。必须先让最后的元素往后挪腾出坑，再依次搬运。如果从前往后挪，第 $i$ 个元素会直接覆盖掉还没来得及搬走的第 $i+1$ 个元素。
        - **删除操作（必须从前往后）**：`for(j = i; j < L.length; j++)`。直接用后一个元素往前盖掉不要的那个元素即可。
- **陷阱 3：参数传递时的引用符 `&`**
    - **易混点**：什么时候传 `SqList L`，什么时候传 `SqList &L`？
    - **辨析**：
        - **需要修改原表本身时（如 InitList、ListInsert、ListDelete）**：必须加 `&`（C++ 的引用传参），否则你在函数内增加的 length 或修改的数组对外面的原表不生效。
        - **只读取不修改时（如 LocateElem 按值查找）**：无需加 `&`，直接传值即可（加了也可以，能节省传递开销，但严谨起见考纲通常仅在有修改动作时强调 `&`）。
        - **带出结果时**：Delete 操作中的 `ElemType &e`，加 `&` 是为了把被删除的元素值“带回”给调用者。

### 💡 复习检查清单（核心逻辑默写骨架）

手写顺序表算法大题时，请严格遵循以下**“安全三段式”**：

1. **第一段：判合法。** （插：$1 \le i \le L+1$ 且防溢出；删：$1 \le i \le L$）。
2. **第二段：移元素。** （注意方向：插倒序，删正序）。
3. **第三段：改长值。** （动数据，并执行 `L.length++` 或 `L.length--`，最后 `return true`）。
