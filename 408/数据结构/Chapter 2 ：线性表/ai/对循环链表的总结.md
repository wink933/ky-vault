- **章节主线** 在考研 408 中，循环链表是对基本链式存储结构的特殊改进。它的核心思想是**“首尾相连，形成闭环”**，彻底解决了普通链表“只能顺着某一个方向单次走到黑”的痛点，并极大优化了首尾两端的操作效率。

---

### 核心知识框架（分点总结）

**1. 循环单链表**

- **结构定义**：将普通单链表尾结点的 `next` 指针由 `NULL` 改为**指向头结点**，从而使整个链表形成一个环。
- **核心优势**：从表中的**任意一个结点**出发，都能遍历整个链表（而普通单链表只能从头开始）。
- **判空条件（带头结点）**：头结点的 `next` 指针指向自己，即 **`L->next == L`**。
- **判断表尾（遍历结束条件）**：检查当前结点的 `next` 是否等于头指针，即 **`p->next == L`**。

**2. 循环双链表**

- **结构定义**：在双链表的基础上，头结点的 `prior` 指向尾结点，尾结点的 `next` 指向头结点。
- **核心优势**：完美融合了双链表“$O(1)$ 找前驱”和循环链表“无缝首尾连接”的特性。
- **判空条件（带头结点）**：头结点的 `prior` 和 `next` 都指向自己，即 **`L->next == L && L->prior == L`**。

**3. “尾指针”极客设计（高频考法）**

- 为了提高首尾操作效率，循环单链表**通常不设头指针，而是只设一个尾指针 `r`**。
- **为什么这么设计？**
    - 找尾结点：直接通过 `r`，时间复杂度为 $O(1)$。
    - 找头结点：尾结点的下一个就是头结点，即 `r->next`，时间复杂度也是 $O(1)$。
    - 这样可以做到**在表头和表尾插入元素的时间复杂度均为 $O(1)$**。

---

### 🚨 高频考点与易错点辨析

- **易错点 1：死循环陷阱（寻找 `NULL` 的下场）**
    - **辨析**：普通的链表遍历条件通常写 `while(p != NULL)` 或 `while(p->next != NULL)`。**在循环链表中这是致命错误！** 循环链表中根本不存在 `NULL` 指针（除未初始化的空树外），照搬此代码会直接死循环。遍历一圈的终止条件必须写成 `while(p->next != L)` 或 `while(p != L)`。
- **易错点 2：设尾指针 `r` 时，“删尾操作”的时间复杂度陷阱**
    - **易混点**：很多同学认为既然设了尾指针 `r`，找尾结点是 $O(1)$，那么“删除尾结点”肯定也是 $O(1)$。
    - **辨析**：**大错特错，依然是 $O(n)$！** 在循环单链表中，删除一个结点必须要找到它的**前驱结点**以防断链。虽然你知道尾结点在哪，但你只能顺着链表从头遍历一整圈去寻找尾结点的前一个结点，因此时间复杂度是 $O(n)$。
- **易错点 3：两个循环链表的合并（尾指针的绝对优势）**
    - **考点**：如果有两个带**尾指针** `Ta` 和 `Tb` 的循环单链表，将它们合并成一个的时间复杂度是 **$O(1)$**。只需让 `Ta` 的尾连到 `Tb` 的头（首元结点），`Tb` 的尾连到 `Ta` 的头即可。如果只给头指针，合并时间复杂度则是 $O(n)$，因为必须要先遍历找尾。

### 💡 复习检查清单（考场条件反射）

做选择题或算法大题遇到“循环链表”时，请立刻检查自己是否清晰以下映射：

1. [ ] **看到“循环单链表判空”** $\rightarrow$ 默写 `L->next == L`。
2. [ ] **看到“循环双链表判空”** $\rightarrow$ 默写 `L->next == L && L->prior == L`。
3. [ ] **看到“循环链表遍历”** $\rightarrow$ 检查 `while` 循环里有没有错误地出现 `NULL`。
4. [ ] **看到“要求首、尾操作都最高效”** $\rightarrow$ 选**仅带尾指针的循环单链表** 或 **循环双链表**。
5. [ ] **看到“单向循环链表删尾结点”** $\rightarrow$ 反射出时间复杂度为 **$O(n)$**（缺前驱）。
