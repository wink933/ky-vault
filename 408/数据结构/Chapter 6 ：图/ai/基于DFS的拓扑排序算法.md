基于深度优先搜索（DFS）的拓扑排序，是利用了 DFS 遍历过程中“回溯”的特性。理解这个算法的核心在于把握一句话：**在 DFS 中，最先退出递归（也就是没有未访问的邻接点、走到尽头）的顶点，一定位于拓扑序列的最后面。**

下面我们以极具严谨性的方式，详细拆解这个算法的底层逻辑和实现细节。

### 一、 核心逻辑与“三态”数组

在标准 DFS 中，我们通常只用一个 `visited` 数组（`true/false`）来标记是否访问过。但在求拓扑排序时，我们需要检测图中是否存在**环**（因为有向无环图 DAG 才有拓扑序列）。

为了同时完成“遍历”和“判环”，我们需要将顶点的访问状态细分为**三种（通常称为三色标记法）**：

- **状态 0（未访问，Unvisited）**：该顶点尚未被遍历。
    
- **状态 1（访问中，Visiting）**：该顶点已被访问，但其所有后继节点的 DFS 递归还未完全结束。它目前正处在系统的**递归调用栈**中。
    
    - _关键点：如果我们在向下搜索时，又碰到了状态为 1 的顶点，说明我们顺着有向边又绕回了递归栈里的长辈节点，这就证明图中**存在环**！_
        
- **状态 2（已完成，Finished）**：该顶点及其所有可达的后继节点都已经搜索完毕，彻底退出递归栈。
    

### 二、 算法执行步骤

1. **初始化**：分配一个状态数组 `state` 初始化为全 0，以及一个栈 `Stack`（用于逆序保存结果）。
    
2. **入口遍历**：依次检查图中的每一个顶点 $v$。如果 `state[v] == 0`，则对 $v$ 调用 `DFS(v)`。
    
3. **DFS(v) 的内部执行过程**：
    
    - **打标记**：进入 `v`，首先将 `state[v]` 设为 1（访问中）。
        
    - **探寻邻居**：遍历 $v$ 的所有邻接点（出边指向的顶点）$w$：
        
        - 如果 `state[w] == 0`：说明 $w$ 未访问，对 $w$ 递归调用 `DFS(w)`。
            
        - 如果 `state[w] == 1`：**发现环！** 直接终止算法，说明该图无法进行拓扑排序。
            
        - 如果 `state[w] == 2`：说明 $w$ 及其子树早就处理完了，是一条安全的交叉边，跳过即可。
            
    - **完成回溯**：当 $v$ 的所有邻居都处理完毕后，将 `state[v]` 修改为 2（已完成）。
        
    - **入栈**：将 $v$ 压入 `Stack`。因为它是“穷途末路”才退出的，它不依赖于任何当前栈外的未访问节点，所以它应该排在拓扑序列的尾部。压入栈中正好可以实现**逆序输出**。
        
4. **输出结果**：所有顶点处理完毕后，依次弹出 `Stack` 中的元素，即为正向的拓扑序列。
    

### 三、 算法伪代码展示

这里使用 C++ 风格的伪代码，结合邻接表的思想：

C++

```
bool hasCycle = false;
int state[V]; // 初始化为 0
stack<int> topoStack;

void DFS(int u) {
    if (hasCycle) return; 
    
    state[u] = 1; // 标记为访问中
    
    // 遍历 u 的所有出边指向的邻接点 v
    for (int v : adjList[u]) {
        if (state[v] == 0) {
            DFS(v);
        } else if (state[v] == 1) {
            hasCycle = true; // 发现环，终止
            return;
        }
        // 若 state[v] == 2，无操作，继续看下一个邻接点
    }
    
    state[u] = 2; // 标记为已完成
    topoStack.push(u); // 压入栈中
}

// 主控函数
void TopologicalSort() {
    // 1. 初始化 state 数组 (略)
    
    // 2. 遍历所有顶点作为起点
    for (int i = 0; i < V; ++i) {
        if (state[i] == 0) {
            DFS(i);
        }
    }
    
    // 3. 判断与输出
    if (hasCycle) {
        print("该图存在环，无拓扑序列");
    } else {
        while (!topoStack.empty()) {
            print(topoStack.top());
            topoStack.pop();
        }
    }
}
```

### 四、 性能与特征分析

- **时间复杂度**：
    
    与标准的 DFS 完全一致。如果采用邻接表存储，每个顶点被调用一次，每条边被检查一次，时间复杂度为 **$O(V+E)$**。
    
- **空间复杂度**：
    
    需要额外的状态数组和用于输出结果的栈，大小均为 $V$；最坏情况下（如图退化成一条单链）递归调用栈的深度可达 $V$。因此空间复杂度为 **$O(V)$**。
    
- **与 Kahn 算法的区别**：
    
    - **Kahn 算法（入度法）**是从“前往后”剥离，它天然就是在寻找图的**源点**（入度为 0）。
        
    - **DFS 法（出度法/逆向深度法）**本质上是从“后往前”回溯，它实际上是在寻找图的**汇点**（出度为 0，或者指向的所有节点都已访问），然后再逆序。
