### 2. 【核心考点精析】

溢出的本质是**运算结果超出了当前机器字长所能表示的定点数有效范围**。在计算机中，仅有**带符号整数（补码）加减法**才会讨论算术溢出（无符号数对应的是借位/进位标志 CF，而非溢出标志 OF）。常用的判据分为软件层面的逻辑推导与硬件层面的门电路实现：

  

1. **操作数与结果符号位判定法（单符号位法）**：
    
      
    - **理论机制**：只有当**同符号数相加**（或异符号数相减）时才可能发生溢出；异符号数相加绝对不会溢出。
        
          
        
    - **判定规则**：
        
          
        - 若两个正数相加，结果变成了负数（正溢出，上溢）：$A_s = 0, B_s = 0, S_s = 1$；
            
              
            
        - 若两个负数相加，结果变成了正数（负溢出，下溢）：$A_s = 1, B_s = 1, S_s = 0$。
            
              
            
    - **布尔逻辑表达式**（设操作数符号位为 $A_s, B_s$，加法结果符号位为 $S_s$）：
        
          
        
        $$V = \overline{A_s} \cdot \overline{B_s} \cdot S_s + A_s \cdot B_s \cdot \overline{S_s}$$
        
        若 $V = 1$ 则表示发生溢出；$V = 0$ 表示无溢出。
        
          
        
2. **双符号位判决法（变形补码 / 模 4 补码）**：
    
      
    - **理论机制**：每个数用 2 个符号位表示（$00$ 表示正数，$11$ 表示负数）。
        
          
        
    - **判定规则**：在 ALU 内部计算后，观察结果的高两位符号位 $S_{s1}S_{s2}$：
        
          
        - $S_{s1}S_{s2} = 00$：正数，无溢出；
            
              
            
        - $S_{s1}S_{s2} = 11$：负数，无溢出；
            
              
            
        - $S_{s1}S_{s2} = 01$：正溢出（上溢）；
            
              
            
        - $S_{s1}S_{s2} = 10$：负溢出（下溢）。
            
              
            
    - **布尔逻辑表达式**：
        
          
        
        $$V = S_{s1} \oplus S_{s2}$$
        
        只要两个符号位不同，即发生溢出；最高符号位 $S_{s1}$ 始终代表真正的正确符号。
        
          
        
3. **最高有效位与符号位进位异或判决法（硬件最常用实现）**：
    
      
    - **理论机制**：利用加法器内部的进位信号。设最高数值位（即符号位之后紧邻的最高数据位 $n-1$）向符号位的进位为 $C_{\text{in}}$（或记为 $C_{n-1}$），符号位向更高位产生的进位输出为 $C_{\text{out}}$（或记为 $C_n$）。
        
          
        
    - **判定规则**：
        
          
        - 当发生正溢出时，两个正数（符号位为 0）相加，符号位无进位输出（$C_{\text{out}} = 0$），但数值位求和进位至符号位（$C_{\text{in}} = 1$）；
            
              
            
        - 当发生负溢出时，两个负数（符号位为 1）相加，符号位自身产生进位输出（$C_{\text{out}} = 1$），但数值位求和未向符号位进位（$C_{\text{in}} = 0$）。
            
              
            
    - **布尔逻辑表达式**（x86 中 OF 标志位的硬件生成逻辑）：
        
          
        
        $$\text{OF} = C_{\text{out}} \oplus C_{\text{in}} = C_n \oplus C_{n-1}$$
        
        若两者进位不一致（异或为 1），则判定溢出。
        
          
        

### 3. 【极值 / 边界与易错陷阱】

- **陷阱一：混淆有符号溢出标志 OF 与无符号进/借位标志 CF**。
    
      
    - **OF（Overflow Flag）**：仅对**有符号数**有意义，判定公式为 $\text{OF} = C_n \oplus C_{n-1}$。
        
          
        
    - **CF（Carry Flag）**：仅对**无符号数**有意义，加法时 $\text{CF} = C_{\text{out}}$，减法时 $\text{CF} = C_{\text{out}} \oplus \text{Sub}$（即借位）。一个运算指令执行完毕，ALU 会同时产生 OF 和 CF，硬件本身不管是有符号还是无符号，由程序员根据数据类型自行检查对应的标志位。
        
          
        
- **陷阱二：误把减法当加法套用进位判决**。
    
      
    - 计算减法 $A - B$ 时，硬件底层通过求补器将减数变补码转换为加法：$A + [-B]_{\text{补}}$。
        
          
        
    - 在利用符号位判断时，必须以转换后的加数符号 $[-B]_{s}$ 参与判断，切不可直接拿原减数 $B$ 的符号代入加法判定公式。
        
          
        
- **陷阱三：双符号位在内存中的实际存储状态**。
    
      
    - 双符号位主要存在于 ALU 内部的数据通路与寄存器暂存中，**数据存入内存时通常只保留一个符号位**（即高位 $S_{s1}$ 截断，只存 $S_{s2}$），切莫以为内存中每个数据都占用两个符号位。
        
          
        

### 4. 【同源延伸与变式盲区】

- **变式设问一（结合条件转移指令）**：
    
    在 x86 汇编大题中，常考察条件跳转指令与标志位的映射：
    
      
    - 无符号数比较（如 `ja`, `jb`, `jbe`）：依赖标志位 **CF 和 ZF**；
        
          
        
    - 有符号数比较（如 `jg`, `jl`, `jle`）：依赖标志位 **SF、OF 和 ZF**（例如判断“小于”的依据是 $\text{SF} \oplus \text{OF} = 1$）。
        
          
        
- **变式设问二（边界值与非对称极值）**：
    
    $n$ 位补码的表示范围是非对称的：$[-2^{n-1}, 2^{n-1} - 1]$。
    
      
    - 特殊极值点：当对最小负数（如 8 位的 $-128$，补码为 `10000000B`）执行取相反数（即求 $[-x]_{\text{补}}$）时，会产生下溢出，因为正数最大只能表示到 $+127$。
        
          
        

> **解题心法**：
> 
> “同号相加防异号，双符相异判溢出；进位异或最简捷，$C_n \oplus C_{n-1}$ 决雌雄。”
