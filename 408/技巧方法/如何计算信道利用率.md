### 2. 【核心考点精析】

1. **信道利用率（Channel Utilization）的底层物理定义**：
    
      
    - **定义**：信道利用率（又称信道效率，通常记为 $U$ 或 $\eta$）是指发送方**实际用于在信道上发送数据的时间**占**整个发送周期总时间**的百分比。
        
          
        
    - **核心基准物理公式**：
        
          
        
        $$U = \frac{T_{\text{有效发送}}}{T_{\text{完整周期}}}$$
        
        - $T_{\text{有效发送}}$：发送方在这一个往返交互周期内，将数据比特注入信道所耗费的总发送时延（Transmission Delay）。
            
              
            
        - $T_{\text{完整周期}}$：从发送方开始发送第一个数据帧的第一个比特起，到收到该数据帧对应的确认帧（ACK）为止的完整轮转耗时（Round-Trip Cycle Time）。
            
              
            
2. **单帧发送的轮转周期模型分解**：
    
      
    - 设单个数据帧长度为 $L$（bit），信道传输速率/物理带宽为 $C$（b/s）：
        
          
        
        $$t_{\text{数据发送}} = \frac{L}{C}$$
        
    - 设信号单向传播时延为 $\tau$（s），往返时延 $\text{RTT} = 2\tau$；
        
          
        
    - 设确认帧（ACK）长度为 $L_{\text{ACK}}$（bit），其发送时延为：
        
          
        
        $$t_{\text{ACK发送}} = \frac{L_{\text{ACK}}}{C}$$
        
        _(若题干指出“短帧/忽略确认帧发送时延”，则 $t_{\text{ACK发送}} \approx 0$)_；
        
          
        
    - 发送一个帧并等待其确认的完整周期为：
        
          
        
        $$T_{\text{完整周期}} = t_{\text{数据发送}} + \text{RTT} + t_{\text{ACK发送}} = t_{\text{数据发送}} + 2\tau + t_{\text{ACK发送}}$$
        
3. **三大滑动窗口协议的信道利用率计算推导**：
    
      
    - **停-等协议（Stop-and-Wait）**：
        
          
        - 发送窗口 $W = 1$，每个周期只能发送 1 个帧：
            
              
            
            $$U_{\text{Stop-Wait}} = \frac{t_{\text{数据发送}}}{t_{\text{数据发送}} + 2\tau + t_{\text{ACK发送}}}$$
            
    - **连续 ARQ 协议（GBN / SR，发送窗口为 $W$）**：
        
          
        - 若发送窗口允许在等待确认前连续发送 $W$ 个数据帧，则该周期内用于发送数据的总耗时为 $W \times t_{\text{数据发送}}$。
            
              
            
        - **利用率上限（木桶理论极值）**：
            
              
            
            $$U = \min\left(1, \frac{W \times t_{\text{数据发送}}}{T_{\text{完整周期}}}\right) = \min\left(1, \frac{W \times t_{\text{数据发送}}}{t_{\text{数据发送}} + 2\tau + t_{\text{ACK发送}}}\right)$$
            
            - **当 $W \times t_{\text{数据发送}} < T_{\text{完整周期}}$ 时（窗口受限）**：
                
                发送方发完 $W$ 个帧后必须停下来等待确认，信道出现空闲气泡，此时 $U = \frac{W \times t_{\text{数据发送}}}{T_{\text{完整周期}}} < 1$；
                
                  
                
            - **当 $W \times t_{\text{数据发送}} \ge T_{\text{完整周期}}$ 时（带宽跑满）**：
                
                在第一个帧的 ACK 返回前，发送方一直在流水线发送而无停顿，**信道利用率达到极限 $U = 100\%$**。
                
                  
                
4. **信道利用率与实际数据传输速率（吞吐率）的换算关系**：
    
      
    - 实际数据传输速率 $R$ 严格等于信道物理带宽 $C$ 乘以信道利用率 $U$：
        
          
        
        $$R = C \times U$$
        
    - 反之，若已知实际平均数据传输速率 $R$ 和信道物理带宽 $C$：
        
          
        
        $$U = \frac{R}{C}$$
        

### 3. 【极值 / 边界与易错陷阱】

- **“利用率可以超过 100%”的数学盲区**：
    
    考生套公式 $U = \frac{W \times t_{\text{数据发送}}}{T_{\text{完整周期}}}$ 时，若题目给出的窗口 $W$ 很大，直接算出来 $125\%$ 并写在卷面上。
    
      
    - **边界破局点**：信道利用率是物理时间占比，**其数学上限严格为 $1$（即 $100\%$）**。一旦算出的理论值 $\ge 1$，说明发送窗口已经足以填满整个往返管道，利用率必须直接取 $100\%$。
        
          
        
- **单位换算漏乘 8（Byte vs bit）**：
    
    帧长通常以字节（B）给出，信道带宽通常以比特每秒（b/s, Mbps）给出。在计算发送时延 $t = \frac{L}{C}$ 时，必须先将 $L$ 乘以 8 转换为比特，否则计算出的利用率会直接缩水 8 倍。
    
      
    
- **单向延迟 $\tau$ 与往返延迟 RTT 的混淆**：
    
    若题干给出“**单向**传播时延为 $50\text{ ms}$”，完整周期中必须加上 $2 \times 50\text{ ms} = 100\text{ ms}$；若题干直接给出“**RTT** 为 $100\text{ ms}$”，则不要再乘以 2。
    
      
    

### 4. 【同源延伸与变式盲区】

- **同源变式场景**：
    
      
    - **变式 1（反求“使信道利用率达到 100% 的最小窗口尺寸 $W_{\min}$”）**：
        
        令 $U = 1$，则必须满足 $W \times t_{\text{数据发送}} \ge t_{\text{数据发送}} + 2\tau + t_{\text{ACK发送}}$：
        
          
        
        $$W_{\min} = \left\lceil \frac{T_{\text{完整周期}}}{t_{\text{数据发送}}} \right\rceil = \left\lceil 1 + \frac{2\tau + t_{\text{ACK发送}}}{t_{\text{数据发送}}} \right\rceil$$
        
    - **变式 2（结合时延带宽积 BDP 计算）**：
        
        若忽略帧发送时延，使管道始终充满比特所需的最小窗口为：
        
          
        
        $$W_{\min} \approx \frac{\text{RTT} \times C}{L} = \frac{\text{时延带宽积}}{\text{帧长}}$$
        
- **解题心法口诀**：
    
      
    
    > **“窗长乘上单帧耗，除以往返周期照；跑满极限只取一，莫忘换算比特调。”**
