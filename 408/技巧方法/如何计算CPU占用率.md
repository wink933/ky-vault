### 2. 【核心考点精析】

在 408 统考中，“计算 CPU 用于某外设 I/O 的时间占整个 CPU 时间的百分比”通常采用**基准时间归一化法**（以 $1\text{ s}$ 为观察窗口）：

  

$$\text{CPU 占用率} = \frac{\text{单位时间内 CPU 用于该 I/O 的时钟周期数}}{\text{单位时间内 CPU 提供的总时钟周期数}} \times 100\% = \frac{\text{单位时间内 CPU 用于该 I/O 的实际总时间}}{\text{单位时间 (1s)}} \times 100\%$$

其中，分母在 $1\text{ s}$ 观察时间内由主频 $f$ 直接决定：

  

$$\text{总时钟周期数} = f \times 1\text{ s}$$

分子的求解根据系统采用的 I/O 控制方式不同，分为以下四种核心计算模型：

  

1. **程序查询方式（Programmed I/O）下的 CPU 占用率**：
    
      
    - **机制**：CPU 通过轮询循环持续读取外设状态寄存器，数据未就绪前 CPU 处于完全阻塞等待状态。
        
          
        
    - **计算模型**：
        
          
        - 若外设在整个数据传送过程中完全独占 CPU，占用率为 $100\%$。
            
              
            
        - 若外设为周期性定时轮询（设轮询周期为 $T_{\text{poll}}$，每次查询检查耗时 $t_{\text{check}}$）：
            
              
            
            $$\text{CPU 占用率} = \frac{t_{\text{check}}}{T_{\text{poll}}} \times 100\%$$
            
2. **程序中断方式（Interrupt-driven I/O）下的 CPU 占用率**：
    
      
    - **机制**：外设准备好数据后向 CPU 发送中断请求。每传送一个“数据传输单元”（字/字节），CPU 均需暂停当前程序，执行一次完整的中断处理流程。
        
          
        
    - **计算模型**：
        
          
        - **步骤 1：求单位时间（1s）内发生的中断次数 $N_{\text{int}}$**：
            
              
            
            $$N_{\text{int}} = \frac{\text{外设数据传输率 } D}{\text{单次中断传送的数据量 } B}$$
            
        - **步骤 2：求单次中断处理消耗的总时钟周期数 $C_{\text{single}}$**：
            
              
            
            $$C_{\text{single}} = (I_{\text{ISR}} + I_{\text{overhead}}) \times \text{CPI}$$
            
            或直接通过执行时间换算：$C_{\text{single}} = T_{\text{single}} \times f$。其中 $I_{\text{ISR}}$ 为中断服务程序指令数，$I_{\text{overhead}}$ 为中断响应隐指令及现场恢复等额外开销的等效指令数。
            
              
            
        - **步骤 3：求占用率**：
            
              
            
            $$\text{CPU 占用率} = \frac{N_{\text{int}} \times C_{\text{single}}}{f \times 1\text{ s}} \times 100\%$$
            
3. **DMA（直接内存存取）方式下的 CPU 占用率**：
    
      
    - **机制**：CPU 仅在数据块传输前（预处理）**和**数据块传输完成产生中断后（后处理）介入；中间成块数据的传送由 DMA 控制器（DMAC）接管总线直接写入/读出主存。
        
          
        
    - **计算模型**：
        
          
        - **情形一：无访存冲突（或总线完全并行）**：
            
              
            - **步骤 1：求 1s 内执行 DMA 块传输的次数 $N_{\text{dma}}$**：
                
                  
                
                $$N_{\text{dma}} = \frac{\text{外设数据传输率 } D}{\text{每次 DMA 传送的数据块大小 } \text{Size}_{\text{block}}}$$
                
            - **步骤 2：求 1s 内预处理与后处理占用的总周期数**：
                
                  
                
                $$C_{\text{dma\_total}} = N_{\text{dma}} \times (C_{\text{pre}} + C_{\text{post}})$$
                
            - **步骤 3：求占用率**：
                
                  
                
                $$\text{CPU 占用率} = \frac{C_{\text{dma\_total}}}{f \times 1\text{ s}} \times 100\%$$
                
        - **情形二：存在访存冲突（周期挪用 / Cycle Stealing 方式）**：
            
              
            - 当外设传送每个字/字节挪用主存周期时，CPU 需停顿等待访存总线。此时 1s 内因总线被挪用而停顿的时间为：
                
                  
                
                $$T_{\text{steal}} = \frac{D}{\text{总线宽度}} \times \text{主存存取周期 } \tau$$
                
            - 此时 CPU 总占用时间需将“预处理+后处理时间”与“被挪用的总等待时间 $T_{\text{steal}}$”累加。
                
                  
                
4. **通道控制方式（Channel Architecture）下的 CPU 占用率**：
    
      
    - **机制**：CPU 仅通过一条“启动 I/O（SIO）”指令向通道下发通道程序首地址，并在通道执行完一组由多个通道命令字（CCW）组成的通道程序后响应通道结束中断。
        
          
        
    - **计算模型**：
        
          
        
        $$\text{CPU 占用率} = \frac{N_{\text{task}} \times (T_{\text{start}} + T_{\text{int}})}{1\text{ s}} \times 100\%$$
        
        $N_{\text{task}}$ 为单位时间下发的 I/O 任务总数，$T_{\text{start}}$ 与 $T_{\text{int}}$ 分别为启动指令执行时间和通道中断服务时间。
        
          
        

### 3. 【极值 / 边界与易错陷阱】

- **陷阱一：量纲单位混淆（十进制 $10^6$ vs 二进制 $2^{20}$）**。
    
      
    - 外设传输率（如 $\text{MB/s}$、$\text{kbps}$）与主频（$\text{MHz}$）在描述速率、频率时统一使用十进制基数：$1\text{ MHz} = 10^6\text{ Hz}$，$1\text{ MB/s} = 10^6\text{ B/s}$。
        
          
        
    - 只有在描述“存储体物理容量”（如 Cache 容量、主存容量）时，才使用二进制前缀（$1\text{ MB} = 2^{20}\text{ B}$）。若在传输率计算时代入 $1024 \times 1024$，会导致除法无法整除并失分。
        
          
        
- **陷阱二：字与字节单位换算遗漏（$\text{bit}$ vs $\text{Byte}$）**。
    
    题干常给出“数据传送单位为 32 位”，若外设传输率以 $\text{MB/s}$（字节）为单位，必须先除以 8 转换为 $4\text{ B}$，再计算单位时间内的传输次数。
    
      
    
- **陷阱三：漏计中断服务程序的“外部隐指令开销”**。
    
    单次中断所消耗的时间不仅包括执行中断服务程序（ISR）中的指令，还必须计入硬件自动完成的“中断响应周期”（关中断、保存断点 PC、引出中断向量等隐指令开销）以及退栈恢复现场的开销。
    
      
    
- **陷阱四：DMA 成块传输耗时与 CPU 介入耗时混淆**。
    
    在无访存冲突假设下，DMA 传输成块数据（如 $5000\text{ B}$）在总线上的挪动是由硬件控制器完成的，CPU 处于释放状态去执行其他用户进程，这部分数据传输时间**绝对不能计入 CPU 占用时间**。
    
      
    

### 4. 【同源延伸与变式盲区】

- **同源变式一（反推外设速率的饱和极值点）**：
    
    若设问：“在中断方式下，当该外设的数据传输率达到多大时，CPU 将被完全占满（CPU 占用率达 $100\%$）？”
    
      
    - 解法：令 $\text{CPU 占用率} = 1.0$，建立方程：
        
          
        
        $$\frac{\frac{D_{\max}}{B} \times C_{\text{single}}}{f \times 1\text{ s}} = 1 \implies D_{\max} = \frac{f \times B}{C_{\text{single}}}$$
        
- **同源变式二（多外设并发下的 CPU 占用叠加）**：
    
    若系统同时连接键盘（低速中断）、打印机（中速中断）和磁盘（DMA）：
    
      
    - 依据线性可加性原理，系统的总 CPU 占用率即为各设备独立计算出的占用率之和：
        
          
        
        $$\text{Ratio}_{\text{total}} = \sum \text{Ratio}_i$$
        
    - 若总和超过 $100\%$，表明中断处理速率跟不上设备数据到达速率，外设缓冲区将发生溢出丢数据。
        
          
        

> **解题心法**：
> 
> “秒为基准立两端，主频十进作分母；中断字粒除速率，指令乘拍并耗损；DMA 首尾记账册，无冲莫算块流转。”
