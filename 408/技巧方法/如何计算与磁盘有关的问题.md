### 1. 【考点全景定位】

- **所属科目**：操作系统（兼跨计算机组成原理的外存与 I/O 模块）

### 2. 【核心考点精析】

磁盘问题在 408 考核中具有高度的结构化特征，所有计算题均可归纳为以下四大核心模型：

  

#### 1. **磁盘单次 I/O 读写时间的三段式拆解模型**

一次磁盘读写操作的总时间 $T_{\text{total}}$ 严格由三部分串行叠加：

  

$$T_{\text{total}} = T_s + T_r + T_t$$

- **寻道时间（Seek Time, $T_s$）**：
    
    将磁头从当前磁道机械臂移动到目标磁道所需的时间。通常由**启动磁臂时间 $s$** 与**磁道跨越移动时间**组成：
    
      
    
    $$T_s = s + m \times \Delta t$$
    
    （$m$ 为跨越的磁道数，$\Delta t$ 为跨越 1 个相邻磁道的平均耗时；若题干直接给“平均寻道时间”，直接代入即可）。
    
      
    
- **旋转延迟时间（Rotational Latency, $T_r$）**：
    
    磁头定位到目标磁道后，等待目标扇区旋转到磁头下方的时间。
    
      
    - 设磁盘旋转速度为 $R$（转/分，$\text{rpm}$），则旋转一周的时间为 $T_{\text{rot}} = \frac{60}{R}\text{ s}$。
        
          
        
    - 对于**随机分布**的扇区访问，平均旋转延迟取**旋转半周的时间**：
        
          
        
        $$T_r = \frac{1}{2} \times T_{\text{rot}} = \frac{1}{2} \times \frac{60}{R} = \frac{30}{R}\text{ s}$$
        
- **传输时间（Transfer Time, $T_t$）**：
    
    从目标扇区开始划过磁头、将数据读入或写出磁头的时间。
    
      
    - 若磁道上共有 $S$ 个扇区，读取其中 1 个扇区（转过 $1/S$ 周）：
        
          
        
        $$T_t = \frac{T_{\text{rot}}}{S} = \frac{60}{R \times S}$$
        
    - 若每次读写 $b$ 字节，每个磁道容量为 $N$ 字节，则：
        
          
        
        $$T_t = \frac{b}{R \times N} = \frac{b}{\text{数据传输率 } C_{\text{transfer}}}$$
        

#### 2. **连续读取多扇区与单缓冲区流水延迟模型（交替编号 / 错位命名法）**

这是综合大题最容易拉开分差的硬核考点。

  

- **物理现象**：磁盘一旦启动旋转便**匀速不停**。当磁头读完一个扇区（耗时 $T_t$），将数据传送到内存单缓冲区进行 CPU 处理（耗时 $T_{\text{buf}}$）。在 $T_{\text{buf}}$ 时间内，盘片依然在高速旋转。
    
      
    
- **未交替编号（自然顺序连续存放）下的“错过旋转”**：
    
      
    - 读完第 $k$ 扇区后，需要 $T_{\text{buf}}$ 进行处理。若 $T_{\text{buf}} > 0$，当处理完毕时，第 $k+1$ 扇区早已从磁头下方转过。
        
          
        
    - 磁头必须**原地等待盘片转完剩余的一整周（甚至更多周）**，直到第 $k+1$ 扇区再次到达磁头下方。
        
          
        
    - **单块耗时推导**：$\text{处理一个扇区周期} = T_t + T_{\text{rot}} \times \lceil \frac{T_{\text{buf}} - (T_{\text{rot}} - T_t)}{T_{\text{rot}}} \rceil$；最经典情况是每次错过必须干等一周（$T_t + T_{\text{rot}}$），总时间呈倍数级恶化。
        
          
        
- **交替编号（Interleaving）的设计推导**：
    
      
    - 为了消除上述等待空转，扇区间必须留出缓冲时间：
        
          
        
        $$\text{转过扇区间隙所需时间} \ge T_{\text{buf}}$$
        
    - 设转过 1 个扇区时间为 $T_t$，则处理完 1 个扇区期间，盘片转过了 $\lfloor \frac{T_{\text{buf}}}{T_t} \rfloor$ 个物理扇区。
        
          
        
    - 最优间隔编号步距：将逻辑上连续的扇区在物理圆周上相隔 $k$ 个物理扇区放置，使得处理完成的瞬间，逻辑下一个扇区恰好转入磁头下方，达成**完全流水线连续读取**。
        
          
        

#### 3. **四大经典磁盘调度算法与磁头总寻道行程计算**

给定当前磁头位置、移动方向与磁盘请求队列，计算移动的磁道总数（行程）及平均寻道长度：

  

|**调度算法**|**核心调度规则**|**408 核心算力特征与瓶颈**|
|---|---|---|
|**FCFS（先来先服务）**|严格按请求到达队列的物理先后次序服务。|磁臂易产生“剧烈盲目往返抖动”，效率最低，但极公平。|
|**SSTF（最短寻道时间优先）**|每次优先选择距离当前磁头最近的请求磁道。|贪心策略；容易引起远离当前磁头请求的**饥饿（Starvation）**现象。|
|**SCAN（电梯算法）**|磁头沿当前单一方向移动，顺路服务所有请求，**直至磁盘物理边界**再调头反向服务。|克服饥饿；两端与中间请求的平均等待时间不均等。|
|**LOOK**|SCAN 的改良版，沿当前方向移动，**走到该方向最后一个请求点**即立刻调头，无需走到物理尽头。|实际工程与 408 大题中最常用的折返基准。|
|**C-SCAN（循环扫描）**|磁头只在**单向移动时响应请求**，到达边界后**极速空载折返**到另一端起点，重头开始单向扫描。|消除内外磁道等待时间不均等；折返行程全额计入移动磁道数。|
|**C-LOOK**|C-SCAN 的改良版，**单向服务到当前方向最远请求点**后，立刻空载跳回到**对侧最小请求点**。|**408 统考真题默认考核机制**，折返不走空边界。|

#### 4. **磁盘存储容量与空闲空间管理映射模型**

- **非格式化容量 vs 格式化容量**：
    
      
    - 非格式化容量：$\text{盘面数} \times \text{每面磁道数} \times \text{内道周长} \times \text{最大位密度}$。
        
          
        
    - 格式化容量（有效可用容量）：
        
          
        
        $$\text{容量} = \text{记录面数（磁头数）} \times \text{每个盘面的磁道数} \times \text{每个磁道的扇区数} \times \text{扇区字节大小（通常 512B 或 4KB）}$$
        
- **位示图（Bitmap）空间精确映射计算**：
    
      
    - 若磁盘总块数为 $N_{\text{block}}$，每个磁盘块状态用 1 个 bit 表达（0/1 表示空闲/占用）：
        
          
        
        $$\text{位示图所需内存空间} = \lceil \frac{N_{\text{block}}}{8} \rceil \text{ 字节}$$
        
    - **坐标转换映射（极高频）**：
        
          
        - 若按字长 $W$ 位分配，行号 $i$、列号 $j$（下标从 0 还是从 1 开始必须审清）：
            
              
            - 下标从 0 开始：$\text{块号 } b = i \times W + j$；反求 $i = \lfloor b / W \rfloor, j = b \bmod W$。
                
                  
                
            - 下标从 1 开始：$\text{块号 } b = (i - 1) \times W + j$。
                
                  
                

### 3. 【极值 / 边界与易错陷阱】

1. **转速单位与“转半周”的失误陷阱**：
    
      
    - 题目给定 $7200\text{ rpm}$，算每转时间必须严格使用 $T_{\text{rot}} = \frac{60}{7200}\text{ s} = \frac{1}{120}\text{ s} \approx 8.33\text{ ms}$。
        
          
        
    - 算“平均旋转延迟”时必须是**转半周**（除以 2 得到 $4.17\text{ ms}$）；而在单缓冲区连续读扇区漏转时，补偿的惩罚时间是**整整转满一整周（或多周）**，切忌在惩罚中除以 2。
        
          
        
2. **C-SCAN / SCAN 的折返端点边界陷阱（题干隐藏条件）**：
    
      
    - 必须审清是走到“磁盘物理两端极值（0 号与 Max 号磁道）”还是走到“队列中最远请求点”：
        
          
        - 若题干明确给出了“柱面范围为 $0 \sim 199$”，且强调是标准 SCAN/C-SCAN，折返点必须打到边界 0 或 199。
            
              
            
        - 若题干未给物理边界（仅给请求列表），或者指明是 C-LOOK/LOOK，折返点只能取请求队列中的最大值与最小值。
            
              
            
3. **柱面号、磁头号、扇区号（CHS）的递增排序边界**：
    
      
    - 物理寻址三元组 $\text{(Cylinder, Head, Sector)}$。
        
          
        
    - 数据写入的最佳物理连续路径顺序应为：**先填满同一个柱面下的所有磁头（盘面），再步进到下一个柱面**（因为切换电子磁头极快，而移动机械臂换柱面耗时极大）。如果题目考查簇/块在盘上的映射顺序，切勿先换柱面。
        
          
        
4. **闪存 SSD vs 机械磁盘的调度陷阱**：
    
      
    - 当存储介质变为固态硬盘（SSD / Flash）时，由于没有机械寻道与旋转延迟，**任何基于物理位置排序的调度算法（SSTF、SCAN、CSCAN）失去意义甚至带来排序负优化**，此时最优调度算法退化为 **FCFS（或 No-op）**。
        
          
        

### 4. 【同源延伸与变式盲区】

- **命题变形**：
    
      
    - _变式 1（双缓冲区 / 循环缓冲区吞吐率）_：若将单缓冲区升级为双缓冲区，当 CPU 处理缓冲区 1 的同时，磁头可以直接将下一扇区填入缓冲区 2。只要 $T_{\text{buf}} \le T_t$，系统即可实现满速流水作业，无需交替编号也能达到零停顿。
        
          
        
    - _变式 2（RAID 阵列读写并发性能）_：RAID 0 依靠数据条带化并发提升读写速率；RAID 1 利用镜像提高可靠性但容量折半；RAID 5 具备容错能力，其校验块采用轮转分布，写一个数据块需引发“2 次读 + 2 次写”的写惩罚（Write Penalty）。
        
          
        
- **解题心法**：
    
      
    
    > **“寻道移臂转找头，半周延迟算平均；单缓错位相间隔，闪存电寻用先来。”**
