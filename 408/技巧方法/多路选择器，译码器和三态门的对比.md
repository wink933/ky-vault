2. **微体系结构数据通路中的协同运作链条推导**：
    
      
    - 设一条汇编指令 `ADD R1, R2` 在单总线 CPU 内部执行：
        
          
        - **译码器**首先介入：指令寄存器（IR）中的操作码字段（如 `0011`）送入**指令译码器**，译码输出端激活动作控制信号线；寄存器地址字段（如 `001`）送入**地址译码器**，译出 $R_1$ 的选通信号；
            
              
            
        - **三态门**提供输出驱动：控制器发出使能脉冲激活 $R_1$ 的输出三态门（$R_1\text{out} = 1$），$R_1$ 退出高阻态，将数据驱动到 CPU 内部公共数据总线上；此时其他寄存器三态门使能均为 0（保持高阻态 $Z$ 隔离）；
            
              
            
        - **多路选择器 (MUX)** 动态切换通路：在 ALU 的前端，MUX 根据控制字选择将来自内部总线的数据，还是来自暂存器、或硬连线立即数（如单步自增的常数 2 或 4）选入 ALU 的运算端口进行运算。
            
              
            

### 3. 【极值 / 边界与易错陷阱】

- **“MUX 选数据”与“三态门并联上总线”的设计权衡盲区**：
    
    两者都能实现“让特定数据传给目的地”，考研中常考查其架构取舍：
    
      
    - **多路选择器 MUX**：属于**集中式逻辑**。数据信号必须先拉专线汇聚到 MUX 输入端。如果连接 16 个 32 位寄存器，布线数量高达 $16 \times 32 = 512$ 根数据线，布线拥堵、芯片面积利用率差，通常仅用于部件局部的点对点切换；
        
          
        
    - **三态门总线**：属于**分布式共享逻辑**。所有部件共用 32 根总线金属线，各部件输出口串联一个三态门后就地并接在总线上。扩展新部件无需重新布线，但同一节拍**严禁两个及以上三态门同时导通**（否则总线电平冲突甚至短路烧片）。
        
          
        
- **混淆“三态门的高阻态 $Z$”与“译码器的未选通输出（$0$ 或 $1$）”**：
    
      
    - 译码器输出端没有高阻态，它输出的是**强电平**（高有效时未选中为逻辑 0，低有效时未选中为逻辑 1）；
        
          
        
    - 三态门未选中时输出的是**断路开路（高阻态 $Z$）**，绝不是输出低电平 0。
        
          
        
- **将“编码器”与“译码器”搞反**：
    
      
    - **译码器（$n \to 2^n$）**：少数输入线 $\to$ 多数控制线（如 3-8 译码器）；
        
          
        
    - **编码器（$2^n \to n$）**：多数信号线 $\to$ 少数代码线（如 8-3 优先权编码器，用于硬件中断排队生成中断向量号）。
        
          
        

### 4. 【同源延伸与变式盲区】

- **同源变式场景**：
    
      
    - **变式 1（用三态门搭建分布式 MUX）**：
        
        “若没有硬件 MUX，如何使用三态门和译码器实现 $N$ 选 1 的功能？”
        
          
        - 解法：将 $N$ 个数据源的输出端分别串接一个三态门，三态门输出引脚全部并联接到单根输出线上；用一个 $\lceil \log_2 N \rceil$ 位的译码器连接这 $N$ 个三态门的使能端，译码器选中哪个通道，就打开哪个三态门，等效构建出一个超大规模的低布线 MUX。
            
              
            
    - **变式 2（存储器字位扩展中的译码使能引脚）**：
        
        “主存扩展时，为什么 74LS138 译码器的使能端（$E_1, \overline{E_2}, \overline{E_3}$）常接 CPU 的访存请求信号 $\overline{\text{MREQ}}$？”
        
          
        - 答：防止非访存操作（如 I/O 操作或内部运算时）地址总线残留电平引发存储器误片选；只有在 CPU 真正发起访存时，才打开译码器产生选中片选信号 $\overline{\text{CS}}$。
            
              
            
- **解题心法口诀**：
    
      
    
    > **“译码展开成片选（$n \to 2^n$ 控信号），多路汇聚挑一路（$N \to 1$ 选数据）；并线上总必三态，断路高阻避火灾（防短路冲突）。”**
