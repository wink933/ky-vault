- **章节模块**：第二章 数据的表示和运算 - 定点数的表示（机器数与真值、原码/反码/补码/移码的双向转换机制）
    
      
    
- **核心能力层级**：概念辨析与底层编码映射规律推导
    
      
    

### 2. 【核心考点精析】

1. **[概念辨析：补码与机器数的包含关系]**：
    
      
    - **核心定义**：**机器数（Machine Number）** 是指数据在计算机内部的最终二进制表示形式，包括**符号位**和**数值位**；而**补码（Two's Complement）**、原码、反码、移码则是机器数所采用的具体**编码规则（规则体制）**。
        
          
        
    - **映射逻辑**：当题目指出“带符号整数采用补码表示”时，**该数值的“补码”本身就等于该数值的“机器数”**。日常做题中的“求机器数”，本质是指：
        
          
        - **场景 A（已知真值 $x$，求其机器数 $[x]_{\text{补}}$）**：将数学真值转换为符合特定位宽 $n$ 的补码二进制串（通常以十六进制书写）；
            
              
            
        - **场景 B（已知负数补码 $[x]_{\text{补}}$，求其相反数的补码 $[-x]_{\text{补}}$ 或原码机器数 $[x]_{\text{原}}$）**：在不同编码机器数之间进行状态变换。
            
              
            
2. **[场景 A：由真值 $x$ 极速生成补码机器数 $[x]_{\text{补}}$]**：
    
      
    - **若真值 $x \ge 0$**：
        
          
        - 最高符号位取 `0`，数值位直接转化为二进制，高位补 0 对齐目标字长。
            
              
            
        - 例：$n=8, x = +41\text{D} = 29\text{H}$，其补码机器数直接为 `0010 1001B`（`29H`）。
            
              
            
    - **若真值 $x < 0$**（设字长为 $n$ 位）：
        
          
        - **模运算法（最严谨的数学定义）**：
            
              
            
            $$[x]_{\text{补}} = 2^n + x = 2^n - \vert{}x\vert{} \pmod{2^n}$$
            
        - **“取反加一”法（经典硬件实现流）**：
            
            先写出绝对值 $\vert{}x\vert{}$ 的二进制表示，最高符号位记为 `1`（原码），随后**符号位不变，数值位全部按位取反，末位加 1**。
            
              
            
        - **“从右向左扫描法”（考场极速手算法）**：
            
            先写出 $\vert{}x\vert{}$ 的完整 $n$ 位无符号二进制串；从最右边（最低有效位 LSB）开始向左扫描，**直到遇到第一个 `1` 为止，该 `1` 及其右侧的所有 `0` 原样照抄；该 `1` 左侧的所有高位（包括符号位）全部按位取反（0 变 1，1 变 0）**。
            
              
            - _示例_：设 $n=16, x = -68$。
                
                $68\text{D} = \text{0000 0000 0100 0100B}$；
                
                从右往左看，第一个 `1` 出现在第 2 位（权值 4 处），因此低 3 位 `100` 照抄；
                
                左侧所有位全部取反，得到：`1111 1111 1011 1100B`（`FFBCH`），无需列加法竖式一步成型。
                
                  
                
3. **[场景 B：已知机器数 $[x]_{\text{补}}$，求相反数机器数 $[-x]_{\text{补}}$ 或还原真值]**：
    
      
    - **由 $[x]_{\text{补}}$ 求 $[-x]_{\text{补}}$（底层硬件求相反数机理）**：
        
          
        - **定理**：不论正负，也不论符号位：
            
              
            
            $$[-x]_{\text{补}} = \sim [x]_{\text{补}} + 1$$
            
            即**对 $[x]_{\text{补}}$ 连同符号位在内的全部二进制位进行按位取反，然后在末位加 1**（同样严格适用“从右向左扫描，遇到首个 1 后左侧全部取反”）。
            
              
            
    - **由机器数 $[x]_{\text{补}}$ 逆求真值 $x$**：
        
          
        - 若符号位为 `0`，真值直接等于数值位的无符号值；
            
              
            
        - 若符号位为 `1`（负数）：
            
              
            
            $$x = [x]_{\text{补}} - 2^n = - ([-x]_{\text{补}})$$
            
            直接使用 $[-x]_{\text{补}} = \sim [x]_{\text{补}} + 1$ 算出其相反数的大小，再冠以负号即可。
            
              
            

### 3. 【极值 / 边界与易错陷阱】

- **补码特有的不对称极小值陷阱（$-2^{n-1}$）**：
    
      
    - 8 位补码的表示范围是 $[-128, +127]$，16 位是 $[-32768, +32767]$，32 位是 $[-2^{31}, 2^{31}-1]$。
        
          
        
    - **边界值 $-2^{n-1}$（如 8 位的 `1000 0000B` / 16 位的 `8000H`）**：
        
          
        - 该数**没有对应的原码表示**（原码 8 位只能表示 $-127 \sim +127$）；
            
              
            
        - 若对其强制求相反数 $[-x]_{\text{补}} = \sim(10000000) + 1 = 01111111 + 1 = 10000000$，结果仍为其自身，在硬件上判定为**溢出（$OF = 1$）**。
            
              
            
- **字长对齐（符号扩展 vs 零扩展）陷阱**：
    
      
    - 许多考生在求较小负数（如 $-33$）的机器数时，只算了 8 位补码（`DFH`），题干要求的是 `int`（32 位），直接拼凑成 `0000 00DFH` 导致正负性颠覆。
        
          
        
    - **符号扩展铁律**：补码从短字长扩展到长字长时，**高位一律填充符号位**（正数补 `0`，负数补 `1`，负数高位全部扩为 `F`，即 `FFFF FFDFH`）。
        
          
        

### 4. 【同源延伸与变式盲区】

- **命题变形**：
    
      
    1. _移码（Offset Binary）互转_：在定点整数中，**同一数值的移码与补码仅差一个符号位**（符号位互补，数值位完全一致），即 $[\text{移码}] = [\text{补码}] \oplus 2^{n-1}$（最高位取反）。
        
          
        
    2. _大端（Big-Endian）与小端（Little-Endian）内存排布结合_：求出机器数 `FFFF FFDFH` 后，设问“该整数在小端存储方式下，低地址第一个字节存放的是什么？” $\rightarrow$ 低位低地址，最低有效字节（`DFH`）存放在低地址端。
        
          
        
    3. _补码加减法硬件运算单元（ALU）控制信号_：实现 $[A - B]_{\text{补}} = [A]_{\text{补}} + [\sim B]_{\text{补}} + 1$。输入端送入 $B$ 的反码，加法器进位输入端 $C_{\text{in}} = 1$，一步完成求相反数加法。
        
          
        
- **解题心法**：
    
      
    
    > 补码本身即机器，正数不变负变局；遇首个一右全照，左侧翻转神速出。
