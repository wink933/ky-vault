### 2. 【核心考点精析】

时间复杂度的核心是**求算法中原操作（基本语句）的执行频度关于问题规模 $n$ 的渐进阶数**。408 考查的全部代码片段可系统解构为以下 5 种数学模型：

  

#### 1. **单层循环模型的代数方程转化法**

- **定步长加减模型（$O(n)$ 阶）**：
    
      
    
    C
    
    ```
    for (int i = 0; i < n; i += k) { ... } // 执行次数：n / k -> O(n)
    ```
    
- **指数/对数步长模型（$O(\log n)$ 阶）**：
    
      
    
    C
    
    ```
    int i = 1;
    while (i < n) { i *= 2; }
    ```
    
    - **推导机制**：设执行 $t$ 次，则 $i$ 的取值序列为 $1, 2, 4, \dots, 2^t$。
        
          
        
    - 循环终止条件为 $i \ge n \implies 2^t \ge n \implies t = \lceil \log_2 n \rceil$。
        
          
        
    - 渐进时间复杂度为 $O(\log n)$。底数无论为 2 还是 3，由于换底公式 $\log_a n = \frac{\log_2 n}{\log_2 a}$，常数系数被大 $O$ 吸收。
        
          
        
- **高次幂迭代与开方步长模型（$O(\sqrt{n})$ 或更低）**：
    
      
    
    C
    
    ```
    int y = 0;
    while ((y + 1) * (y + 1) <= n) { y = y + 1; }
    ```
    
    - **推导机制**：设执行 $t$ 次，循环结束时 $(t+1)^2 > n \implies t \approx \sqrt{n}$，时间复杂度为 $O(\sqrt{n})$。
        
          
        
    
    C
    
    ```
    int count = 0;
    for (int i = 2; i < n; i = i * i) { count++; }
    ```
    
    - **推导机制**：变量 $i$ 变化为 $2 \to 2^2 \to 2^4 \to 2^8 \to \dots \to 2^{2^t}$。
        
          
        
    - 终止条件 $2^{2^t} \ge n \implies 2^t \ge \log_2 n \implies t = O(\log \log n)$。
        
          
        

#### 2. **嵌套循环模型的级数求和法（级数放缩与累加）**

嵌套循环切忌直接将各层上界相乘，必须写出**外层循环变量控制下的内层求和式** $\sum_{i} (\text{内层执行次数})$：

  

- **算术级数（等差型，内外变量耦合）**：
    
      
    
    C
    
    ```
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= i; j++)
            x++;
    ```
    
    - **推导机制**：
        
          
        
        $$T(n) = \sum_{i=1}^{n} \sum_{j=1}^{i} 1 = \sum_{i=1}^{n} i = \frac{n(n+1)}{2} = O(n^2)$$
        
- **几何级数（倍增型内层变量）**：
    
      
    
    C
    
    ```
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j *= 2)
            x++;
    ```
    
    - **推导机制**：内层与外层相互独立，内层恒为 $\log_2 n$ 次：
        
          
        
        $$T(n) = \sum_{i=1}^{n} (\log_2 n) = n \log_2 n = O(n \log n)$$
        
- **调和级数模型（倍数跳步型，经典高频陷阱）**：
    
      
    
    C
    
    ```
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j += i)
            x++;
    ```
    
    - **推导机制**：内层执行次数为 $\lfloor \frac{n}{i} \rfloor$：
        
          
        
        $$T(n) = \sum_{i=1}^{n} \frac{n}{i} = n \sum_{i=1}^{n} \frac{1}{i} = n \cdot \left( \ln n + \gamma + O\left(\frac{1}{n}\right) \right) = O(n \log n)$$
        

#### 3. **递归程序片段的递推方程法（主定理 Master Theorem）**

递归程序的时间复杂度表示为递推关系式 $T(n) = a T(n/b) + f(n)$（$a \ge 1, b > 1$）：

  

- **通用判定法则（三种关键状态）**：
    
    计算临界指数 $p = \log_b a$，比较 $f(n)$ 与 $n^p$ 的增长速度：
    
      
    1. **$f(n) = O(n^{p - \varepsilon})$（叶子结点占主导）**：
        
          
        
        $$T(n) = \Theta(n^{\log_b a})$$
        
        _典型示例_：大整数乘法 Karatsuba 算法 $T(n) = 3T(n/2) + O(n) \implies O(n^{\log_2 3}) \approx O(n^{1.585})$。
        
          
        
    2. **$f(n) = \Theta(n^p \log^k n)$（各层开销均匀）**：
        
          
        
        $$T(n) = \Theta(n^{\log_b a} \log^{k+1} n)$$
        
        _典型示例_：归并排序 $T(n) = 2T(n/2) + O(n) \implies a=2, b=2, p=1$，$f(n) = n^1 \implies T(n) = O(n \log n)$。
        
        _典型示例_：折半查找 $T(n) = T(n/2) + O(1) \implies a=1, b=2, p=0$，$f(n) = n^0 \implies T(n) = O(\log n)$。
        
          
        
    3. **$f(n) = \Omega(n^{p + \varepsilon})$ 且满足正则条件（根结点开销占主导）**：
        
          
        
        $$T(n) = \Theta(f(n))$$
        
- **减治模型（线性递推）**：
    
      
    - 形式：$T(n) = T(n-1) + O(1) \implies T(n) = O(n)$。
        
          
        
    - 斐波那契递归：$T(n) = T(n-1) + T(n-2) + O(1) \implies$ 递归树形态为二叉树，节点总数达 $2^n \implies T(n) = O(2^n)$。
        
          
        

#### 4. **平摊复杂度（Amortized Complexity）与双指针滑动窗口分析**

408 经常考查形式上看似是 $O(n^2)$、实则是 $O(n)$ 的线性算法：

  

- **双指针 / 游标单调前进模型**：
    
      
    
    C
    
    ```
    int i = 0, j = 0;
    while (i < n && j < n) {
        if (arr[i] < arr[j]) i++;
        else j++;
    }
    ```
    
    - **核心机制**：循环体内每执行一步，必然导致 $i$ 或 $j$ 至少有一个递增 1。由于 $i < n$ 且 $j < n$，循环最多总共执行 $2n$ 次，故时间复杂度严格为 $O(n)$，决不能因为两个游标而误判为 $O(n^2)$。
        
          
        
- **KMP 算法的 `next` 数组求值与模式匹配**：
    
      
    - 内部 `while(k > 0 && P[q] != P[k]) k = next[k];` 尽管有内层回溯，但利用势能分析法，指针推进总数受限于文本串长度 $n$ 和模式串长度 $m$，匹配总耗时为 $O(n + m)$。
        
          
        

### 3. 【极值 / 边界与易错陷阱】

1. **输入敏感型（Input-sensitive）的最坏、最好与平均情况界定**：
    
      
    - 快速排序：
        
          
        - **最好 / 平均情况**：每次划分严格对称，递推式为 $T(n) = 2T(n/2) + O(n) \implies O(n \log n)$。
            
              
            
        - **最坏情况（极值陷阱）**：输入序列已有序（正序或逆序），基准元素沦为边界极值，划分极度倾斜，递推式退化为 $T(n) = T(n-1) + O(n) \implies T(n) = O(n^2)$。
            
              
            
    - 插入排序 / 冒泡排序：输入已有序时，一次遍历直接跳出，最好为 $O(n)$；逆序时为最坏 $O(n^2)$。
        
          
        
2. **循环控制变量与数组维度的非对称陷阱**：
    
      
    - 审清变量边界到底由谁限制。例如两层循环中，内层是 `for (int j = 1; j <= m; j++)`，若未声明 $m = n$，复杂度应写为 $O(m \cdot n)$，切勿盲目写成 $O(n^2)$。
        
          
        
3. **“加法规则”与“乘法规则”的高阶吞噬**：
    
      
    - $T(n) = T_1(n) + T_2(n) = \max(O(f(n)), O(g(n)))$。
        
          
        
    - 若算法由若干独立模块顺序执行组成，由增长最快的最高阶主导，例如 $O(n) + O(n \log n) + O(\log n) = O(n \log n)$。只有嵌套调用时才使用乘法规则 $O(f(n) \times g(n))$。
        
          
        

### 4. 【同源延伸与变式盲区】

- **命题变形**：
    
      
    - _变式 1（条件截断型循环）_：
        
          
        
        C
        
        ```
        for (int i = 0; i < n; i++)
            if (arr[i] == target) break;
        ```
        
        题目若不加说明，默认求**最坏情况复杂度**（遍历到底未找到，$O(n)$）；若考查“等概率成功查找”，则为平均复杂度 $\frac{n+1}{2} = O(n)$。
        
          
        
    - _变式 2（空间换时间与递归工作栈）_：考查时间复杂度的同时要求给出**空间复杂度**。特别注意递归调用时的**递归调用栈深度**（如快排最好递归深度为 $O(\log n)$，最坏递归深度为 $O(n)$）。
        
          
        
    - _变式 3（矩阵压缩存储与转置运算）_：三元组稀疏矩阵转置中，“普通转置法”外层按列扫描 $O(n \times t)$；“快速转置法”利用辅助数组 `num` 和 `cpot`，时间降至 $O(n + t)$，属于典型的通过数学辅助信息抹除内层冗余遍历的考点。
        
          
        
- **解题心法**：
    
      
    
    > **“单层步长寻反解，双重嵌套写级数；调和反比带对数，递归主设定胜负。”**
