在考研数据结构（统考 408 及各校自命题）中，树与二叉树是**考查频次最高、题型覆盖最广**的板块。涵盖选择题的**性质计算与遍历重构**，以及算法设计大题的**递归遍历、路径搜索、属性验证**等。

  

### 一、 核心基础：二叉树的五大高频定量性质

1. **叶子节点与度为 2 的节点关系**：
    
      
    - 在任意非空二叉树中，度为 0 的节点数（叶子节点 $n_0$）与度为 2 的节点数 $n_2$ 恒满足：
        
          
        
        $$n_0 = n_2 + 1$$
        
    - _证明线索_：边数 $B = n - 1 = n_1 + 2n_2$，同时总节点数 $n = n_0 + n_1 + n_2$，联立两式即可消去 $n_1$。
        
          
        
2. **完全二叉树的下标对应规律**（基于 1-based 顺序存储，共 $n$ 个节点）：
    
      
    - 节点 $i$ 的父节点为 $\lfloor i/2 \rfloor$（若 $i > 1$；$i=1$ 为根）。
        
          
        
    - 节点 $i$ 的左孩子为 $2i$（若 $2i \le n$，否则无左孩子）。
        
          
        
    - 节点 $i$ 的右孩子为 $2i + 1$（若 $2i + 1 \le n$，否则无右孩子）。
        
          
        
    - **最后一个非叶子节点下标**为 $\lfloor n/2 \rfloor$（堆排序建堆起点）。
        
          
        
    - 节点 $i$ 所在层次为 $\lfloor \log_2 i \rfloor + 1$。
        
          
        
3. **完全二叉树的叶子节点与度为 1 节点限制**：
    
      
    - 完全二叉树中度为 1 的节点数 $n_1$ **只能是 0 或 1**。
        
          
        
    - 若 $n$ 为奇数，则 $n_1 = 0$；若 $n$ 为偶数，则 $n_1 = 1$。
        
          
        
4. **树高与最大/最小节点数**：
    
      
    - 高度为 $h$ 的二叉树最多有 $2^h - 1$ 个节点（满二叉树）。
        
          
        
    - 拥有 $n$ 个节点的完全二叉树高度为 $\lceil \log_2(n + 1) \rceil$ 或 $\lfloor \log_2 n \rfloor + 1$。
        
          
        

### 二、 遍历体系与树的重构

#### 1. 四种经典遍历模式

- **前序遍历 (N-L-R)**：根 $\rightarrow$ 左子树 $\rightarrow$ 右子树（常用于复制树、前缀表达式）。
    
      
    
- **中序遍历 (L-N-R)**：左子树 $\rightarrow$ 根 $\rightarrow$ 右子树（**BST 的中序遍历为严格递增序列**）。
    
      
    
- **后序遍历 (L-R-N)**：左子树 $\rightarrow$ 右子树 $\rightarrow$ 根（常用于求树高、释放树节点、自底向上计算属性、后缀表达式）。
    
      
    
- **层序遍历**：借助辅助队列 FIFO 逐层遍历（常用于找最深叶子、判断完全二叉树、求树宽）。
    
      
    

#### 2. 二叉树的重构定理

- **唯一确定一棵二叉树的充要条件**：
    
      
    - **必须含有中序遍历序列**，再配合**前序**、**后序**或**层序**之一。
        
          
        
    - _原因_：前序/后序/层序决定“谁是根节点”，中序遍历利用根节点将序列精确切分为“左子树区间”和“右子树区间”。
        
          
        
- **反例**：仅凭“前序 + 后序”**无法**唯一确定二叉树（当存在单支节点时无法区分左右子树）。
    
      
    

### 三、 线索二叉树 (Threaded Binary Tree)

- **设计初衷**：在拥有 $n$ 个节点的二叉树中，存在 $2n - (n - 1) = n + 1$ 个空指针域。利用这些空指针存放节点在某种遍历序列下的**前驱**与**后继**信息。
    
      
    
- **节点结构**：
    
      
    - `lchild`、`ltag`、`data`、`rtag`、`rchild`
        
          
        
    - `ltag = 0`：`lchild` 指向左孩子；`ltag = 1`：`lchild` 指向直接前驱（线索）。
        
          
        
    - `rtag = 0`：`rchild` 指向右孩子；`rtag = 1`：`rchild` 指向直接后继（线索）。
        
          
        
- **中序线索二叉树考点**：
    
      
    - **找后继**：若 `rtag == 1`，则 `rchild` 即为后继；若 `rtag == 0`，后继为该节点**右子树中最左下的节点**（右孩子的左子树不断往左下走）。
        
          
        
    - **找前驱**：若 `ltag == 1`，则 `lchild` 即为前驱；若 `ltag == 0`，前驱为该节点**左子树中最右下的节点**。
        
          
        

### 四、 树、森林与二叉树的转换

- **孩子兄弟表示法（二叉链表表示法）**：
    
      
    - 左指针 `firstchild` 指向结点的第一个孩子。
        
          
        
    - 右指针 `nextsibling` 指向结点的下一个兄弟（“左孩子，右兄弟”）。
        
          
        
- **遍历对应关系（高频客观题考点）**：
    
      
    

|**树的遍历**|**森林的遍历**|**对应二叉树的遍历**|
|---|---|---|
|**先根遍历**|**先根（先序）遍历**|**前序遍历**|
|**后根遍历**|**后根（中序）遍历**|**中序遍历**|

_注：树没有中序遍历，森林有中序（后根）遍历。_

  

### 五、 核心专用树与动态平衡体系

#### 1. 二叉排序树 (BST - Binary Search Tree)

- **性质**：左子树所有节点键值 $<$ 根节点键值 $<$ 右子树所有节点键值。
    
      
    
- **删除操作规范**：
    
      
    - 若待删节点 $z$ 为叶子，直接删除。
        
          
        
    - 若 $z$ 只有左子树或只有右子树，用子树根替代 $z$。
        
          
        
    - 若 $z$ 有左右两个孩子，用 $z$ 的**直接前驱**（左子树最大点）或**直接后继**（右子树最小点）替代 $z$ 的键值，然后转化为删除该前驱或后继节点。
        
          
        

#### 2. 平衡二叉树 (AVL 树)

- **定义**：左右子树高度差（平衡因子 $\text{BF} = h_L - h_R$）绝对值不大于 1，即 $\text{BF} \in \{-1, 0, 1\}$。
    
      
    
- **四种旋转调整**（失衡点为 $A$，发现者为新插入点）：
    
      
    - **LL 旋转**：在 $A$ 的左孩子的左子树插入导致失衡 $\rightarrow$ 单次**右旋**。
        
          
        
    - **RR 旋转**：在 $A$ 的右孩子的右子树插入导致失衡 $\rightarrow$ 单次**左旋**。
        
          
        
    - **LR 旋转**：在 $A$ 的左孩子的右子树插入导致失衡 $\rightarrow$ 先对左孩子**左旋**，再对 $A$ **右旋**。
        
          
        
    - **RL 旋转**：在 $A$ 的右孩子的左子树插入导致失衡 $\rightarrow$ 先对右孩子**右旋**，再对 $A$ **左旋**。
        
          
        
- **节点数递推关系（经典选择题计算）**：
    
      
    - 深度为 $h$ 的 AVL 树所需的**最少节点数**递推式：
        
          
        
        $$N_0 = 0, \quad N_1 = 1, \quad N_2 = 2, \quad N_h = N_{h-1} + N_{h-2} + 1$$
        

#### 3. 红黑树 (Red-Black Tree) —— 考研新大纲重点

- **五大红黑性质**：
    
      
    1. 节点要么是红色的，要么是黑色的。
        
          
        
    2. **根节点是黑色的**。
        
          
        
    3. **叶节点（外部叶子虚节点 NIL）是黑色的**。
        
          
        
    4. **红节点不相邻**：若一个节点是红色的，则它的两个子节点必须是黑色的。
        
          
        
    5. **黑高平衡**：对每个节点，从该节点到其所有后代叶节点的简单路径上，均包含**相同数目的黑色节点**。
        
          
        
- **关键性质结论**：
    
      
    - 包含 $n$ 个内部节点的红黑树高度最大不超过 $2\log_2(n + 1)$，查找、插入、删除时间复杂度稳定在 $O(\log_2 n)$。
        
          
        

#### 4. 哈夫曼树 (Huffman Tree) 与编码

- **定义**：带权路径长度 (WPL) 达到最小的二叉树（最优二叉树）。
    
      
    
    $$\text{WPL} = \sum_{i=1}^n w_i \cdot l_i$$
    
- **构造规则**：
    
      
    1. 选取权值最小的两棵树作为左右子树构建新父节点，新父节点的权值为两者之和。
        
          
        
    2. 原两棵树从集合中移出，新节点放回集合。
        
          
        
    3. 重复直至只剩一棵根树。
        
          
        
- **考研高频性质**：
    
      
    - 包含 $n$ 个叶子节点的哈夫曼树**不存在度为 1 的节点**（$n_1 = 0$）。
        
          
        
    - 总结点数恒为 $2n - 1$；执行合并的次数为 $n - 1$。
        
          
        
    - **前缀编码特性**：任意一个字符的编码都不是另一个字符编码的前缀，哈夫曼树中所有有效字符节点均处于叶子节点位置。
        
          
        

### 六、 算法大题高频递归模板总结

考研 408 算法大题若涉及二叉树，**90% 以上采用递归（分治回溯）完成**。其标准解题结构可概括为：

  

1. **基底条件 (Base Case)**：空指针判断 `if (root == NULL) return ...;`
    
      
    
2. **递归子问题处理**：分别调用 `dfs(root->left)` 与 `dfs(root->right)`
    
      
    
3. **本层合并决策**：
    
      
    - **后序自底向上汇总**（如：计算树高度、计算 WPL、寻找最近公共祖先 LCA、检查是否为平衡二叉树）。
        
          
        
    - **前序自顶向下传参**（如：记录根到当前节点的路径和、检查对称二叉树）。
