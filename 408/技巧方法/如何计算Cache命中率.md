### 2. 【核心考点精析】

1. **Cache 命中率与缺失率的统计学定义**：
    
      
    - 设在一个特定程序执行周期内，CPU 对 Cache 发起的访存总次数为 $N$；
        
          
        
    - 其中能够在 Cache 中直接命中并成功读取数据的次数为 $N_c$；
        
          
        
    - 未能在 Cache 中命中、需要转向主存（或下一级 Cache）读取的缺失次数为 $N_m$（满足 $N = N_c + N_m$）。
        
          
        
    - **Cache 命中率（Hit Rate, $H$）**：
        
          
        
        $$H = \frac{N_c}{N} = \frac{N_c}{N_c + N_m}$$
        
    - **Cache 缺失率 / 失效率（Miss Rate, $M$）**：
        
          
        
        $$M = 1 - H = \frac{N_m}{N_c + N_m}$$
        
2. **平均访问时间（Average Memory Access Time, AMAT）的核心推导**：
    
    在 408 考题中，命中率几乎从不孤立考察，必然与 Cache 存取时间 $t_c$ 及主存存取时间 $t_m$（或缺失惩罚 Miss Penalty）结合计算平均访问时间 $t_a$。根据底层硬件并发控制逻辑，分为两种基本体系模型：
    
      
    - **模型一：Cache 与主存“并行访问”体系（先并发启动）**
        
          
        - CPU 发出访存请求时，同时向 Cache 和主存发送地址。
            
              
            
        - 若 Cache 命中（概率为 $H$），立即终止主存访问，耗时为 $t_c$；
            
              
            
        - 若 Cache 缺失（概率为 $1 - H$），继续等待主存完成访问，总耗时即为主存访问时间 $t_m$。
            
              
            
        - **计算公式**：
            
              
            
            $$t_a = H \cdot t_c + (1 - H) \cdot t_m$$
            
    - **模型二：Cache 与主存“串行 / 先后访问”体系（层级式穿透）**
        
          
        - CPU 先查询 Cache，耗时 $t_c$。
            
              
            
        - 若命中（概率为 $H$），总耗时为 $t_c$；
            
              
            
        - 若未命中（概率为 $1 - H$），在耗费了 $t_c$ 的检测时间后，才开始启动对主存的访问，访问主存耗时 $t_m$，总耗时为 $t_c + t_m$。
            
              
            
        - **计算公式**：
            
              
            
            $$t_a = H \cdot t_c + (1 - H)(t_c + t_m) = t_c + (1 - H) \cdot t_m$$
            
            _(注：此时缺失惩罚 Miss Penalty 为 $t_m$)_。
            
              
            
3. **访问效率（Access Efficiency, $e$）度量**：
    
    衡量引入 Cache 后系统速度提升逼近理想 Cache 的程度：
    
      
    
    $$e = \frac{t_c}{t_a} \times 100\%$$
    
    $e$ 越接近 1（或 100%），表明命中率足够高，存储体系整体性能越逼近纯 Cache 的极限存取速度。
    
      
    

### 3. 【极值 / 边界与易错陷阱】

- **陷阱一：审题不清“并行访问”与“先查 Cache 再访主存”**。
    
    这是 408 综合题中最隐蔽的丢分点！
    
      
    - 若题干描述为“Cache 和主存同时访问”：套用 $t_a = H \cdot t_c + (1 - H) \cdot t_m$；
        
          
        
    - 若题干描述为“Cache 缺失时才访问主存”或“先访问 Cache，不命中再访主存”：未命中时的代价是 $t_c + t_m$，必须套用 $t_a = t_c + (1 - H) \cdot t_m$。
        
          
        
- **陷阱二：缺失调块与 CPU 读取的时序重叠**。
    
    当 Cache 缺失从主存调入整块时：
    
      
    - 若支持“关键字优先（Critical-Word-First）”或尽早重启：主存送回 CPU 所需字后 CPU 立即继续执行，缺失惩罚仅为一个字的访问延迟；
        
          
        
    - 若要求“整块全部载入 Cache 后 CPU 再从 Cache 读取”：缺失惩罚包含整块传输时间 + 再次读 Cache 时间。
        
          
        
- **陷阱三：写操作（Write-Through vs Write-Back）对命中率与访存时间的影响**。
    
      
    - 全写法（Write-Through）若无写缓冲（Write Buffer），每次写操作不论是否命中 Cache 都必须写主存，会强制增加主存访存次数；
        
          
        
    - 写回法（Write-Back）仅在 Cache 行被换出且“脏位（Dirty Bit）”为 1 时才写回主存。
        
          
        

### 4. 【同源延伸与变式盲区】

- **同源变式一（二级 Cache / 多级层次结构扩展）**：
    
    若系统配备 L1 Cache、L2 Cache 和主存（Main Memory），求 CPU 的平均访存时间：
    
      
    - 设 L1 命中率为 $H_1$，访问时间为 $t_1$；L2 局部命中率为 $H_2$（全局命中率为 $H_{2,\text{global}} = (1 - H_1)H_2$），访问时间为 $t_2$；主存访问时间为 $t_m$。
        
          
        
    - 串行层级模型下的 AMAT 公式为：
        
          
        
        $$t_a = t_1 + (1 - H_1) \cdot \Big( t_2 + (1 - H_2) \cdot t_m \Big)$$
