作为你的 **“408 计算机组成原理复习助手”**，我为你精准提炼 408 第二章“程序的机器级代码表示”综合大题中最核心的**常规算术运算指令**（以 x86 架构为例）。

在阅读 C 语言反汇编代码时，这些指令是翻译底层数学逻辑（如 `a = b + c` 或 `i++`）的绝对主力。

### 结论

在 32 位 x86 汇编中，常见的算术运算指令主要涵盖加法（`add`）、减法（`sub`）、乘法（`imul`）、除法（`idiv`）以及自增自减（`inc`/`dec`）。 它们的核心规律是：**运算结果通常会覆盖第一个操作数（目的操作数），并且几乎都会改变标志寄存器（EFLAGS）中的条件标志（如 ZF、SF、OF、CF），为后续的条件分支（if-else）提供判断依据**。

---

### 关键点：核心指令与底层机制

根据资料，请务必掌握以下 4 类高频算术指令：

**1. 加法与减法指令：`add` / `sub`**

- **机制**：双操作数指令。执行 `add A, B` 相当于 $A = A + B$；执行 `sub A, B` 相当于 $A = A - B$。
- **操作数类型**：可以是寄存器（reg）、内存（mem）或立即数（imm）。
- _(汇编示例)_：`add eax, dword ptr [ebp+8]` 代表将内存中的参数与 `eax` 相加，结果存回 `eax`。

**2. 自增与自减指令：`inc` / `dec`**

- **机制**：单操作数指令。执行 `inc A` 相当于 $A = A + 1$；执行 `dec A` 相当于 $A = A - 1$。
- **应用场景**：在 C 语言的 `for` 或 `while` 循环中，作为循环变量（如 `i++` 或 `i--`）更新的极速硬件实现。

**3. 有符号乘法指令：`imul`（极其灵活，考法最多）**

- **单操作数格式** `imul src`：**隐含操作数**。被乘数固定为 `EAX`，执行 $EAX \times src$，得到的 64 位超长结果存入 `EDX:EAX`（高 32 位在 EDX，低 32 位在 EAX）。
- **双操作数格式** `imul dest, src`：执行 $dest = dest \times src$，结果被截断为 32 位存入 `dest`。
- **三操作数格式** `imul dest, src, imm`：执行 $dest = src \times 立即数$。

**4. 有符号除法指令：`idiv`（隐含寄存器的重灾区）**

- **机制**：单操作数指令。格式为 `idiv divisor`。
- **隐含操作数**：它强制要求将被除数放在被拼接的 64 位寄存器 `EDX:EAX` 中。
- **运算结果分流**：执行除法后，**商存入 `EAX`，余数存入 `EDX`**。

### ⚠️ 易错点 / 易混点（408 汇编大题致命陷阱）

在 408 考研大题中，命题人极其喜欢在以下几个特性上给你挖坑：

**1. 访存越界陷阱：双操作数不能同为内存！**

- **错觉**：很多人写汇编时会想当然地写出 `add [ebp-4], [ebp-8]` 这种直接让两个内存变量相加的代码。
- **纠错**：**绝对非法！** x86 指令集规定，绝大多数双操作数指令中，**最多只能有一个操作数是内存地址**。必须先用 `mov` 把一个内存变量拿到寄存器里，再和另一个内存变量相加。

**2. 乘除法的“隐形操作手”陷阱（EDX:EAX）**

- **大坑**：在阅读乘法（单操作数 `imul`）或除法（`idiv`）代码时，指令表面上只写了一个操作数，很多同学不知道去哪里找结果。
- **实战反应**：只要看到 `idiv`，眼睛必须立刻往上扫，寻找前置指令中针对 `EDX` 和 `EAX` 的赋值（通常除法前会有一条 `cdq` 指令将 EAX 的符号位扩展到 EDX 中以构成 64 位被除数）；除法结束后，如果 C 语言代码里求的是商（`/`），就去看 `EAX`；求的是模/余数（`%`），就去看 `EDX`。

**3. 对标志位（Flags）的影响**

- 算术指令（`add`/`sub` 等）执行后会自动刷新 `EFLAGS` 寄存器。例如减法产生借位会置 `CF=1`，结果为负置 `SF=1`，结果为零置 `ZF=1`。
- _对比_：数据传送指令（如 `mov`、`lea`）以及压栈出栈（`push`、`pop`）**绝对不改变任何标志位**。

### 💡 记忆提示（工厂加工模型）

你可以把这几类运算想象成“车间加工”：

- **`add` / `sub`** = **双人流水线**。原料 A 和原料 B 被送进 ALU 加工器，加工完的新产物直接扔进原料 A 的筐里（覆盖目的操作数）。
- **`inc` / `dec`** = **计数器打点**。自己直接拨动滚轮 +1 或 -1。
- **`imul` / `idiv` (单操作数模式)** = **VIP 专属通道**。只要启用这台巨型机器，哪怕指令上没写，系统也会默认征用车间里最大的两辆推车 —— **`EAX`** 和 **`EDX`**。除法就像“拆解”，把超长的拼装件（EDX:EAX）拆成“商”和“余数”分别放回这两辆车里。
