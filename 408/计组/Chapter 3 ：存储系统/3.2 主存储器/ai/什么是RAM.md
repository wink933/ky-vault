作为你的 **“408 计算机组成原理复习助手”**，我将为你梳理 RAM（随机存取存储器）的核心考点。在 408 考试中，这部分是存储系统章节的绝对重点，尤其爱考 **SRAM 与 DRAM 的对比** 以及 **DRAM 的刷新机制**。

### 结论

随机存取存储器（RAM）是一种**易失性**的半导体存储器，其最大特点是**存取时间与存储单元的物理位置无关**。在考研 408 中，它的核心知识点分为两脉：用于构建 Cache 的 **SRAM（静态 RAM）** 和用于构建主存的 **DRAM（动态 RAM）**。

---

### 关键点

**1. 核心机制：SRAM vs DRAM**

- **SRAM（静态RAM）**：利用**双稳态触发器**存储信息。只要不断电，状态就能一直保持，读出也是非破坏性的，速度极快。
- **DRAM（动态RAM）**：利用**栅极电容上的电荷**存储信息。因为电容会自然漏电，信息会随时间衰减，且读出是破坏性的，所以必须要有自动恢复和定期维护的机制。

**2. DRAM 的两大特殊机制（必考）**

- **刷新（Refresh）**：为了防止电容漏电导致信息丢失，必须定期给 DRAM 充电。刷新是以**行**为单位进行的，不依赖 CPU。
    - _集中刷新_：在一个刷新周期内，集中安排时间刷新所有行。会产生 CPU 无法访问主存的“死时间”。
    - _分散刷新_：把刷新分散到每个存取周期内。没有死时间，但会极大增加系统的存取周期，降低存取速度。
    - _异步刷新_：结合前两者优点，将刷新周期除以行数，每隔固定时间刷新一行，死时间被分散开来。
- **地址线复用**：为了减少芯片的引脚数量，DRAM 通常将地址线引脚复用，**行地址和列地址分两次先后输入**。这使得 DRAM 的地址线数量可以直接减半。

### 易混概念辨析：SRAM 与 DRAM 对比

这是 408 最爱考的选择题辨析点，请务必熟记此表：

| 维度         | SRAM (静态RAM) | DRAM (动态RAM)    |
| :--------- | :----------- | :-------------- |
| **存储信息原理** | 双稳态触发器       | 电容电荷            |
| **破坏性读出**  | 非（非破坏性）      | **是**（破坏性读出）    |
| **是否需要刷新** | **不需要**      | **需要**          |
| **运行速度**   | 快            | 慢               |
| **集成度**    | 低            | 高               |
| **发热量**    | 大            | 小               |
| **主要用途**   | 高速缓存（Cache）  | 主存（Main Memory） |

### 易错点 / 陷阱提示

- **陷阱 1：刷新 vs 重写（易混点）**
    - **重写**：DRAM 是破坏性读出，读操作后原有电荷流失，因此每次读出后必须立刻进行一次“重写”来恢复数据。
    - **刷新**：由于电容自然漏电，即使不读写，一段时间后数据也会丢失，所以需要专门的定时“刷新”操作。**重写不能代替刷新**。
- **陷阱 2：刷新是由谁控制的？**
    - DRAM 的刷新对 CPU 是透明的，它由**存储器内部的控制电路**（或主存控制中心）独立完成，**不需要 CPU 的干预**，也不占用 CPU 资源。
- **陷阱 3：DRAM 引脚数计算**
    - 计算 DRAM 芯片引脚时，**地址线要除以 2**（因为复用）。例如 $4M \times 4$ 位的 DRAM，容量 $4M = 2^{22}$，理论需要 22 根地址线，但采用引脚复用后，地址线只需 **11 根**。
    - _注意：_ 考试中有时不仅要算地址线和数据线，还要考虑电源线、接地线、以及行通选($\overline{RAS}$)、列通选($\overline{CAS}$) 等控制线。

### 💡 记忆提示

- **SRAM 的 S 是 Static (稳定)** $\rightarrow$ 结构稳定（触发器） $\rightarrow$ 速度快 $\rightarrow$ 成本高 $\rightarrow$ 适合做 **Cache**。
- **DRAM 的 D 是 Dynamic (动态)** $\rightarrow$ 状态在流失（电容） $\rightarrow$ 必须动态“刷新” $\rightarrow$ 集成度高/容量大 $\rightarrow$ 适合做 **主存**。
