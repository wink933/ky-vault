作为你的 **“408 计算机组成原理复习助手”**，我严格基于教材资料（特别是第三章存储系统）为你精准提炼 **只读存储器（ROM，Read-Only Memory）** 的核心考点。

在 408 统考中，ROM 通常不会出大题，但它是第一章和第三章选择题里的**“高频挖坑词”**。命题人极度喜欢拿它的“访问方式”和“编址方式”与 RAM 进行概念混淆。

### 结论

**ROM（只读存储器）** 是一种**非易失性**的半导体存储器。 在计算机系统的正常运行过程中，它的内容只能被读取，不能被修改；一旦断电，其内部存储的信息**绝对不会丢失**。在计算机架构中，ROM 和 RAM 共同组成了系统的主存储器（主存），并且它们是**统一编址**的。

---

### 关键点：408 核心机制与特性

根据资料，你必须掌握关于 ROM 的以下 4 个核心设定：

**1. 绝对的随机存取特性（🌟 必考核心）**

- **机制**：虽然它的名字叫“只读”，但 ROM 的存取方式和 RAM 一模一样，都是**随机存取（Random Access）**。这意味着 CPU 访问 ROM 中任意一个地址单元所花费的时间都是固定的，与数据的物理位置毫无关系。

**2. 物理与架构特性**

- **非易失性**：断电后数据不丢失，可靠性极高。
- **高位密度**：由于结构简单，它的位密度通常高于 SRAM 等可读/写存储器。
- **统一编址**：在主存空间中，ROM 和 RAM 会被分配在不同的物理地址区间，对 CPU 而言，访问 ROM 里的指令和访问 RAM 里的数据，使用的访存指令是完全一样的。

**3. 核心应用场景**

- **存放固定不变的程序和数据**：例如计算机主板上的 BIOS（基本输入/输出系统）程序、操作系统的引导程序等。
- **控制存储器（CM）**：在第五章的微程序控制器中，存放微指令的控制存储器（CM）底层物理元件就是 ROM。

**4. ROM 的家族演进（了解即可，防偏难选择题）** 资料中提到了 ROM 极其清晰的演进路线：

- **MROM（掩模式 ROM）**：厂家出厂时直接写死，谁也改不了。
- **PROM（一次可编程 ROM）**：用户可以用专用设备写一次，写完就定型（破坏性熔断）。
- **EPROM（可擦除可编程 ROM）**：可以用紫外线或电信号多次擦除和重写，但写入速度极慢。
- **Flash 存储器（闪存）**：在 EPROM 基础上发展而来，既有 ROM 的非易失性，又具备快速的电可擦除重写能力（现代 SSD 固态硬盘和 U 盘的核心元件）。

### ⚠️ 易错点 / 易混点（408 必背排雷区）

这是 408 命题人最喜欢设置的 3 个“致命错觉陷阱”：

**1. 致命陷阱：“既然 RAM 叫随机存取存储器，那 ROM 就不是随机存取”**

- **真相**：**绝对错误 ❌！** `` 资料反复强调：**ROM 同 RAM 一样，均采用随机存取方式**。选择题里只要看到“ROM 只能顺序存取”直接打叉。

**2. 致命陷阱：“主存（内存）仅仅由 RAM 组成”**

- **真相**：**错误 ❌！** 计算机的主存是由 RAM 和 ROM **共同构成**的。比如一台电脑的低地址区间可能分给 ROM 放引导代码，高地址区间分给 RAM 供操作系统和用户程序使用。

**3. 概念界限：Flash（闪存）属于 RAM 吗？**

- **真相**：**不属于 ❌！** Flash 是在 ROM 基础上发展起来的非易失性存储器。虽然它现在读写速度很快（还能当硬盘用），但在分类体系上，它永远属于 ROM 这一侧的衍生物。

### 💡 记忆提示（“石碑与黑板”模型）

你可以把计算机的主存储器想象成一间教室里的**两种记录工具**：

- **RAM（内存条）** = **粉笔黑板**。随时可以快速写字和擦除（可读可写），但一旦放学关灯关门（断电），值日生就会把黑板擦得一干二净（易失性）。
- **ROM（只读存储器）** = 镶嵌在墙上的**传世石碑**。上面的字是找石匠刻上去的（只能读，很难改），就算放学断电经历千年，字也永远都在（非易失性）。
- **随机存取**：不管是看黑板上的哪个字，还是看石碑上的哪个字，你只需眼睛一瞟（给出地址），**看任何一个字所花的时间都是瞬间相等的（随机存取）**，不需要像看录像带那样快进倒退。
