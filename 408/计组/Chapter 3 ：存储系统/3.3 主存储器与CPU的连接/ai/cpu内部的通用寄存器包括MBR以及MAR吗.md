### 结论

**绝对不包括。** MAR（存储器地址寄存器）和 MBR（存储器数据寄存器，在资料中也常称为 MDR）属于 CPU 内部的**专用寄存器（或控制/状态寄存器）**，它们**绝不属于**通用寄存器。

---

### 关键点：底层定位拆解

在 408 的概念体系中，区分它们的核心在于“用途”和“位宽的决定因素”：

**1. 通用寄存器组（GPRs）的定位**

- **用途**：为 ALU（算术逻辑单元）提供操作数并暂存运算的中间结果（例如 x86 架构里的 EAX、EBX 等）。
- **宽度**：它的宽度直接决定了我们上一题讲的**“机器字长”**（即 CPU 内部单次能处理的最大整数位数）。

**2. MAR 和 MBR（MDR）的定位**

- **用途**：它们是 CPU 内部专门为了**“和外部主存（内存）打交道”**而设立的两个专用过渡站。MAR 只负责放“要找的内存地址”，MBR/MDR 只负责放“从内存取回来或要写进内存的数据”。
- **宽度**：
    - **MAR 的位数**由该机器的**最大物理寻址空间（即地址总线宽度）**决定。
    - **MBR/MDR 的位数**由该机器的**数据总线宽度（或存储字长）**决定。
    - _(注：正如上一题所说，它们的宽度在物理设计上可以与机器字长/通用寄存器完全不相等)_。

### ⚠️ 易错点 / 易混点（408 必考选择题：透明性陷阱）

在 408 第一章和第五章的历年真题中，命题人最喜欢用**“透明性（Transparency）”**这个概念来考查你是否真正分清了这两类寄存器：

- **什么是透明？** 在计算机中，“透明”的意思是**“客观存在，但用户看不见，也无法直接用指令去控制它”**。
- **通用寄存器 $\rightarrow$ 不透明（可见）**：对汇编语言程序员是可见的。因为程序员在写汇编代码时，可以直接指定数据放到哪个通用寄存器里（如 `MOV AX, 1`）。
- **MAR 和 MBR $\rightarrow$ 完全透明**：根据教材明确规定，**CPU 中的指令寄存器（IR）、MAR 和 MBR（MDR）对所有程序员均透明**。这意味着，它们是由 CPU 的硬件控制电路在底层自动调用的，程序员不能写任何一条指令去直接说“把某个数放进 MAR 里”。
