### 结论

在 408 考研中，现代计算机本质上**依然是冯·诺依曼机**的进化版。

两者的灵魂完全相同（均严格遵循**“存储程序”**思想），核心区别仅仅在于**物理形态的集成度**（运算器与控制器合并为 CPU）以及**部件间的互连拓扑**（从早期简单连接演进为典型的**多总线结构**）。

---

### 核心对比矩阵（🔥 408 极速速查表）

| 对比维度        | 经典冯·诺依曼机                              | 现代计算机                                             |
| :---------- | :------------------------------------ | :------------------------------------------------ |
| **核心思想**    | **存储程序**（按地址访问，顺序执行）                  | **存储程序**（依然未变）                                    |
| **硬件部件划分**  | 严格划分为**五大独立部件**：运算器、控制器、存储器、输入设备、输出设备 | 高度集成：运算器与各类寄存器、控制器集成形成 **CPU 芯片**；外设由 I/O 控制器管理   |
| **系统互连方式**  | 早期各部件间多为分散的直接连接                       | 采用典型的**多总线结构**（CPU 通过处理器总线、I/O 桥接器与主存及外设通信）       |
| **驱动工作方式**  | **控制流驱动**（由 PC 提供地址逐条取指令）             | **控制流驱动**（未变）                                     |
| **指令与数据存放** | 同等地位存放在同一个存储器中，无格式差别                  | 在主存中依然同等存放（但在 CPU 内部的 L1 Cache 中通常采用指令和数据分离的哈佛结构） |

### 关键点

根据教材，理解两者的关系必须把握以下核心机制：

**1. 坚不可摧的“存储程序”灵魂** 现代计算机无论跑得多快，其工作方式依然是冯·诺依曼在 EDVAC 机时提出的“存储程序”：将编写好的程序和数据预先存入主存储器，启动后 CPU 无须人工干预，自动、连续地根据程序计数器（PC）提供的地址取指令并按序执行。

**2. 从“五大件”到“三大件”的物理演进** 在现代体系结构中，物理部件的界限发生了重组。运算器（ALU）和控制器被“打包”塞进了一块 CPU 芯片里；而各种复杂的输入输出设备（键盘、显示器、硬盘）及其控制电路被统称为外部设备（I/O 设备）。系统在宏观上简化为了 **CPU、存储器、I/O 系统** 三大部分。

**3. 多总线结构的全面接管** 为了解决传统架构中数据传输的瓶颈，现代计算机广泛采用总线（如处理器总线、系统总线）作为部件间传输信息的公共通路。以 CPU 为核心，通过各类桥接芯片（如北桥/南桥，或现代整合的 I/O 桥接器）来统一协调存储器和外部设备的访问。

### 易错点 / 易混点（⚠️ 408 极高频陷阱）

出题人极爱在第一章的概念判断题中，利用现代计算机的新技术来动摇你对“冯·诺依曼结构”的判断：

- ❌ **常见陷阱 1：认为现代计算机引入了流水线、多核处理，所以已经不再是冯·诺依曼机了。**
    - ✅ **408 纠正**：**致命错误！** 只要一台计算机仍然把指令和数据用二进制存放在同一个存储器里，并且靠 PC（程序计数器）来逐条取指令执行，它就属于冯·诺依曼架构。流水线和多核仅仅是微架构（Microarchitecture）层面的实现优化，没有改变“存储程序”这一 ISA 层面的根本定性。
- ❌ **常见陷阱 2：认为冯·诺依曼机的工作方式是“数据驱动”。**
    - ✅ **408 纠正**：**送分陷阱！** 冯·诺依曼机的本质工作方式是**“控制流驱动”**（按指令的执行顺序来驱动操作）。“数据流驱动”（只要操作数准备好就触发执行）是与冯·诺依曼体系相对立的非传统体系结构模型。  
      [[数据流驱动和控制流驱动有什么区别]]
- ❌ **常见陷阱 3：认为现代 CPU 内部指令 Cache 和数据 Cache 是分开的，因此违背了冯·诺依曼结构“指令和数据同等存放”的原则。**
    - ✅ **408 纠正**：_(根据资料知识归纳)_ 这是一种微观上的妥协。在 L1 Cache 层面上，为了避免取指和访存发生结构冒险，确实采用了指令和数据分离的“哈佛结构”；但在**主存储器（内存）**层面上，指令和数据依然没有任何物理隔离，完全混合存放，依然完美遵守冯·诺依曼的核心思想。
