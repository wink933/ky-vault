在高等数学和空间解析几何中，我们常说的“计算投影面方程”，通常是指求**空间曲线在坐标面上的投影（投影柱面与投影曲线）**，或者是求**空间曲面/立体在坐标面上的投影区域（常用于多重积分化维）**。

这两者的计算核心逻辑都是“消元”，但具体场景有所不同。以下为你进行“外科手术式”的分类拆解：

### 核心心法：向哪个面投影，就消去哪个变量

- 向 **$xOy$** 面投影 $\rightarrow$ 想办法消去 **$z$**
    
- 向 **$yOz$** 面投影 $\rightarrow$ 想办法消去 **$x$**
    
- 向 **$zOx$** 面投影 $\rightarrow$ 想办法消去 **$y$**
    

### 场景一：求空间曲线的投影

空间曲线 $L$ 通常由两个曲面的交线构成，其一般方程为方程组：

$$\begin{cases} F(x,y,z) = 0 \\ G(x,y,z) = 0 \end{cases}$$

**目标**：求该曲线在 $xOy$ 平面上的投影。

**步骤**：

1. **构造投影柱面**：通过代入法或加减消元法，从上述方程组中**消去 $z$**，得到一个只含 $x, y$ 的方程 $H(x,y) = 0$。
    
    - _注：这个在空间中无限延伸的 $H(x,y) = 0$ 严格来说叫做**投影柱面**。_
        
2. **写出投影曲线方程**：将投影柱面与 $xOy$ 平面（即 $z=0$）联立。完整的投影曲线方程必须写成二维空间或三维空间中加上 $z=0$ 的形式：
    
    $$\begin{cases} H(x,y) = 0 \\ z = 0 \end{cases}$$
    

**实战举例**：

求曲线 $\begin{cases} x^2 + y^2 + z^2 = 1 \\ x + y + z = 0 \end{cases}$ 在 $xOy$ 平面上的投影。

- 由第二个方程得 $z = -(x+y)$，代入第一个方程。
    
- 得到 $x^2 + y^2 + (x+y)^2 = 1$，化简为 $2x^2 + 2xy + 2y^2 = 1$（这就是投影柱面）。
    
- 最终投影曲线为：$\begin{cases} 2x^2 + 2xy + 2y^2 = 1 \\ z = 0 \end{cases}$。
    

### 场景二：求空间立体的投影区域（求二重/三重积分的 $D$ 域）

在计算多重积分时，我们需要找出一个空间立体 $\Omega$ 投射到坐标面上的“影子”（投影区域 $D$）。这分为两种常见情况：

#### 情况 A：立体由上下两张曲面相交围成（最常见）

如果空间区域由曲面 $z = z_1(x,y)$ 和 $z = z_2(x,y)$ 围成。

- **计算方法**：直接令两曲面的方程相等，即 **$z_1(x,y) = z_2(x,y)$**，化简后得到的二维不等式区域，就是投影区域 $D_{xy}$。
    
- **例子**：求抛物面 $z = x^2 + y^2$ 与平面 $z = 4$ 围成立体的投影。
    
    令 $x^2 + y^2 = 4$，这就是投影区域的边界。因此投影区域为 $D_{xy}: x^2 + y^2 \le 4$。
    

#### 情况 B：立体是一个封闭的完整曲面（如椭球体、偏心球）

如果空间区域由一个封闭曲面 $F(x,y,z) = 0$ 围成，你不能通过简单的相交来找边界，你需要找它的“赤道轮廓线”。

- **计算方法（偏导数法）**：
    
    1. 对被消去的变量求偏导并令其为0。如果向 $xOy$ 面投影，则令 **$\frac{\partial F}{\partial z} = 0$**。这代表寻找曲面上法向量水平、切平面垂直于 $xOy$ 面的点（即轮廓的边缘）。
        
    2. 将 $\frac{\partial F}{\partial z} = 0$ 与原方程 $F(x,y,z) = 0$ 联立，消去 $z$。
        
    3. 得到的 $H(x,y) = 0$ 就是投影区域的边界曲线。
        
- **例子**：求曲面 $x^2 + 2y^2 + z^2 - 2z = 0$ 在 $xOy$ 面的投影区域。
    
    1. 令 $F(x,y,z) = x^2 + 2y^2 + z^2 - 2z$。
        
    2. 求偏导：$\frac{\partial F}{\partial z} = 2z - 2 = 0 \Rightarrow z = 1$。
        
    3. 将 $z = 1$ 代回原曲面方程，得 $x^2 + 2y^2 + 1 - 2 = 0$，即 $x^2 + 2y^2 = 1$。
        
        所以投影区域为 $D_{xy}: x^2 + 2y^2 \le 1$。
