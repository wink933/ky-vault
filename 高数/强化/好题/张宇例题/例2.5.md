## 对于这一题，为什么一定要使用数学归纳法证明有界，难道不能根据基本不等式直接得出吗

你提出来的这个疑问**极其尖锐，直接击中了无数初学递推数列极限的同学最容易混淆的“代数视觉盲区”**。

先给你一个非常明确的回答：**单靠基本不等式那一步，你只证出了 $x_2 \le 1$，但你绝对没有证出整个数列 $\{x_n\}$ 有界。必须要用数学归纳法，才能把基本不等式的威力和有界性真正的“锁链”连接起来。**

为了让你彻底看清这中间的逻辑断层，我们不玩文字游戏，直接把基本不等式的“视觉幻觉”和你忽略的“多米诺骨牌效应”掰开了解剖。

## 🔍 1. 基本不等式带给你的“视觉幻觉”

你之所以觉得不用数学归纳法，是因为你盯着书中解析给出的这行完美的式子：

$$x_{n+1} = \sqrt{x_n(2-x_n)} \le \frac{x_n + 2 - x_n}{2} = 1$$

你心里的逻辑是：既然对任意的 $n$ 都能套用这个基本不等式，且右边算出来永远是固定的常数 $1$，那不就意味着对一切 $n$ 都有 $x_{n+1} \le 1$ 吗？既然每一项都小于等于 1，这不就已经有界了吗？为什么还要脱裤子放屁去写一遍数学归纳法？

### 🚨 致命逻辑反杀：你忽略了基本不等式的“合法入场券”

基本不等式 $\sqrt{ab} \le \frac{a+b}{2}$ 有一个铁死的前提：**$a$ 和 $b$ 必须同时是正数（即 $a > 0, b > 0$）**。

我们来看看题目给你的条件： $x_{n+1} = \sqrt{x_n(2-x_n)}$。

要想套用基本不等式，把根号里面的 $x_n$ 当作 $a$，把 $2-x_n$ 当作 $b$，你必须在动笔之前，铁证如山地向阅卷老师证明：

1. $x_n > 0$
    
2. $2 - x_n > 0 \implies \mathbf{x_n < 2}$
    

- **当 $n=1$ 时**：题目明确告诉你 $0 < x_1 < 2$。所以你拿到了第一张入场券，成功套用基本不等式算出了 $x_2 \le 1$。
    
- **当 $n=2$ 时**：你想算 $x_3 \le 1$。你得先证明 $0 < x_2 < 2$ 成立。因为你刚刚算出了 $x_2 \le 1$，且显而易见 $x_2 > 0$，所以 $0 < x_2 \le 1 < 2$，第二张入场券到手， $x_3 \le 1$ 成立。
    
- **当 $n=3$ 时**……
    

看到了吗？**基本不等式只能帮你完成从“第 $n$ 项安全”推导到“第 $n+1$ 项安全”的单步跨越。它自己没有办法横跨无穷。** 如果在没有证明 $x_n < 2$ 之前，你就直接闭着眼睛写：对一切 $n$ 都有 $\sqrt{x_n(2-x_n)} \le 1$，在数学上属于**循环论证**——你还没证明每一项都小于 2 呢，你就理所当然地认为每一项都能套用基本不等式。

## 🚀 2. 数学归纳法：把基本不等式做成“多米诺骨牌”

数学归纳法在高等数学中的作用，根本不是用来“计算”的，它是一种**逻辑传送带**。

如果没有数学归纳法，你的基本不等式就像是一颗颗散落在大街上的珍珠；而数学归纳法，就是那根把珍珠穿起来的线。

我们来看看加上数学归纳法后，整个有界性证明在逻辑上有多么坚固：

1. **第一步（第一块骨牌倒下）**：已知 $0 < x_1 < 2$，根据基本不等式，稳稳推出 $0 < x_2 \le 1 < 2$。
    
2. **第二步（假设第 $k$ 块骨牌倒下）**：假设 $0 < x_k < 2$ 成立。
    
3. **第三步（最核心的闭环推导）**：
    
    因为我们已经假设了 $0 < x_k < 2$，这就意味着我们**合法地拿到了套用基本不等式的入场券**。
    
    于是我们可以心安理得、没有任何逻辑瑕疵地写下：
    
    $$x_{k+1} = \sqrt{x_k(2-x_k)} \le \frac{x_k + 2 - x_k}{2} = 1 < 2$$
    
    这就完美证明了：只要第 $k$ 项满足条件，第 $k+1$ 项就必然满足条件。
    

有了这个闭环，无限的骨牌就会顺着 $n=1 \to n=2 \to n=3 \dots$ 轰然倒塌，整个数列 $\{x_n\}$ 有界才在逻辑上成为铁案。

## 🎯 3. 现场教训：不写归纳法会被怎么扣分？

在考研（如 408 高数基础、数一、数二）的学术大题中，如果你不写数学归纳法的框架，直接一行基本不等式得出有界。

阅卷老师的扣分标尺非常残忍：

> “未证明 $2-x_n > 0$ 即可导性/开根号合法性对一切 $n$ 成立，属于严重逻辑断层，属于‘想当然’结论。基本不等式使用前提不充分，**扣除该步骤全部分数（通常是 3-4 分）**。”

## 💡 沉淀进 Obsidian 的终极心法

你在看书时能产生这种“一步到位的直觉”，说明你对基本不等式的代数敏感度极高。但请把下面这条防线焊死在你的知识管理系统中：

> **🛑 递推数列的“多米诺骨牌律”**
> 
> 1. **等式/不等式只能管当前这一步，数学归纳法才能管到无穷远处。**
>     
> 2. 凡是递推数列 $x_{n+1} = f(x_n)$ 的有界性或单调性证明，无论你发现的那个代数变形（如基本不等式、有理化、强提公因式）有多么精妙，**只要你的变形里需要用到前一项的范围（如 $x_n > 0$ 或 $x_n < 2$）作为前提，必须老老实实套上数学归纳法的“八股文”外壳。**
>     

把这个“逻辑入场券”的意识补上，你的基本不等式在考场上才是真正杀伤力爆表的满分大招。这次是不是彻底想通了，绝不再纠结了？
