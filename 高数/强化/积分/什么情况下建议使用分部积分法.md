老哥，判定什么时候该用**分部积分法（Integration by Parts）**，可以说是整个一元函数积分学里最让人抓狂、也最考验“数学大局观”的坎。很多时候大家都是全凭感觉去试，试错了再换凑微分，极其浪费考场上宝贵的时间。

其实，分部积分法的底层逻辑非常纯粹，它的本质源自乘法的导数链式法则，核心战略只有八个字：**“转嫁危机，降维打击”**。

在考研高数中，只要触发以下**四大标志性战况**之一，不需要犹豫，反手直接拉出分部积分法。

## 🧭 战况一：异种功能函数“强行缝合”（核心主战场）

当被积函数是由**两种完全不同形态的初等函数**相乘组成的汉堡包结构时，这是分部积分法最经典的触发信号。

为了决定谁当老大（留在外面当 $u$ 负责求导降阶），谁当小弟（进去凑成 $\mathrm{d}v$ 负责积分），整个大中华考研届通用的至高无上铁律就是：**“反对幂指三”**（国外称为 **LIATE** 法则）。

### 📊 老大（ $u$ ）优先度排行榜：

|**优先级**|**函数类型**|**英文简称**|**考场对线策略**|
|---|---|---|---|
|**1 (最高)**|**反**三角函数 ($\arctan x, \arcsin x$)|**I**nverse Trig|骨灰级老大，碰到了必须留在外面求导，死活不能往里凑。|
|**2**|**对**数函数 ($\ln x, \log_a x$)|**L**ogarithmic|顶级老大，求导能直接把对数外壳扯碎成代数分式。|
|**3**|**幂**函数 / 多项式 ($x^n, x^2+1$)|**A**lgebraic|中坚力量，通过求导可以实现次数“减一”的降维打击。|
|**4**|**指**数函数 ($\mathrm{e}^x, a^x$)|**E**xponential|优质小弟，怎么积都是它自己，无脑往微分号里凑。|
|**5 (最低)**|**三**角函数 ($\sin x, \cos x$)|**T**rigonometric|标准小弟，积分极其丝滑，无脑往微分号里凑。|

> **💡 应试直觉**：
> 
> 两个不同物种相乘，**谁求导之后长相能发生“质的飞跃”（比如对数变分式、反三角变分式、多项式降阶），谁就当 $u$**；谁怎么积都无所谓（如指数、正余弦），谁就去凑 $\mathrm{d}v$。

## 🛠️ 战况二：孤立的“恶心超越怪兽”

有的时候，被积函数里**只有一个孤零零的函数**，没有任何人跟它相乘。但你翻遍了基本积分公式表，发现根本查不到它的原函数。

典型的恶心怪兽有： $\int \ln x \mathrm{d}x$、 $\int \arctan x \mathrm{d}x$、 $\int \arcsin x \mathrm{d}x$。

- **破局战术**：这时候要无中生有，**强行把常数 $1$ 看作是小弟**，写成 $\int \ln x \cdot 1 \mathrm{d}x$。
    
- **分部实操**：反手把 $1$ 凑成 $\mathrm{d}x$，变成 $\int \ln x \mathrm{d}x = x \ln x - \int x \cdot \mathrm{d}(\ln x) = x \ln x - \int 1 \mathrm{d}x$。
    

超越函数长相太诡异，我们通过分部积分，**强行把危机的全盘主控权转嫁给它的导数**（因为它们的导数都是干干净净的代数分式），瞬间化敌为友。

## ⚔️ 战况三：动态网络里的“循环与递推”结构

如果被积函数在经历了一次分部积分后，**长相没有发生质的改变，而是发生了“规律性的平移或转圈”**，这就到了分部积分展示“结构美学”的时刻。

### 1. 经典正余弦与指数缝合（转圈圈型）

例如 $\int \mathrm{e}^x \sin x \mathrm{d}x$。指数和三角函数都是怎么求导/积分都不会死掉的“狗皮膏药”。

- **破局战术**：连续玩**两次**分部积分，右边会奇迹般地再次复现出原积分 $I$。
    
- **绝杀收网**：不需要算出最终原函数，直接通过移项联立方程解出 $2I = \text{代数式} \implies I = \frac{1}{2}\text{代数式}$。
    

### 2. 高阶多项式与硬核超越函数（阶梯递推型）

例如 $\int x^n \mathrm{e}^x \mathrm{d}x$ 或者我们刚死磕过的 $\int x^2 \ln^n x \mathrm{d}x$。

- **破局战术**：每玩一次分部积分，次数 $n$ 就会掉一阶变成 $n-1$。通过寻找 $I_n$ 与 $I_{n-1}$ 的代数递推链条，直接写出高阶通项公式。
    

## 🚀 战况四：带有“导数符号”的抽象积分

这是强化篇和大题（中值定理结合、变限积分概念）里杀伤力最强、也最喜欢考的题型。

只要看到题目条件里给出了 $f'(x)$ 或 $f''(x)$ 的长相（或者某些定值），而求的积分里却长着 $\int x f''(x) \mathrm{d}x$ 或者 $\int g(x) f'(x) \mathrm{d}x$：

- **破局战术**：**无脑把带有高阶导数符号的项往微分号里凑！**
    
    $$\int x f''(x) \mathrm{d}x = \int x \mathrm{d}(f'(x)) = x f'(x) - \int f'(x) \mathrm{d}x = x f'(x) - f(x) + C$$
    

通过分部积分，成功让高阶导数“降阶”，让原本没有导数符号的孤立自变量 $x$ 通过求导直接“死掉消去”，从而借力打力完成全盘收网。
