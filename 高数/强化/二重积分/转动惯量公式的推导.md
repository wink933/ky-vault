图片 **5146ca06c2c8092db2f43bd853c65905.png** 中展示的各种转动惯量（Moment of Inertia）公式，虽然形式多样（涉及二重积分、三重积分、第一类曲线积分和第一类曲面积分），但它们的推导逻辑是完全一致的。

这些公式都是由**物理学中转动惯量的最基础定义**结合**微积分思想**推导而来的。以下是具体的推导拆解：

### 1. 物理本质：离散到连续的跨越

在基础物理中，对于一个由若干质点组成的**离散系统**，其绕某一轴线转动的转动惯量定义为：每个质点的质量 $m_i$ 乘以它到转轴垂直距离的平方 $r_i^2$ 的总和。

$$I = \sum m_i r_i^2$$

当我们将研究对象从离散的质点变为**连续的物体**（如一根铁丝、一块薄板或一个实心球体）时，求和符号 $\sum$ 就变成了积分符号 $\int$。我们将物体无限细分成无数个微小的“质量元” $\text{d}m$，转动惯量的通用连续体公式就变为：

$$I = \int r^2 \text{d}m$$

图片中的所有公式，都是在这个核心公式 $I = \int r^2 \text{d}m$ 的基础上展开的。推导的核心就在于确定两件事：**“距离平方 $r^2$ 怎么写”** 和 **“质量元 $\text{d}m$ 怎么写”**。

### 2. 距离平方 $r^2$ 的几何推导

$r$ 代表的是微元点 $(x, y, z)$ 到**转轴（或极点）的垂直距离**。根据空间解析几何，距离的平方 $r^2$ 的表达形式如下：

- **绕 $x$ 轴转动 ($I_x$)**：点 $(x, y, z)$ 到 $x$ 轴的垂足是 $(x, 0, 0)$，两点间距离的平方为 $y^2 + z^2$。所以在三维中 $r^2 = y^2 + z^2$；如果在二维 $xy$ 平面内，由于 $z=0$，则 $r^2 = y^2$。
    
- **绕 $y$ 轴转动 ($I_y$)**：同理，点 $(x, y, z)$ 到 $y$ 轴距离的平方为 $x^2 + z^2$（三维），或 $x^2$（二维）。
    
- **绕 $z$ 轴转动 ($I_z$)**：点 $(x, y, z)$ 到 $z$ 轴距离的平方为 $x^2 + y^2$。
    
- **对原点 $O$ 的极转动惯量 ($I_O$)**：点 $(x, y, z)$ 到原点 $(0, 0, 0)$ 距离的平方为 $x^2 + y^2 + z^2$（三维），或 $x^2 + y^2$（二维）。
    

### 3. 质量元 $\text{d}m$ 的展开推导

根据物体形状的不同，质量等于密度 $\rho$ 乘以几何微元。这直接决定了使用哪种积分：

#### 第一列：平面薄片（区域 $D$）

如果物体是位于 $xy$ 平面上的薄片，密度为面密度 $\rho(x, y)$。

- 面积微元为 $\text{d}x\text{d}y$。
    
- 质量元 $\text{d}m = \rho \text{d}x\text{d}y$。
    
- **推导 $I_x$**：代入通用公式，因为是二维平面，距离 $x$ 轴的距离平方为 $y^2$，即得到二重积分 $I_x = \iint_D y^2 \rho \text{d}x\text{d}y$。
    

#### 第二列：空间实体（区域 $\Omega$）

如果物体是三维实心体，密度为体密度 $\rho(x, y, z)$。

- 体积微元为 $\text{d}x\text{d}y\text{d}z$（或记作 $\text{d}V$）。
    
- 质量元 $\text{d}m = \rho \text{d}x\text{d}y\text{d}z$。
    
- **推导 $I_x$**：代入通用公式，距离 $x$ 轴的距离平方为 $(y^2 + z^2)$，即得到三重积分 $I_x = \iiint_\Omega (y^2 + z^2) \rho \text{d}x\text{d}y\text{d}z$。
    

#### 第三列：空间曲线（曲线 $L$）

如果物体是空间中的一根细线，密度为线密度 $\rho(x, y, z)$。

- 弧长微元为 $\text{d}s$。
    
- 质量元 $\text{d}m = \rho \text{d}s$。
    
- **推导 $I_x$**：代入通用公式，得到第一类曲线积分 $I_x = \int_L (y^2 + z^2) \rho \text{d}s$。
    

#### 第四列：空间曲面薄壳（曲面 $\Sigma$）

如果物体是空间中的一层曲面壳，密度为面密度 $\rho(x, y, z)$。

- 曲面面积微元为 $\text{d}S$。
    
- 质量元 $\text{d}m = \rho \text{d}S$。
    
- **推导 $I_x$**：代入通用公式，得到第一类曲面积分 $I_x = \iint_\Sigma (y^2 + z^2) \rho \text{d}S$。
    

### 总结

图表中所有的公式不需要死记硬背。你只需要在脑海中提取 **“距离轴的垂直距离平方”**，然后将它与对应几何体形态的 **“质量微元”** 结合，就能瞬间写出对应的多重积分或线面积分表达式。
