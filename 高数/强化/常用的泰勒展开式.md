# 👑 高数核心工具库：麦克劳林展开式与解题铁律

## 📌 核心说明

- **适用前提**：所有公式默认均满足 $x \to 0$。
    
- **高阶余项**：统一使用佩亚诺（Peano）余项 $o(x^n)$ 表示。
    

## 📂 一、 八大核心基础展开式

### 1. 指数、对数与分式（四大金刚）

#### ① 指数函数 $e^x$

> **特征**：全能型，各项均为正号，分母带阶乘。
> 
> $$e^x = 1 + x + \frac{1}{2!}x^2 + \frac{1}{3!}x^3 + \dots + \frac{1}{n!}x^n + o(x^n)$$

#### ② 对数函数 $\ln(1+x)$

> **特征**：正负交替，**分母无阶乘**。
> 
> $$\ln(1+x) = x - \frac{1}{2}x^2 + \frac{1}{3}x^3 - \dots + \frac{(-1)^{n-1}}{n}x^n + o(x^n)$$

#### ③ 基础分式 $\frac{1}{1-x}$

> **特征**：等比级数核心，**全为正号**，分母无阶乘。
> 
> $$\frac{1}{1-x} = 1 + x + x^2 + x^3 + \dots + x^n + o(x^n)$$

#### ④ 广义二项式 $(1+x)^\alpha$

> **特征**：牛顿二项式定理的延伸，极易演变成根式。
> 
> $$(1+x)^\alpha = 1 + \alpha x + \frac{\alpha(\alpha-1)}{2!}x^2 + \frac{\alpha(\alpha-1)(\alpha-2)}{3!}x^3 + \dots + o(x^3)$$

> **🔥 考研高频两大特例（建议单独记忆）：**
> 
> - $\sqrt{1+x} = (1+x)^{\frac{1}{2}} = 1 + \frac{1}{2}x - \frac{1}{8}x^2 + o(x^2)$
>     
> - $\frac{1}{\sqrt{1+x}} = (1+x)^{-\frac{1}{2}} = 1 - \frac{1}{2}x + \frac{3}{8}x^2 + o(x^2)$
>     

### 2. 三角与反三角（四大常客）

#### ① 正弦函数 $\sin x$

> **特征**：奇函数，**只有奇数次幂**，正负交替。
> 
> $$\sin x = x - \frac{1}{3!}x^3 + \frac{1}{5!}x^5 - \dots + \frac{(-1)^n}{(2n+1)!}x^{2n+1} + o(x^{2n+1})$$

#### ② 余弦函数 $\cos x$

> **特征**：偶函数，**只有偶数次幂**，正负交替。
> 
> $$\cos x = 1 - \frac{1}{2!}x^2 + \frac{1}{4!}x^4 - \dots + \frac{(-1)^n}{(2n)!}x^{2n} + o(x^{2n})$$

#### ③ 反正切函数 $\arctan x$

> **特征**：奇函数，只有奇数次幂，**分母无阶乘**，正负交替。
> 
> $$\arctan x = x - \frac{1}{3}x^3 + \frac{1}{5}x^5 - \dots + \frac{(-1)^n}{2n+1}x^{2n+1} + o(x^{2n+1})$$

#### ④ 反正弦函数 $\arcsin x$

> **特征**：奇函数，只有奇数次幂，**全为正号**。
> 
> $$\arcsin x = x + \frac{1}{6}x^3 + \frac{3}{40}x^5 + \dots + o(x^5)$$

## 📂 二、 强化必备：四大进阶展开式

在强化大题和相减未定式中，以下三个公式是打破僵局的利器：

### 1. 正切函数 $\tan x$

> **特征**：奇函数，**全为正号**。考研通常只需用到前两项。
> 
> $$\tan x = x + \frac{1}{3}x^3 + \frac{2}{15}x^5 + o(x^5)$$

### 2. 正割函数 $\sec x$

> **特征**：偶函数，全为正号，常用于与 $\cos x$ 对冲。
> 
> $$\sec x = \frac{1}{\cos x} = 1 + \frac{1}{2}x^2 + \frac{5}{24}x^4 + o(x^4)$$

### 3. 复合对数余弦 $\ln(\cos x)$

> **特征**：偶函数，**全为负号**，可免去现场双重复合展开的痛苦。
> 
> $$\ln(\cos x) = -\frac{1}{2}x^2 - \frac{1}{12}x^4 + o(x^4)$$

### 💡 隐藏款：双曲函数家族

> **极速记忆法**：双曲正弦 $\sinh x$ 与双曲余弦 $\cosh x$ 的展开式形态分别与 $\sin x, \cos x$ **完全一致**，只需将所有负号**通通改为正号**即可。

## 📂 三、 考场绝杀：三大“差式”三阶等价公式

当 $x \to 0$ 时，以下组合在选择题和填空题中可以直接作为**公式级工具**秒杀：

|**目标组合**|**三阶等价无穷小形式**|**底层泰勒支持**|
|---|---|---|
|**$\tan x - x$**|$\sim \frac{1}{3}x^3$|$\left(x + \frac{1}{3}x^3\right) - x$|
|**$x - \sin x$**|$\sim \frac{1}{6}x^3$|$x - \left(x - \frac{1}{6}x^3\right)$|
|**$\tan x - \sin x$**|$\sim \frac{1}{2}x^2 \cdot x = \frac{1}{2}x^3$|$\tan x(1 - \cos x)$ 提公因式或泰勒相加|

## 📂 四、 泰勒展开三大解题铁律（避坑指导）

### 🛑 铁律一：上下同阶原则（判定展开到第几阶）

求分式极限 $\lim_{x \to 0} \frac{F(x)}{G(x)}$ 时：

1. 先看分母（或结构最简单的项）通过等价无穷小能锁定它是几阶（例如分母是 $x^3$）。
    
2. **操作**：一旦确定主干阶数为 $n$ 阶，则分子大项中的所有泰勒公式**必须死死展开到 $x^n$ 项为止**。多展是浪费时间，少展必导致计算错误。
    

### 🛑 铁律二：相减项非零原则

当遇到 $f(x) - g(x)$ 的相减未定式时：

1. **操作**：必须展开到“第一项不被完全消去”的非零项为止。
    
2. 绝不能只展开到第一项看到它们抵消为 $0$ 就停止，否则会丢失低阶的主力无穷小量。
    

### 🛑 铁律三：间接展开优于强行求导

1. 面对复杂的复合、分式根式（如 $\sqrt{\frac{1+x}{1-x}}$），**严禁直接暴力求导**。
    
2. **操作**：先通过代数恒等变形（分子有理化、强提公因式、倒数翻转）将其拆分为上述基础八大公式的基底，然后整体换元代入，最后像多项式乘法一样合并，高于目标阶数的项统一扔进 $o(x^n)$ 中。
